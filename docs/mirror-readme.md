# 考研数学复习网站 · 镜像

{生成说明}

这是用户的考研数学复习网站（https://xushengqwer.github.io/kaoyan-math-review/）的内容镜像，给 Antigravity 里写稿、审稿的 AI 读。网站代码和提交由另一边的 Claude Code 负责。

**能改的只有两个文件夹**：`共同维护/`（和用户一起磨合的规矩）和 `待提交/`（交稿）。其他都是从仓库生成的，只读，改了也会在下次生成时被覆盖。平时只在对话里回答，用户说了才动这两个文件夹。

## 目录

| 位置 | 是什么 |
|---|---|
| `章节/目录.md` | 三科所有章、每章的卡片 id |
| `章节/<科目>/第NN章-<章名>.md` | 一章的全部内容：教材、笔记（含〔意义〕〔例题〕〔提示〕）、决策流、本章总结。卡片记号行保留 |
| `规矩/学习方法.md` | 用户的学习方法、推意义和例题的方式（最核心；要改请用户直接找 Claude Code） |
| `规矩/网站排版规则.md` | markdown 在网站上显示成什么样，哪些写法会原样露出来（审稿必读；由网站代码决定，只读） |
| `规矩/内容组织原则.md` | 整体架构原则 |
| `规矩/进度.md` | 每章做到哪、定下过哪些修改（很长，只看你要做的那一章） |
| `共同维护/设计口味.md` | 审稿门槛、解耦、三块分工、读薄等偏好（审稿必读）。**可以改**：用户和你磨合出新的口味，直接写进来 |
| `共同维护/写作格式要求.md` | 写〔定义〕〔性质〕〔意义〕〔例题〕的开场白模板和格式要求。**可以改** |
| `待提交/` | 交稿文件放这里；Claude Code 提交后挪进 `待提交/已提交/` |

`共同维护/` 里的文件以这里为准，Claude Code 每次生成镜像时把改动抄回仓库存档。

## 写稿

不需要素材包：直接读要写的那一章的文件。开场白模板在 `共同维护/写作格式要求.md`，学习方法在 `规矩/学习方法.md`。用户说「可以了」以后，按下面「交稿」的格式把定稿写进 `待提交/`。

## 审稿

先读 `共同维护/设计口味.md`、`规矩/网站排版规则.md`，再读要审的那一章的整个文件（全局视角就从这里来：稿子要和整章现在的内容对照着看）。稿子如果已经在 `待提交/` 里，直接读那个文件。按优先级查：

1. **会让人做错题的问题**：每一步自己重算（行列式、叉积、解方程、代回验算）；前提条件；逻辑方向；和本章〔定义〕〔性质〕矛盾。
2. **和整章不搭**：重复讲了别的站、别的方向已经讲过的东西（应改成一句调用）；用了本章还没讲的工具；「转入方向 m」时方向 m 接不住；术语、记号和本章不一致。
3. **和网站不搭**：`规矩/网站排版规则.md` 里「会原样露出来」的写法；标题格式；一张卡里多个 `####`；⚠️ 前缺 `---`；`$` 不成对。
4. **口味**：知识清单式堆砌、为了全而全的边角料、比喻代替推导、例题没走到意义里的某个分叉。

文风、措辞不挑。没有问题就直说没有。不要输出改好的全文，除非用户让你改交稿文件。

## 交稿

用户说「可以了」以后，在 `待提交/` 里新建一个 `.md`，文件名写清是什么，如 `高数第4章-方向2-建平面与直线的方程.md`。一份文件交一件事；几份可以攒着，Claude Code 能一次接完、一次提交（更省）。格式：

```
---
卡片: calc-vec-coordinates
操作: 追加意义例题
说明: 方向 2：建立平面与直线的方程
审稿: 已审（Antigravity Claude），用户确认
---

<!-- 意义 -->

#### 2. ……（意义 2 全文）

<!-- 例题 -->

#### 例题 2：……（例题 2 全文）
```

- **卡片**：卡片 id（见 `章节/目录.md`）。
- **操作**只有两种：
  - `追加意义例题`：意义接在〔意义〕最后、例题接在〔例题〕最后，两半共用一个新记号（Claude Code 生成）。可以只交其中一段。同一章攒了几份时，按文件名排序依次接上，所以文件名里写上方向号。
  - `替换卡`：再加一行 `记号: xxxx`（章节文件里 `<!-- card:xxxx -->` 的那个 id），下面给 `<!-- 教材 -->`（或 `<!-- 意义 -->`）和 / 或 `<!-- 笔记 -->`（或 `<!-- 例题 -->`）的新全文，整张卡的这一半会被换掉。
- 分段行 `<!-- 意义 -->` 等单独一行；正文里**不要写任何 `<!-- -->` 记号行**，不要反引号、HTML、[cite] 标记。
- 别的改动（删卡、合卡、整节换掉、改结构）不走交稿文件，请用户直接找 Claude Code 说。
