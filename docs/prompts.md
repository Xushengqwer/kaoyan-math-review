# 我写给 AI 的提示词

遇到问题时，按自己的理解写给 AI（主要是 Gemini）的提示词，原样保存，一个字不改。新的往后加。
每条写清：什么时候、在做什么、为什么写。同一件事的几次追加放在一条里，按先后排。

## 1. 意义和例题为什么存在：学完以后会什么

**时间与场合**：2026-10-09 · Antigravity · 第 2 章，开始重构意义和例题之前  
**起因**：AI 生成的 21 个意义和例题，用户没有自己想过，不确定是不是自己要的工具。

```text
我先说一下我想要重构的内容，是意义和例题的部分，我先说一下，我设立意义和例题的初衷，意义和例题是为了，我们逆向去思考，我们学习了上述的定义和性质的内容之后，我们应该会什么？能解决什么样的问题？？
很多时候，我们学习完了也不知道我们会了什么，这是很严重的问题，因为很多时候比如做题，是你自己去根据问题导向，来判断，现在遇到的问题是什么，我有什么样的工具？一定能获取什么样的结论？
这些才是最关键的检验，你认可吗？认可的话，我们先达成共识
然后在说一下，你现在看到的学习资料，这个是AI生成的，有21个意义和例题，说实话，这些我都没自己思考过，因为不是我设计的，问题也没经过我的脑子，我也不确定这个是不是我要的工具，以及是否真的是一个经常会遇到的需求。
我想你和我一起重新设计意义和例题，一个一个意义来，每一个意义都要思考清楚，我们面对的问题是什么，运用什么工具，我们是有可能综合运用我们所学的知识的，然后问题，抽象出来，也是可以分类的。


你的看法呢？我想从意义和例题着手，深入思考，我们这章学完，能获得什么样的能力，解决什么样的问题，应该来说，能获取很多的小能力，解决不同场景的小问题，比如说我可以知道复杂式子的误差是多少了，能估计了，我能知道函数的图像了，等等
```

## 2. 意义不要分太碎：集中，再快速分叉

**时间与场合**：2026-10-09 · Antigravity · 第 2 章，第一个意义动笔前  
**起因**：怕意义拆成知识清单，查起来困难。

```text
肯定按顺序来递进，你既然分了六个大类，我们按顺序来吧，第一个大类，我暂时不知道你的想法是分一个意义来解决呢？还是多个意义呢？
不过我个人建议，最好不要分的太碎，最终变成了知识清单，搜索会非常困难，最好是比较集中，然后根据简单判断，快速分叉到对应的工具中去，这需要我们有更好的逻辑思考能力，更好的抽象能力，提炼能力。

如果可以，你先来弄第一个意义卡，你先只需要出意义卡，然后出对应的例题卡（例题的意义在于演示，否则纯靠意义的文字是不行的）
```

## 3. 说人话：抓住本质，不炫技

**时间与场合**：2026-10-09 · Antigravity · 第 2 章第一个意义的初稿之后  
**起因**：初稿术语多、不直接、没抓住核心。

```text
你其实先聚焦于意义就好了，下一个对话，我可以再看例题，我还能提关于例题的想法。
然后你需要给我的是markdown，可能图片我是不方便加载进去的。
最好是我可以直接复制的markdown。
另外我感觉，你刚刚的意义，写的质量还能再提升一下，有点易读性差了，然后不直接，没有抓住核心的感觉，术语超多，像在炫技。
我们的本质是什么？不就是有些点，不能直接用求导的导函数代入值吗？哪些不能？不能的话，我们采取什么方法？
能得到什么结论？？

我觉得我并没有使用什么网文词，就是朴素的话语，就能把一件事说清楚，反而这是最核心的，做题的时候，我不会去一个一个对术语，就是看这种抽象感觉，你说对不
```

```text
你能帮我重新写一份决策流吗？这是一份从整章的角度来进行的一次决策流思考，是我们当遇到问题的时候，进行的一次思维树思考
```

```text
不行啊，你得注意看下我的格式呀，这个我是不好复制进去的，而且我是建议你尽可能更加在一个文章内完成全部的决策流判断和思考，这样思维更加健壮，能解决更多问题，不预设更多条件
```

```text
很不错，就是有点稍微太长了，大脑的决策流很难存这么长的
```

```text
也重新写一份本章总结吧，整体风格就是口述故事一样，把整个章节以大白话的形式，说明白，其实建立一个简单的抽象类比概念，也是非常重要的
```

## 6. 笔记文风：定义和性质是为了搞懂概念

**时间与场合**：2026-10-10 · Gemini · 重构第 3 章时  
**起因**：笔记读着晦涩，每次都要另开窗口弄清它到底讲了什么。

```text
我感觉想稍微纠一下笔记的文风了， 笔记内容有点晦涩了，我想想快速搞懂核心内容，以及快速温习这个部分的核心概念是什么，但是抓不住，可阅读性有点低。
每次，我其实都需要专门开一个窗口去探究到底讲了什么，其实笔记的内容就是给我们讲清楚这些概念的，使用大白话，讲清楚谁是谁，到底是什么。
更多的细节，比如如何操作，我们可以放到意义和例题当中去，定义和性质，我们是快速搞懂概念，深刻理解概念，不是么，其实理解的深刻，自然很多错误就没有了，这是建立数学直觉的过程，不是让你去死记细节的过程

重写一次吧
```

## 7. 笔记重构：先问到懂，再总结成卡

**时间与场合**：2026-10-11 · AI Studio 新窗口 · 第 3 章〔定义〕〔性质〕笔记  
**起因**：笔记是 AI 生成的，自己并没看懂；要通过反复追问弄懂教材里的概念，再把推敲出的精华写成笔记。Claude 给的开场白是让 Gemini 先讲、讲完停下，不合意图，用户改写成这一版。

```text
附件是我考研数学复习网站高数部分的素材：其他各章的教材，以及第 3 章「一元函数积分学」的〔定义〕〔性质〕（教材 + 笔记）。

这次我们的目的是重构把第 3 章〔定义〕〔性质〕的笔记，写到我真正看懂。

  - 教材基本不动，我目前主要是并不十分理解教材中给出的概念，我的笔记都是AI生成的，我并不是看的非常懂，说明我不仅没懂教材内容，笔记也看不懂
  - 一站一站来（第①站到第⑥站）。
  - 我会追问没懂的细节。我们反复推敲之后，再总结精华成果，把这一张卡的内容重写出来：markdown 原文，放在一个代码块里。
  - 意义和例题这次不碰，等概念都懂了再做。

理解了的话，先说明白，然后我再给你抛出问题，我们来推敲
```
