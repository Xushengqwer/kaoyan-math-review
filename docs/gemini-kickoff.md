# 给 Gemini 的开场白（每章重写时用）

第 3 章（2026-10-11～15）和 Gemini 一起重写时摸出来的做法，提炼成可以反复用的模板。分两段，各在一个新对话里用：先做〔定义〕〔性质〕，全部弄懂以后再做〔意义〕〔例题〕。

**在 Antigravity 里用（2026-10-17 起）**：不用素材包、不用上传附件。在镜像目录里开对话，把下面开场白里的「附件是……」换成「请读 `章节/<科目>/第NN章-….md`」，把 `{learning-method.md …}` 那两处换成「请读 `规矩/学习方法.md`」里对应的代码块（或直接让它去读）。写完、用户说可以以后，按 `README.md`「交稿」一节在 `待提交/` 里出交稿文件。这份文件在镜像的 `共同维护/` 里，用户和 Antigravity 可以直接改，Claude 生成镜像时会抄回仓库留底。

以前在 Gemini 网页版里的用法（仓库里的工具还在）：
- 拼好的成品放在 Downloads，名字是「给Gemini的开场白-高数第N章.md」；`node tools/kickoff.cjs <卡片id>` 生成（学习方法两段直接从 `docs/learning-method.md` 抽，不手抄）。
- 素材包：第一段 `node tools/pack.cjs <卡片id> --only 定义,性质 --deps none`；第二段在同一个对话里补发 `--only 意义,例题 --deps none`。需要前面几章时把 `none` 换成章号。

## 第一段：〔定义〕〔性质〕

```text
附件是我考研数学复习网站{科目}第 {N} 章「{章名}」的〔定义〕〔性质〕（教材 + 笔记），是网站上现在的版本。

这个网站是我自己的复习资料。每张卡分两栏对照着读：左边教材，右边笔记。这一章按「站」组织：{站列表}。这一章的笔记是之前 AI 生成的，我并没有吃透。

这次分两段做：先一站一站重写〔定义〕〔性质〕，把概念弄懂；全部弄懂以后，再另开对话做〔意义〕〔例题〕。

{learning-method.md「给 AI 的版本」代码块}

请你主动帮我梳理每一站、每张卡的定位和核心判断点，不用等我先整理好。我会拿着没懂的地方来问你，我们反复推敲。等我说可以了，再把那张卡写出来，写的时候请照这几条，方便我直接用：

- 教材、笔记分成两个代码块，都是 markdown 原文。
- 卡片标题用 `### `，小节用 `#### `，小点用 `##### `；公式用 $…$ 和 $$…$$；不要用 HTML；不要加 [cite: 1] 这类引用标记。
- 两栏是并排对照的，笔记别比教材长太多。笔记里的计算演示、推导演示、对照表，单独放在教材那个代码块的最后，前面单独一行写：
  `###### 🧮 推导演示：……（和右边笔记对称）`

理解了的话，先简单说说你看完素材的感觉，然后等我提问。
```

## 第二段：〔意义〕〔例题〕

在定义、性质都弄懂之后发。用户会先自己推一遍这一章的主线（骨架先行），再和 Gemini 一起补全。

```text
定义和性质已经推敲完了，现在做〔意义〕〔例题〕。附件是这一章现在的〔意义〕〔例题〕（旧版，AI 生成的，我没细看过，只当参考）。

{learning-method.md「意义和例题怎么推 · 给 AI 的版本」代码块}

写的时候请照这几条：

- 一次只写一个方向：意义 n 和例题 n 各放一个代码块，markdown 原文，不要 HTML，不要 [cite: 1] 这类引用标记。
- 意义：标题「#### n. 方向名：一句话」，下面依次是 🔍 问题、🎯 结论、💡 工具（只写工具名和所属站，公式留在性质卡里）、⚙️ 执行步骤（决策树，小节用 `##### ❶`）、⚠️ 边界与避坑。前提条件写全，走不通时写明转到哪个方向。
- 例题：标题「#### 例题 n：……」，小题用 `#####`。有分叉的步骤写三样：👀 看到什么 → 🔀 有哪几条路、走哪条、为什么、另外几条为什么不走 → ✍️ 动手；走过场的步骤一行带过，不要写成流水账，不要在末尾加一句话总结。例题要把意义 n 的决策树真刀真枪走一遍，至少有一小题走到边界（停手、转方向）。
- 网站上意义下面紧跟例题，满格显示，长度不用和别的对齐。
```
