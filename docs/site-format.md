# 网站排版规则（写稿、审稿时对照）

网站把 markdown 原文直接渲染出来，下面这些写法在网站上有固定的样子。写稿、审稿时照这里查「和网站搭不搭」。权威是 `assets/js/app.js`（`mdHtml`、`emphasisHtml`）和 `assets/css/style.css`，这份是摘要；以后网站改了，Claude 同步改这里。

## 页面结构

- 一章一张「超级卡」，分四节：〔定义〕〔性质〕〔意义〕〔例题〕（有的章还有〔提示〕）。教材里放〔定义〕〔性质〕〔意义〕，笔记里放〔定义〕〔性质〕〔例题〕〔提示〕。
- 〔定义〕〔性质〕按「站」组织（①②③…），两栏对照：左边教材（窄，桌面约 380px），右边笔记（宽，约 704px）。同一张卡左右两半长度要接近（差太多时把笔记里的演示挪到教材末尾）。
- 〔意义〕〔例题〕不挂站，排在所有站后面；不分两栏：意义 n 在上、例题 n 在下，各占满格。
- 手机宽度 375px 时两栏变成上下排。

## 记号行（看不见，但决定结构）

- `<!-- section:定义 -->`、`<!-- station:① -->`、`<!-- group:xxxx -->`、`<!-- card:xxxx -->`：单独一行、后面空一行。
- 小节、站、分组、卡片的边界，和左右（上下）配对，**只认记号**；同一个 card id = 同一张卡的两半（意义 n 和例题 n 共用一个）。
- 卡片编号按位置自动算，原文里写的数字不影响编号。
- 记号由 Claude 用工具加，写稿、交稿时**不要自己写记号行**。

## 标题

- `#### n. 标题`：一张卡的标题（〔定义〕〔性质〕〔意义〕）。编号显示成渐变小圆标。
- `#### 例题 n：标题`：例题卡的标题；一个意义下有两道例题时写 `例题 n-1`、`例题 n-2`。
- `#####`：卡片里的小标题。写成「`##### 话题：一句话`」时，冒号前后会分成两种颜色（话题 + 一句话）。
- `###### 🧮 推导演示：……（和右边笔记对称）`：只在〔定义〕〔性质〕的教材末尾用，显示成大留白 + 向下箭头的过渡横幅。意义、例题里不要用。
- 一张卡里只该有一个 `####` 标题；第二个 `####` 会显示成卡片里的大标题，网站编辑时还会提示「打乱结构」。小节一律用 `#####`。
- 单独一行、整行加粗、以圈号开头的行（如 `**⑤′ 另一种换法：配方法**`）是站名行，会变成站牌。正文里别这样写。

## 强调

- `==文字==`：半高的黄色荧光笔（重点）。用户喜欢，但别满篇都是。
- `**文字**`：同一行里成对才加粗。`**标签**：` 这种「加粗 + 冒号」会显示成彩色小标签。
- 以 🎯 🔑 💡 🚧 ⚠️ 开头的列表条目：整条变成带底色的框（🎯 跟这一节的颜色、🔑💡 金、🚧 橙、⚠️ 红），紧跟的加粗变成框的标题、开头那句加大。其他表情只是一个小徽标，不加框。
- 以 💡 开头的引用块（`> 💡 …`）：金色提示框。
- `---`：分隔线。〔意义〕里「⚠️ 边界与避坑」前面要有一条，不然它看起来像上一步的一部分。

## 公式

- `$…$` 行内、`$$…$$` 独立成行，KaTeX 渲染（自定义宏：`\iddots`、`\centernot`）。每行的 `$` 要成对；从 AI 对话复制时偶尔会截断一行，后面的公式就全错位了。
- 矩阵、行列式（`\begin{vmatrix}`）行内也能用。
- 手机上独立公式要放得下约 300px：长式子用 `aligned` / `cases` 拆行，附加条件写成文字。放不下的会在卡片里横向滚动。

## 会原样露出来的写法（不要用）

- 反引号 `` `…` ``：变成灰底等宽的代码块（用户不喜欢灰色），里面的 `#####` 之类会原样露出来。
- 行首缩进 4 格（不在列表里）：变成代码块。
- HTML 标签。
- AI 引用附件留下的 `[cite: 1]` 这类标记。
- `####` 前面多一个空格：标题认不出来，右侧目录里就没有这一条。

## 其他

- 图片：单独一段 `![图注](assets/images/surfaces/文件.svg)`（第 4 章的曲面、投影示意图），图注里不写 `$`。
- 表格可以用；手机上列多的表会很高，三列以内最好。
- 右侧目录：每站列出〔定义〕〔性质〕的卡片标题；意义、例题在「题型」一组里，意义 n 下面紧跟例题 n。目录里的标题就是 `####` 那一行冒号前后的字，所以标题要能一眼看出这张卡讲什么。
