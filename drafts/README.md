# 草稿

放「要写进网站、但还没写进去」的内容文件：Claude 写的草稿，用户确认后由 Codex 写进网站（流程见 `AGENTS.md` 第 6 节 A）。

- **一个文件就是一条内容的全文**：一条笔记、一张卡的教材、一份决策流或一份本章总结。文件里不加任何头部说明，写进网站时逐字原样。
- **文件名**：`<科目>-<章>-<内容>-v<版本>.md`，例如 `linalg-eigen-summary-v2.md`、`linalg-eigen-card1-book-v1.md`。改了就出新版本号，不覆盖旧版。
- **状态**：用户在任务里说哪个文件、写进哪一条，就是确认了。没被点名的文件都算还在讨论中，不要写进网站。
- **写进网站以后**：文件留着，方便日后用 `tools/verify.cjs` 核对。
- 网站只读 `assets/`，这个目录不影响网站显示。
