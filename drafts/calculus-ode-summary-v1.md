# 第 9 章 常微分方程

**一条主线**：只知道函数的变化规律，反过来把函数求出来：先把问题翻译成方程，再按方程的样子求解。一阶方程想办法变成能直接积分的样子；高阶方程先降阶，降不了的线性方程看解的结构，系数是常数时用指数函数去试。分三层、六站，每一站由上一站引出：

列方程：怎么列方程，解是什么；一阶方程：一阶方程怎么积出来；高阶方程：高阶方程怎么降阶 → 线性方程的解的结构 → 常系数齐次怎么解 → 常系数非齐次怎么解

**一段话说完**：前八章，函数都是给定的，我们求它的极限、导数、积分。实际问题常常反过来：只知道变化的规律，比如放射性物质衰变的速度与剩下的量成正比，要求出量本身。把规律写出来，就是含未知函数导数的方程，叫微分方程。最简单的是 $y' = f(x)$，解就是不定积分，多出一个任意常数；所以 $n$ 阶方程的通解带 $n$ 个任意常数，再用初始条件定下来。一阶方程的办法只有一条：想办法变成能直接积分的样子。变量能分开，就两边各积各的；分不开但只依赖 $\dfrac{y}{x}$，就换元 $u = \dfrac{y}{x}$，让它能分开；一阶线性方程乘上 $e^{\int P\,\mathrm{d}x}$，左边正好是一个乘积的导数，也能直接积；左边本身是某个函数的全微分，通解就是这个函数等于常数。高阶方程先看能不能降成一阶：方程里缺 $y$ 或缺 $x$，令 $y' = p$ 就降一阶。降不了的，最常见的是线性方程：齐次方程的解可以相加、可以乘常数，通解是两个不成比例的解的组合；非齐次方程的通解再加上一个特解，这和线性代数里 $Ax = b$ 的解的结构是同一件事。系数是常数时，找齐次方程的解用 $e^{rx}$ 去试，求导只多出因子 $r$，方程变成关于 $r$ 的二次方程，这是特征方程；找非齐次方程的特解，右端是什么样，就设什么样的特解，碰上特征根就乘 $x$。欧拉方程换元 $x = e^t$ 后，也是常系数方程。

## ① 怎么列方程，解是什么

前八章，函数是给定的；实际问题常常反过来，只知道变化的规律，要找出函数本身。比如放射性物质衰变，速度与剩下的量成正比；一条曲线，每一点处切线的斜率满足某个条件。把变化率写成导数，条件就成了一个含未知函数导数的方程，这就是微分方程；方程里导数的最高阶数叫它的阶。最简单的是 $y' = f(x)$，解就是第 3 章的不定积分，多出一个任意常数。所以解一般带常数：$n$ 阶方程要积 $n$ 次，通解里有 $n$ 个独立的任意常数，再用 $n$ 个初始条件定下来，得到特解。列方程有几个固定的翻译：切线斜率是 $y'$，变化率是对时间的导数，面积、弧长写成变限积分；方程里有变限积分时，两边求导就成了微分方程，初始条件藏在积分上下限相等的那一点。有时题目不要求解出来，只问 $y''(0)$ 之类的值，直接把 $x = 0$ 代进方程就行。

* 通解中独立任意常数的个数 = 方程的阶数；
* 切线在 $y$ 轴上的截距是 $y - xy'$；切线斜率等于 $2x + y$，就是 $y' = 2x + y$；
* 衰减：$\dfrac{\mathrm{d}R}{\mathrm{d}t} = -\lambda R$，$R = R_0e^{-\lambda t}$；
* 积分方程：$f(x) = 2\displaystyle\int_0^x f(t)\,\mathrm{d}t + x^2$ 求导得 $f' = 2f + 2x$，令 $x = 0$ 得 $f(0) = 0$。

## ② 一阶方程怎么积出来

一阶方程 $y' = f(x, y)$ 的办法只有一条：想办法变成能直接积分的样子。最好的情形是变量能分开，$y$ 都在左边、$x$ 都在右边，两边各积各的，这是可分离变量的方程。分不开时，换一个未知函数让它分开：右边只依赖 $\dfrac{y}{x}$ 的齐次方程，令 $u = \dfrac{y}{x}$；右边是 $ax + by + c$ 的函数，令 $u = ax + by + c$。一阶线性方程 $y' + P(x)y = Q(x)$ 分不开，但两边乘上 $e^{\int P\,\mathrm{d}x}$ 以后，左边正好是 $ye^{\int P\,\mathrm{d}x}$ 的导数，于是也能直接积，这就是通解公式；伯努利方程两边除以 $y^n$，换成 $z = y^{1-n}$，就是线性方程。还有一种：方程写成 $P\,\mathrm{d}x + Q\,\mathrm{d}y = 0$，左边恰好是某个函数 $u$ 的全微分，那么 $\mathrm{d}u = 0$，通解就是 $u = C$；判别它、求出 $u$，用的是第 7 章与路径无关的办法。乘 $e^{\int P\,\mathrm{d}x}$ 其实也是在凑全微分，这样的因子叫积分因子。

* 可分离：$\displaystyle\int\dfrac{\mathrm{d}y}{g(y)} = \int f(x)\,\mathrm{d}x + C$，$g(y_0) = 0$ 时 $y = y_0$ 也是解；
* 齐次：令 $u = \dfrac{y}{x}$，化为 $x\dfrac{\mathrm{d}u}{\mathrm{d}x} = \varphi(u) - u$；
* 线性：$y = e^{-\int P\,\mathrm{d}x}\left[\displaystyle\int Qe^{\int P\,\mathrm{d}x}\,\mathrm{d}x + C\right]$；如 $y' + y\tan x = \cos x$ 的通解是 $y = (x + C)\cos x$；
* 全微分：$\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$ 时，通解 $u(x, y) = C$。

## ③ 高阶方程怎么降阶

二阶方程没有一阶那样统一的办法，我们先看能不能降成一阶，再用 ② 的办法。$y'' = f(x)$ 积两次就行。方程里不出现 $y$ 时，把 $y'$ 当成新的未知函数 $p(x)$，$y'' = p'$，方程就是 $p$ 的一阶方程。方程里不出现 $x$ 时，还是令 $y' = p$，但把 $p$ 看成 $y$ 的函数，$y'' = p\dfrac{\mathrm{d}p}{\mathrm{d}y}$，这样方程里只剩 $y$ 和 $p$，也是一阶方程。降阶以后还要再积一次，一共两个常数；题目给了初始条件，第一次积完就把 $C_1$ 定下来，后面会简单很多。

* $y^{(n)} = f(x)$：连续积分 $n$ 次；
* 缺 $y$：令 $y' = p(x)$，$y'' = p'$；
* 缺 $x$：令 $y' = p(y)$，$y'' = p\dfrac{\mathrm{d}p}{\mathrm{d}y}$；
* 例：$(1 + x^2)y'' = 2xy'$，$y(0) = 1$，$y'(0) = 3$：$p = 3(1 + x^2)$，$y = x^3 + 3x + 1$。

## ④ 线性方程的解的结构

降不了阶的方程里，最常见的是线性方程 $y'' + P(x)y' + Q(x)y = f(x)$：$y$ 和它的导数都只以一次的形式出现。线性带来一个好处：右端为 $0$ 的齐次方程，两个解相加、乘常数，仍然是解。所以只要找到两个线性无关的解，即两个不成比例的解，它们的组合 $C_1y_1 + C_2y_2$ 就是通解。非齐次方程的两个解相减，右端抵消，是齐次方程的解；所以非齐次方程的通解，就是它的一个特解加上齐次方程的通解。这和线性代数里 $Ax = b$ 的通解等于一个特解加上 $Ax = 0$ 的通解，是同一件事。右端是几项之和时，各自求特解再相加。剩下两个问题：怎么找齐次方程的两个解，怎么找非齐次方程的一个特解。系数是常数时，这两件事都有固定的办法。

* 齐次：$y_1, y_2$ 线性无关 $\implies$ 通解 $y = C_1y_1 + C_2y_2$；
* 非齐次：通解 $y = Y + y^*$，$Y$ 是齐次方程的通解，$y^*$ 是一个特解；
* 非齐次方程的两个解之差是齐次方程的解；
* 例：$1$、$x$、$x^2$ 是某个二阶非齐次线性方程的解，通解是 $C_1(x - 1) + C_2(x^2 - 1) + 1$。

## ⑤ 常系数齐次怎么解

系数是常数的齐次方程 $y'' + py' + qy = 0$，要找一个函数，它的二阶导数、一阶导数和它自己按常数比例加起来为 $0$，最好求导以后形状不变。指数函数正好是这样：$y = e^{rx}$，求一次导只多一个因子 $r$。代进去，$e^{rx}$ 约掉，剩下 $r^2 + pr + q = 0$，这是特征方程，解微分方程变成了解二次方程。两个不等的实根，给出两个不成比例的解；重根只给出一个，另一个是 $xe^{rx}$；一对共轭复根 $\alpha \pm \mathrm{i}\beta$，用欧拉公式把复指数换成实函数，得到 $e^{\alpha x}\cos\beta x$、$e^{\alpha x}\sin\beta x$。高阶的同理，$k$ 重根带出 $1, x, \cdots, x^{k-1}$ 乘指数。反过来，由通解读出特征根，就能写出方程。

* 不等实根：$y = C_1e^{r_1x} + C_2e^{r_2x}$；重根：$y = (C_1 + C_2x)e^{rx}$；
* 共轭复根 $\alpha \pm \mathrm{i}\beta$：$y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$；
* 例：$y'' - 2y' + 5y = 0$，$r = 1 \pm 2\mathrm{i}$，$y = e^x(C_1\cos 2x + C_2\sin 2x)$；
* 反求：通解 $C_1e^x + C_2e^{-2x}$，特征根 $1$、$-2$，方程是 $y'' + y' - 2y = 0$。

## ⑥ 常系数非齐次怎么解

右端不为 $0$ 时，还要一个特解。右端是多项式、指数、正弦余弦这几类函数时，它们求导以后还是同一类，所以特解就设成和右端同一类的样子，系数待定，代进方程比较系数，这叫待定系数法。只有一个例外：右端的 $e^{\lambda x}$ 恰好是齐次方程的解，即 $\lambda$ 是特征根时，代进去左边是 $0$，配不出右端，这时要乘上 $x$；是重根就乘 $x^2$。右端有 $\cos\omega x$ 或 $\sin\omega x$ 时，看 $\lambda + \mathrm{i}\omega$ 是不是特征根，而且特解里正弦、余弦两项都要设。右端是几类之和，就分开设，再用叠加原理相加。最后，系数不是常数、但每一项里 $x$ 的次数等于导数的阶数，这是欧拉方程：令 $x = e^t$，$x\dfrac{\mathrm{d}y}{\mathrm{d}x}$ 就成了 $\dfrac{\mathrm{d}y}{\mathrm{d}t}$，方程化成常系数的，回到 ⑤ 和这一站。

* 右端 $e^{\lambda x}P_m(x)$：设 $y^* = x^kQ_m(x)e^{\lambda x}$，$k$ 是 $\lambda$ 作为特征根的重数（不是根取 $0$）；
* 右端 $e^{\lambda x}[P_l\cos\omega x + P_n\sin\omega x]$：设 $y^* = x^ke^{\lambda x}[R_m^{(1)}\cos\omega x + R_m^{(2)}\sin\omega x]$，$\lambda + \mathrm{i}\omega$ 是特征根时 $k = 1$；
* 例：$y'' - 5y' + 6y = xe^{2x}$，$2$ 是单根，$y^* = x(ax + b)e^{2x}$，得 $y^* = -\left(\dfrac{x^2}{2} + x\right)e^{2x}$；
* 欧拉方程：$x = e^t$，$xy' = \dfrac{\mathrm{d}y}{\mathrm{d}t}$，$x^2y'' = \dfrac{\mathrm{d}^2y}{\mathrm{d}t^2} - \dfrac{\mathrm{d}y}{\mathrm{d}t}$。
