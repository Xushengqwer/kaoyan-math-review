### 第一步：看题目在问谁

先找题目问的对象，它决定去哪一站：

* **问重积分本身**（用定义或几何意义判断；比较两个重积分的大小；估值；双重和式的极限；区域缩成一点时的极限；被积函数里含这个积分本身）→ **① 曲顶柱体的体积怎么算**
* **在直角坐标下算二重积分**（区域由直线、抛物线等围成；被积函数含绝对值、$\max$、分段；交换积分次序；累次积分的内层积不出）→ **② 怎么化成两次定积分**
* **区域是圆、扇形、圆环，或被积函数含 $x^2 + y^2$**（极坐标计算；直角坐标与极坐标的累次积分互化；给定换元）→ **③ 区域是圆的怎么办**
* **算三重积分**（投影、截面；柱面坐标、球面坐标）→ **④ 三重积分怎么算**
* **区域关于坐标轴、原点、直线 $y = x$ 对称**（含 $\iint x^2\,\mathrm{d}\sigma$ 与 $\iint y^2\,\mathrm{d}\sigma$ 这类比较）→ **⑤ 重积分怎么算更省事**
* **求体积、曲面面积、质量、质心、形心、转动惯量** → **⑥ 什么量能用重积分算**

投影区域怎么求：在第 4 章。曲面的法向量：在第 5 章。重积分化成变限积分以后求导、求极限：在第 3 章 ② 和第 1 章。曲线积分、曲面积分：在第 7 章。

### 第二步：动笔之前，先看能不能直接判断

* **区域对称**：先按 ⑤ 看奇偶，奇的部分直接为 $0$；这一步放在选坐标、定限之前。
* **区域关于 $y = x$ 对称，被积函数里 $x$、$y$ 地位不同**：互换后相加除以 $2$；如 $\iint_D \dfrac{af(x) + bf(y)}{f(x) + f(y)}\,\mathrm{d}\sigma = \dfrac{a + b}{2}\sigma$。
* **比较大小**：区域相同，只比被积函数；被积函数相同且非负，区域大的积分大。
* **被积函数是 $x$、$y$ 的一次式**：用面积和形心直接写出，$\iint_D (ax + by + c)\,\mathrm{d}\sigma = (a\bar{x} + b\bar{y} + c)\sigma$。
* **三重积分的被积函数只含 $z$，截面是圆或椭圆**：先二后一，截面上的积分就是被积函数乘截面面积。
* **内层是 $e^{y^2}$、$e^{-y^2}$、$\dfrac{\sin y}{y}$、$\sin y^2$、$\dfrac{1}{\ln y}$**：原函数不是初等函数，直接交换次序。
* **被积函数里含 $\iint_D f\,\mathrm{d}\sigma$**：它是一个常数，设为 $A$，两边在 $D$ 上积分，解出 $A$。
* **区域缩成一点的极限**：用中值定理，$\lim\limits_{r \to 0}\dfrac{1}{\pi r^2}\iint_{x^2 + y^2 \le r^2} f\,\mathrm{d}\sigma = f(0, 0)$，不必算出积分。

### 第三步：按站计算

* **① 曲顶柱体的体积怎么算**：
  * 比较大小：区域相同，比被积函数；不好比时作差，看差的符号；
  * 估值：求被积函数在区域上的最大值 $M$、最小值 $m$，$m\sigma \le \iint_D f\,\mathrm{d}\sigma \le M\sigma$；
  * 双重和式的极限：提出 $\dfrac{1}{n^2}$，把每一项写成 $f\left(\dfrac{i}{n}, \dfrac{j}{n}\right)$，极限就是 $\iint_{[0, 1] \times [0, 1]} f\,\mathrm{d}\sigma$；$f$ 能拆成 $g(x)h(y)$ 时，拆成两个定积分相乘；
  * 区域缩成一点：用中值定理写成 $f(\xi, \eta)\,\sigma$，$(\xi, \eta)$ 跟着趋于那一点；
  * 积分方程：设 $A = \iint_D f\,\mathrm{d}\sigma$，代回原式，两边在 $D$ 上积分，解出 $A$。
* **② 怎么化成两次定积分**：
  * 画出区域，求出边界的交点；
  * 选次序：竖线穿过区域时，上下边界不换式子，就先 $y$ 后 $x$；否则试横线；两种都要换式子，就分块；
  * 被积函数含绝对值、$\max$、$\min$、符号函数：用使里面等于 $0$ 的曲线（如 $|y - x^2|$ 用 $y = x^2$）把区域分开，每块去掉绝对值；
  * 交换次序：由上下限写出区域的不等式，画图，按另一型重写；
  * 内层积不出：先交换次序，或换成极坐标；
  * 定积分的被积函数是变限积分（如 $\int_0^1 f(x)\,\mathrm{d}x$，$f(x) = \int_x^1 g(t)\,\mathrm{d}t$）：写成二重积分，交换次序。
* **③ 区域是圆的怎么办**：
  * 代入 $x = r\cos\theta$，$y = r\sin\theta$，面积元乘 $r$；
  * 边界化成极坐标：$x^2 + y^2 = R^2$ 是 $r = R$；$x^2 + y^2 = 2ax$ 是 $r = 2a\cos\theta$；$x^2 + y^2 = 2ay$ 是 $r = 2a\sin\theta$；直线 $x = a$ 是 $r = \dfrac{a}{\cos\theta}$；直线 $y = x$ 是 $\theta = \dfrac{\pi}{4}$；
  * 定限：先从图上读出 $\theta$ 的范围，再对每个 $\theta$ 看射线从哪进、从哪出；
  * 直角坐标与极坐标互化：先由上下限画出区域，再按另一种坐标重写；
  * 被积函数只含 $x^2 + y^2$、区域是以原点为心的圆：$\iint_{x^2 + y^2 \le t^2} f(x^2 + y^2)\,\mathrm{d}\sigma = 2\pi\int_0^t f(r^2)r\,\mathrm{d}r$，化成变限积分；
  * 一般换元（如 $u = x + y$，$v = x - y$）：先求 $J$，面积元乘 $|J|$；新区域由旧边界逐条代换得到。
* **④ 三重积分怎么算**：
  * 先一后二：求 $\Omega$ 在 $xOy$ 面上的投影 $D_{xy}$，找出下曲面 $z_1$、上曲面 $z_2$，先对 $z$ 积分；
  * 先二后一：被积函数只含 $z$、截面面积好算时用；$z$ 从立体的最低处到最高处，截面 $D_z$ 随 $z$ 变；
  * 柱面坐标：$\Omega$ 由圆柱面、旋转抛物面、圆锥面围成，或被积函数含 $x^2 + y^2$；投影用极坐标，$z$ 照先一后二，体积元乘 $\rho$；
  * 球面坐标：$\Omega$ 由球面、圆锥面围成，或被积函数含 $x^2 + y^2 + z^2$，体积元乘 $r^2\sin\varphi$；
  * 边界化成球面坐标：$x^2 + y^2 + z^2 = R^2$ 是 $r = R$；$x^2 + y^2 + z^2 = 2az$ 是 $r = 2a\cos\varphi$；$z = \sqrt{x^2 + y^2}$ 是 $\varphi = \dfrac{\pi}{4}$。
* **⑤ 重积分怎么算更省事**：
  * 奇偶：区域关于 $y$ 轴对称，看被积函数关于 $x$ 的奇偶；关于 $x$ 轴对称，看 $y$；
  * 被积函数拆项：拆成奇、偶几部分，奇的部分直接为 $0$；如单位圆上 $(x + y)^2$ 的积分，等于 $x^2 + y^2$ 的积分；
  * 区域本身不对称：用一条曲线把它分成几块，让每块各自对称；
  * 轮换：区域关于 $y = x$ 对称时，$\iint_D f(x, y)\,\mathrm{d}\sigma = \iint_D f(y, x)\,\mathrm{d}\sigma$，两式相加除以 $2$；
  * 三重：关于坐标面对称，看对应变量的奇偶；$x, y, z$ 地位相同时，$\iiint_\Omega x^2\,\mathrm{d}v = \dfrac{1}{3}\iiint_\Omega (x^2 + y^2 + z^2)\,\mathrm{d}v$，再用球面坐标。
* **⑥ 什么量能用重积分算**：
  * 体积：$\iint_D (f - g)\,\mathrm{d}\sigma$，$D$ 由两曲面交线的投影围成；或 $\iiint_\Omega \mathrm{d}v$；
  * 曲面面积：曲面写成 $z = f(x, y)$，求投影 $D_{xy}$，积 $\sqrt{1 + f_x^2 + f_y^2}$；写不成时，向别的坐标面投影；
  * 质量、质心、转动惯量：写出权 $\mu$、$x\mu$、$d^2\mu$；$d$ 是到转轴的距离，对 $x$ 轴，平面上 $d^2 = y^2$，空间里 $d^2 = y^2 + z^2$；
  * 质心：区域和密度都对称时，对称轴上的那个坐标直接写出；
  * 形心反用：$\iint_D x\,\mathrm{d}\sigma = \bar{x}\sigma$，区域是圆、矩形、三角形时，形心直接写出。

### 第四步：读结论

* **① 曲顶柱体的体积怎么算**：
  * **比较大小**：$f \le g$，积分也 $\le$；$f \ge 0$ 时，区域越大，积分越大。
  * **和式极限**：$\dfrac{1}{n^2}$ 和 $\dfrac{i}{n}$、$\dfrac{j}{n}$ 都凑齐，才是 $[0, 1] \times [0, 1]$ 上的二重积分。
* **② 怎么化成两次定积分**：
  * **交换次序**：换前换后积分值相同；区域写对的标志是两种次序画出的是同一个图。
* **⑤ 重积分怎么算更省事**：
  * **奇偶对称**：区域和被积函数要配对，区域关于 $y$ 轴对称，看的是 $x$ 的奇偶。
  * **轮换**：要求区域关于 $y = x$ 对称；区域不对称时，不能互换。
* **⑥ 什么量能用重积分算**：
  * **体积、面积、质量、转动惯量**：都是正数；算出负数，检查上下限和 $f - g$ 的顺序。
  * **质心**：区域和密度都对称时，质心在对称轴上。

---

### 第五步：算完之后

* **自查**：
  * 交换次序、坐标互化：两种写法各画一次图，应是同一个区域；
  * 极坐标定限：把被积函数换成 $1$，算出的面积应等于区域的面积；
  * 三重积分定限：把被积函数换成 $1$，算出的体积应等于立体的体积；
  * 估值：结果应落在 $m\sigma$ 与 $M\sigma$ 之间；
  * 用对称得出 $0$ 的：再确认一次区域和变量的配对。
* **交卷前检查**：
  * 极坐标乘了 $r$，柱面坐标乘了 $\rho$，球面坐标乘了 $r^2\sin\varphi$；
  * 换元乘了 $|J|$，取了绝对值；
  * 内层上下限只含外层变量，外层上下限是常数；
  * 分块以后，每一块的上下限都重新定过；
  * 圆 $x^2 + y^2 = 2ax$（$a > 0$）的 $\theta$ 取 $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$；
  * 曲面面积积的是 $\sqrt{1 + f_x^2 + f_y^2}$，不是 $f$ 本身；
  * 转动惯量里是到轴距离的平方。
