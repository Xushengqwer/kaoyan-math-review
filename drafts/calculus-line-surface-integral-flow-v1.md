### 第一步：看题目在问谁

先找题目问的对象，它决定去哪一站：

* **问对弧长、对面积的积分**（第一类曲线积分、第一类曲面积分；曲线、曲面形状物体的质量、质心、形心、转动惯量、引力；弧长）→ **① 弯的线、弯的面上怎么求总量**
* **算不闭曲线上的第二类曲线积分**（$\displaystyle\int_L P\,\mathrm{d}x + Q\,\mathrm{d}y$；空间曲线上的 $\displaystyle\int_\Gamma P\,\mathrm{d}x + Q\,\mathrm{d}y + R\,\mathrm{d}z$；两类曲线积分互化；变力做功）→ **② 沿着路走，力做了多少功**
* **平面上沿闭曲线的第二类曲线积分**（格林公式；补线；挖奇点；用曲线积分求面积；沿外法线方向的积分）→ **③ 绕一圈的积分，换成里面的二重积分**
* **问与路径无关、全微分、原函数**（判断与路径无关；求 $u$；已知与路径无关，求未知函数；沿任意闭曲线积分为 $0$ 的条件）→ **④ 什么时候只看起点和终点**
* **算不闭曲面上的第二类曲面积分**（$\displaystyle\iint_\Sigma P\,\mathrm{d}y\,\mathrm{d}z + Q\,\mathrm{d}z\,\mathrm{d}x + R\,\mathrm{d}x\,\mathrm{d}y$；两类曲面积分互化；流量）→ **⑤ 流过一张曲面的量**
* **闭曲面上的第二类曲面积分、空间闭曲线上的第二类曲线积分**（高斯公式；补面；挖奇点；斯托克斯公式；求散度、旋度、通量、环流量）→ **⑥ 闭曲面和空间曲线**

弧微分：在第 2 章。投影区域：在第 4 章。曲面的法向量、曲线的切向量、梯度：在第 5 章。曲面面积元、重积分的对称性、质心、转动惯量、引力：在第 6 章。全微分方程 $P\,\mathrm{d}x + Q\,\mathrm{d}y = 0$：在第 9 章，其中求 $u$ 的办法在 ④。

### 第二步：动笔之前，先看能不能直接判断

* **第一类积分，被积函数能用方程化简**：先代入；如球面 $x^2 + y^2 + z^2 = a^2$ 上，$f(x^2 + y^2 + z^2)$ 就是常数 $f(a^2)$。
* **第一类积分，曲线、曲面对称**：先按重积分的办法看奇偶，奇的部分直接为 $0$；$x, y, z$ 互换后曲线（曲面）不变时，用轮换，如 $\displaystyle\oint_\Gamma x^2\,\mathrm{d}s = \dfrac{1}{3}\oint_\Gamma (x^2 + y^2 + z^2)\,\mathrm{d}s$。
* **第二类曲线积分，先算 $\dfrac{\partial Q}{\partial x} - \dfrac{\partial P}{\partial y}$**：
  * 处处为 $0$、区域里没有洞：不闭就按 ④ 换路径或求 $u$；闭曲线上积分直接为 $0$；
  * 是常数 $k$：闭曲线上的积分是 $k$ 乘区域面积；
  * 为 $0$，但原点等处无定义：按 ③ 挖奇点。
* **被积函数的分母是 $x^2 + y^2$、$x^2 + y^2 + z^2$ 的幂**：先把曲线、曲面的方程代入分母；代入后分母成了常数，奇点就没了。
* **第二类曲面积分，先算散度 $P_x + Q_y + R_z$**：散度简单（常数，或只含一个变量），用高斯公式，不闭就补面。
* **第二类曲面积分，曲面垂直于某个坐标面**：对应的那一项为 $0$；如圆柱面 $x^2 + y^2 = 1$ 上，$\displaystyle\iint_\Sigma R\,\mathrm{d}x\,\mathrm{d}y = 0$。
* **第二类曲面积分的对称**：与第一类相反，曲面关于 $xOy$ 面对称、两半取相反的侧时，$R$ 关于 $z$ 是偶函数，$\displaystyle\iint_\Sigma R\,\mathrm{d}x\,\mathrm{d}y = 0$。
* **空间闭曲线是平面与曲面的交线**：用斯托克斯公式，取那块平面作 $\Sigma$，法向量是常向量。

### 第三步：按站计算

* **① 弯的线、弯的面上怎么求总量**：
  * 第一类曲线积分：写出参数式，$\mathrm{d}s = \sqrt{x'^2(t) + y'^2(t)}\,\mathrm{d}t$（空间曲线加 $z'^2(t)$），化成定积分，下限小于上限；
  * 曲线是 $y = y(x)$：$\mathrm{d}s = \sqrt{1 + y'^2}\,\mathrm{d}x$；曲线是 $r = r(\theta)$：$\mathrm{d}s = \sqrt{r^2 + r'^2}\,\mathrm{d}\theta$；
  * 空间曲线是两张曲面的交线：先用对称、轮换，再参数化；交线在平面上时，常是一个圆，长度直接写出；
  * 第一类曲面积分：曲面写成 $z = z(x, y)$，求投影 $D_{xy}$，$\mathrm{d}S = \sqrt{1 + z_x^2 + z_y^2}\,\mathrm{d}x\,\mathrm{d}y$，把 $z$ 代入被积函数；
  * 曲面是 $F(x, y, z) = 0$：$\mathrm{d}S = \dfrac{\sqrt{F_x^2 + F_y^2 + F_z^2}}{|F_z|}\,\mathrm{d}x\,\mathrm{d}y$；球面 $x^2 + y^2 + z^2 = a^2$ 上 $\mathrm{d}S = \dfrac{a}{|z|}\,\mathrm{d}x\,\mathrm{d}y$；
  * 曲面分上下两片、或由几张曲面拼成：分开投影，再相加；
  * 质量、质心、转动惯量、引力：写出权，把重积分的 $\mathrm{d}\sigma$、$\mathrm{d}v$ 换成 $\mathrm{d}s$、$\mathrm{d}S$。
* **② 沿着路走，力做了多少功**：
  * 写出参数式，标出起点、终点对应的参数值；起点的值放下限，终点的值放上限，不管大小；
  * 把 $x, y$ 及 $\mathrm{d}x = x'(t)\,\mathrm{d}t$、$\mathrm{d}y = y'(t)\,\mathrm{d}t$ 代入；
  * 曲线是 $y = y(x)$：以 $x$ 为参数；曲线是 $x = x(y)$：以 $y$ 为参数；
  * 曲线是折线：分段，每段各写参数；平行于 $x$ 轴的一段上 $\mathrm{d}y = 0$；
  * 空间曲线是交线：用柱面坐标、三角函数写出参数式，如 $x^2 + y^2 = 1$ 上 $x = \cos t$，$y = \sin t$，$z$ 由另一个方程解出；方向按题目说的「从哪一侧看去逆时针」定出 $t$ 增加还是减少；
  * 变力做功：力 $\boldsymbol{F} = (P, Q, R)$，功 $= \displaystyle\int_\Gamma P\,\mathrm{d}x + Q\,\mathrm{d}y + R\,\mathrm{d}z$。
* **③ 绕一圈的积分，换成里面的二重积分**：
  * 查三件事：闭不闭；正向（区域在左边）；$P$、$Q$ 在区域里偏导数连续；
  * 都满足：算 $\dfrac{\partial Q}{\partial x} - \dfrac{\partial P}{\partial y}$，在 $D$ 上作二重积分；顺时针就加负号；
  * 不闭：补一段线（常用平行于坐标轴的线段，或圆弧），让它和原曲线围成区域；补的那段单独算，再减掉；
  * 区域里有奇点，且奇点以外 $\dfrac{\partial Q}{\partial x} = \dfrac{\partial P}{\partial y}$：作一条围住奇点的小曲线 $l$，形状按分母选（分母 $x^2 + y^2$ 取圆，分母 $4x^2 + y^2$ 取椭圆 $4x^2 + y^2 = \varepsilon^2$），原积分等于绕 $l$ 同向的积分，在 $l$ 上把分母代掉再算；
  * 求面积：$A = \dfrac{1}{2}\displaystyle\oint_L x\,\mathrm{d}y - y\,\mathrm{d}x$，曲线是参数式时最方便；
  * 沿外法线方向的积分（如 $\displaystyle\oint_L \dfrac{\partial u}{\partial \boldsymbol{n}}\,\mathrm{d}s$）：换成 $\displaystyle\iint_D (P_x + Q_y)\,\mathrm{d}\sigma$。
* **④ 什么时候只看起点和终点**：
  * 判断：区域单连通，且 $\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$ 处处成立；
  * 计算：改走平行于坐标轴的折线，或求出 $u$，算 $u(B) - u(A)$；
  * 求 $u$：沿折线，$u(x, y) = \displaystyle\int_{x_0}^{x} P(x, y_0)\,\mathrm{d}x + \int_{y_0}^{y} Q(x, y)\,\mathrm{d}y$，起点常取原点；原点处无定义时，换一个点；
  * 求 $u$ 的另一种办法：$u = \displaystyle\int P\,\mathrm{d}x + \varphi(y)$，再由 $u_y = Q$ 定出 $\varphi(y)$；或把 $P\,\mathrm{d}x + Q\,\mathrm{d}y$ 分组凑成全微分；
  * 已知与路径无关，求未知函数：列 $\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$，解出未知函数（常是一个微分方程）；
  * 有洞的区域：$\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$ 处处成立时，绕洞一圈的积分都相等，不绕洞的为 $0$。
* **⑤ 流过一张曲面的量**：
  * 分面投影：$\displaystyle\iint_\Sigma R\,\mathrm{d}x\,\mathrm{d}y$ 投到 $xOy$ 面，$z$ 用曲面方程代入，上侧取正，下侧取负；$P\,\mathrm{d}y\,\mathrm{d}z$ 投到 $yOz$ 面，前侧取正；$Q\,\mathrm{d}z\,\mathrm{d}x$ 投到 $zOx$ 面，右侧取正；
  * 合一投影：曲面是 $z = z(x, y)$ 时，三项一起投到 $xOy$ 面，被积函数是 $-Pz_x - Qz_y + R$，上侧取正、下侧取负；
  * 两类互化：$\mathrm{d}y\,\mathrm{d}z = \cos\alpha\,\mathrm{d}S$，$\mathrm{d}z\,\mathrm{d}x = \cos\beta\,\mathrm{d}S$，$\mathrm{d}x\,\mathrm{d}y = \cos\gamma\,\mathrm{d}S$，$(\cos\alpha, \cos\beta, \cos\gamma)$ 是所取一侧的单位法向量；
  * 曲面分几片：每片单独定侧、单独投影，再相加。
* **⑥ 闭曲面和空间曲线**：
  * 高斯：查曲面闭不闭、取外侧还是内侧、$P, Q, R$ 在立体里偏导数连续；外侧直接用，内侧加负号；
  * 不闭：补平行于坐标面的平面（如 $z = 0$ 或 $z = h$），使它们围成立体；补的面单独算，常因 $\mathrm{d}z = 0$ 只剩一项，再减掉；
  * 立体里有奇点（分母为 $0$ 的点）：先把曲面方程代入分母；代不掉，用一个小球面（或按分母选的小椭球面）把奇点挖掉，原积分等于穿出小曲面的通量；
  * 斯托克斯：取以 $\Gamma$ 为边界、好算的曲面 $\Sigma$（常取 $\Gamma$ 所在的平面），侧按右手法则定；用第一类形式，把行列式第一行换成平面的单位法向量 $(\cos\alpha, \cos\beta, \cos\gamma)$；
  * 散度、旋度：$\operatorname{div}\boldsymbol{A} = P_x + Q_y + R_z$；$\operatorname{rot}\boldsymbol{A}$ 按三阶行列式展开；
  * 空间曲线积分与路径无关：$\operatorname{rot}\boldsymbol{A} = \boldsymbol{0}$，求 $u$ 沿平行于坐标轴的三段折线积分。

### 第四步：读结论

* **① 弯的线、弯的面上怎么求总量**：
  * **第一类积分**：被积函数为正时，结果是正数；与曲线方向、曲面的侧都无关。
* **② 沿着路走，力做了多少功**：
  * **功**：结果可正可负；为负，表示力总体上阻碍运动。
* **③ 绕一圈的积分，换成里面的二重积分**：
  * **挖奇点**：绕奇点一圈的积分，与曲线的形状、大小无关，只与绕的方向有关；不围住奇点，积分为 $0$。
* **④ 什么时候只看起点和终点**：
  * **原函数**：$u$ 不唯一，相差一个常数；写答案时加 $C$，或说明取的是哪一个。
* **⑤ 流过一张曲面的量**：
  * **流量**：结果为负，表示实际是从另一侧流过来的。
* **⑥ 闭曲面和空间曲线**：
  * **通量**：$\operatorname{div}\boldsymbol{A} = 0$ 的区域里，穿出包围同一奇点的闭曲面的通量都相同；不围住奇点，通量为 $0$。
  * **散度、旋度**：散度是数，旋度是向量。

### 第五步：算完之后

* **自查**：
  * 第一类积分：把被积函数换成 $1$，应得弧长、面积；
  * 第二类曲线积分：起点、终点对应的参数值放对了上下限；
  * 格林、高斯算出的结果，用一个简单的特例（如区域是圆、立体是球）验算一次；
  * 补线、补面：补的那部分减掉了，且它的方向（侧）与围成闭曲线（闭曲面）时所取的一致；
  * 用对称得出 $0$ 的：再确认一次是第一类还是第二类。
* **交卷前检查**：
  * 第一类曲线积分的下限小于上限；第二类曲线积分的下限对应起点；
  * 格林公式里是 $\dfrac{\partial Q}{\partial x} - \dfrac{\partial P}{\partial y}$，不是反过来；
  * 闭曲线顺时针、闭曲面取内侧，加了负号；
  * 用格林、高斯之前，查过区域里没有奇点；
  * $\mathrm{d}S$ 乘了 $\sqrt{1 + z_x^2 + z_y^2}$，$\mathrm{d}x\,\mathrm{d}y$ 没有乘；
  * 第二类曲面积分投影时，$z$ 用曲面方程代入了，且按侧定了正负号；
  * 斯托克斯：$\Gamma$ 的方向与 $\Sigma$ 的侧符合右手法则。
