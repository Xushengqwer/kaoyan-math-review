### 〔定义〕

**本卡主线**：只知道函数的变化规律，反过来把函数求出来：先把问题翻译成方程，再按方程的样子求解。整张卡分三层、六站，每一站由上一站引出：
* **列方程**：
  * **① 怎么列方程，解是什么**：把变化规律写成含导数的方程；$n$ 阶方程的通解带 $n$ 个任意常数，初始条件定出特解；
* **一阶方程**：
  * **② 一阶方程怎么积出来**：想办法变成能直接积分的样子：分离变量、换元、乘积分因子、认出全微分；
* **高阶方程**：
  * **③ 高阶方程怎么降阶**：缺 $y$ 或缺 $x$，令 $y' = p$，降成一阶方程；
  * **④ 线性方程的解的结构**：齐次方程的解可以叠加；非齐次方程的通解是一个特解加上齐次方程的通解；
  * **⑤ 常系数齐次怎么解**：用 $e^{rx}$ 去试，解方程变成解特征方程；
  * **⑥ 常系数非齐次怎么解**：右端是什么样，特解就设什么样，碰上特征根乘 $x$；欧拉方程换元后也是常系数方程；
* **依赖**：导数、泰勒公式（第 2 章）；不定积分、变限积分求导、弧长与面积（第 3 章）；与路径无关的条件、求原函数（第 7 章）；幂级数的和函数（第 8 章）。

**① 怎么列方程，解是什么**

前八章，函数是给定的；实际问题常常反过来，只知道变化的规律，要找出函数本身。比如放射性物质衰变，速度与剩下的量成正比；一条曲线，每一点处切线的斜率满足某个条件。把变化率写成导数，条件就成了一个含未知函数导数的方程，这就是微分方程。最简单的是 $y' = f(x)$，解就是不定积分，多出一个任意常数；所以 $n$ 阶方程要积 $n$ 次，通解里有 $n$ 个独立的任意常数，再用 $n$ 个初始条件定下来。列方程有几个固定的翻译：切线斜率是 $y'$，变化率是对时间的导数，面积、弧长写成变限积分；方程里有变限积分时，两边求导就成了微分方程。

#### 1. 微分方程与阶
* **微分方程**：含有未知函数的导数（或微分）的方程；未知函数是一元函数时，称为==常微分方程==；
* **阶**：方程中未知函数的最高阶导数的阶数，称为微分方程的==阶==。

#### 2. 解、通解与特解
- **解**：代入方程后使其成为恒等式的函数，称为方程的==解==；
- **通解**：含有独立的任意常数、且任意常数的个数==等于方程的阶数==的解；
- **特解**：确定了通解中任意常数后得到的解。

#### 3. 初始条件与初值问题
用来确定通解中任意常数的条件称为==初始条件==，如 $y\big|_{x = x_0} = y_0$，$y'\big|_{x = x_0} = y_1$；求微分方程满足初始条件的特解的问题称为==初值问题==。

**② 一阶方程怎么积出来**

一阶方程 $y' = f(x, y)$ 的办法只有一条：想办法变成能直接积分的样子。最好的情形是变量能分开，$y$ 都在左边、$x$ 都在右边，两边各积各的。分不开时，换一个未知函数让它分开：右边只依赖 $\dfrac{y}{x}$，令 $u = \dfrac{y}{x}$；右边是 $ax + by + c$ 的函数，令 $u = ax + by + c$。一阶线性方程分不开，但两边乘上 $e^{\int P\,\mathrm{d}x}$ 以后，左边正好是 $ye^{\int P\,\mathrm{d}x}$ 的导数，也能直接积；伯努利方程换成 $z = y^{1-n}$，就是线性方程。方程写成 $P\,\mathrm{d}x + Q\,\mathrm{d}y = 0$ 时，如果左边恰好是某个函数 $u$ 的全微分，通解就是 $u = C$。乘 $e^{\int P\,\mathrm{d}x}$ 其实也是在凑全微分，这样的因子叫积分因子。

#### 1. 可分离变量的方程
能写成
$$\dfrac{\mathrm{d}y}{\mathrm{d}x} = f(x)g(y)$$

的一阶方程，称为==可分离变量的方程==。

#### 2. 齐次方程
能写成
$$\dfrac{\mathrm{d}y}{\mathrm{d}x} = \varphi\left(\dfrac{y}{x}\right)$$

的一阶方程，称为==齐次方程==。

#### 3. 一阶线性方程
$$\dfrac{\mathrm{d}y}{\mathrm{d}x} + P(x)y = Q(x)$$

称为==一阶线性微分方程==（$y$ 与 $y'$ 都是一次的）：
- **齐次**：$Q(x) \equiv 0$；
- **非齐次**：$Q(x) \not\equiv 0$。

#### 4. 伯努利方程
$$\dfrac{\mathrm{d}y}{\mathrm{d}x} + P(x)y = Q(x)y^n \quad (n \neq 0, 1)$$

称为==伯努利方程==；$n = 0$ 或 $1$ 时它就是线性方程。

#### 5. 全微分方程与积分因子
* **全微分方程**：若方程 $P(x, y)\,\mathrm{d}x + Q(x, y)\,\mathrm{d}y = 0$ 的左端恰是某函数 $u(x, y)$ 的全微分，即 $\mathrm{d}u = P\,\mathrm{d}x + Q\,\mathrm{d}y$，则称它为==全微分方程==；
* **积分因子**：若存在函数 $\mu(x, y) \neq 0$，使 $\mu P\,\mathrm{d}x + \mu Q\,\mathrm{d}y = 0$ 成为全微分方程，则称 $\mu(x, y)$ 为原方程的==积分因子==。

**③ 高阶方程怎么降阶**

二阶方程没有一阶那样统一的办法，我们先看能不能降成一阶，再用 ② 的办法。$y'' = f(x)$ 积两次就行。方程里不出现 $y$ 时，把 $y'$ 当成新的未知函数 $p(x)$，$y'' = p'$，方程就是 $p$ 的一阶方程。方程里不出现 $x$ 时，还是令 $y' = p$，但把 $p$ 看成 $y$ 的函数，$y'' = p\dfrac{\mathrm{d}p}{\mathrm{d}y}$，方程里只剩 $y$ 和 $p$，也是一阶方程。题目给了初始条件，第一次积完就把 $C_1$ 定下来，后面会简单很多。

#### 1. 可降阶的方程
* **$y^{(n)} = f(x)$ 型**：右端只含 $x$；
* **$y'' = f(x, y')$ 型**：不显含未知函数 $y$；
* **$y'' = f(y, y')$ 型**：不显含自变量 $x$。

**④ 线性方程的解的结构**

降不了阶的方程里，最常见的是线性方程：$y$ 和它的各阶导数都只以一次的形式出现。线性带来一个好处：右端为 $0$ 的齐次方程，两个解相加、乘常数，仍然是解。所以只要找到两个不成比例的解，它们的组合就是通解。非齐次方程的两个解相减，右端抵消，是齐次方程的解；所以非齐次方程的通解，是它的一个特解加上齐次方程的通解，这和线性代数里 $Ax = b$ 的解的结构是同一件事。剩下两个问题：怎么找齐次方程的两个解，怎么找非齐次方程的一个特解；系数是常数时，这两件事都有固定的办法。

#### 1. 二阶线性方程
$$y'' + P(x)y' + Q(x)y = f(x)$$

称为==二阶线性微分方程==，$f(x)$ 称为==自由项==：
- **齐次**：$f(x) \equiv 0$；
- **非齐次**：$f(x) \not\equiv 0$；把 $f(x)$ 换成 $0$ 得到的方程，称为它对应的齐次方程；
- **$n$ 阶**：$y^{(n)} + a_1(x)y^{(n-1)} + \cdots + a_n(x)y = f(x)$ 同理。

#### 2. 函数组的线性相关与线性无关
设 $y_1(x), \cdots, y_n(x)$ 定义在区间 $I$ 上，若存在==不全为零==的常数 $k_1, \cdots, k_n$，使在 $I$ 上
$$k_1y_1 + k_2y_2 + \cdots + k_ny_n \equiv 0$$

则称这组函数在 $I$ 上==线性相关==，否则称==线性无关==。
- **两个函数**：$y_1, y_2$ 线性无关 $\iff \dfrac{y_1}{y_2}$ 在 $I$ 上不恒为常数。

**⑤ 常系数齐次怎么解**

系数是常数的齐次方程 $y'' + py' + qy = 0$，要找一个函数，它的二阶导数、一阶导数和它自己按常数比例加起来为 $0$，最好求导以后形状不变。指数函数正好是这样：$y = e^{rx}$，求一次导只多一个因子 $r$。代进去，$e^{rx}$ 约掉，剩下 $r^2 + pr + q = 0$，解微分方程变成了解二次方程。两个不等的实根，给出两个不成比例的解；重根只给出一个，另一个是 $xe^{rx}$；一对共轭复根 $\alpha \pm \mathrm{i}\beta$，用欧拉公式把复指数换成实函数。高阶的同理。

#### 1. 常系数线性方程
$$y'' + py' + qy = f(x) \quad (p, q \text{ 为常数})$$

称为==二阶常系数线性微分方程==；$n$ 阶的 $y^{(n)} + p_1y^{(n-1)} + \cdots + p_ny = f(x)$（$p_1, \cdots, p_n$ 为常数）同理。

#### 2. 特征方程与特征根
把 $y^{(k)}$ 换成 $r^k$ 得到的代数方程
$$r^2 + pr + q = 0$$

称为 $y'' + py' + qy = 0$ 的==特征方程==，它的根称为==特征根==；$n$ 阶时特征方程为 $r^n + p_1r^{n-1} + \cdots + p_n = 0$。

**⑥ 常系数非齐次怎么解**

右端不为 $0$ 时，还要一个特解。右端是多项式、指数、正弦余弦这几类函数时，它们求导以后还是同一类，所以特解就设成和右端同一类的样子，系数待定，代进方程比较系数，这叫待定系数法。只有一个例外：右端的 $e^{\lambda x}$ 恰好是齐次方程的解，即 $\lambda$ 是特征根时，代进去左边是 $0$，配不出右端，这时要乘上 $x$；是重根就乘 $x^2$。右端有 $\cos\omega x$ 或 $\sin\omega x$ 时，看 $\lambda + \mathrm{i}\omega$ 是不是特征根，而且正弦、余弦两项都要设。右端是几类之和，就分开设，再相加。系数不是常数、但每一项里 $x$ 的次数等于导数的阶数，这是欧拉方程：令 $x = e^t$，就化成常系数方程。

#### 1. 两类自由项
考研只考下面两类自由项（$P_m(x)$ 表示 $m$ 次多项式）：
* **指数乘多项式**：$f(x) = e^{\lambda x}P_m(x)$，多项式是 $\lambda = 0$ 的情形；
* **再乘正弦余弦**：$f(x) = e^{\lambda x}[P_l(x)\cos\omega x + P_n(x)\sin\omega x]$。

#### 2. 欧拉方程
形如
$$\begin{aligned} & x^ny^{(n)} + p_1x^{n-1}y^{(n-1)} + \cdots \\ & + p_{n-1}xy' + p_ny = f(x) \end{aligned}$$

（$p_1, \cdots, p_n$ 为常数）的方程称为==欧拉方程==，其特点是各项中 $x$ 的幂次与导数的阶数相同。

### 〔性质〕

**① 怎么列方程，解是什么**

#### 1. 一阶方程解的存在唯一性
设 $f(x, y)$ 及 $\dfrac{\partial f}{\partial y}$ 在矩形区域 $|x - x_0| \le a$，$|y - y_0| \le b$ 上连续，则初值问题
$$y' = f(x, y), \quad y(x_0) = y_0$$

在 $x_0$ 的某邻域内存在唯一解。
* **几何意义**：过区域内每一点，恰有一条积分曲线；两条积分曲线不会相交。

#### 2. 列方程：几何问题
设曲线为 $y = y(x)$，$(x, y)$ 是曲线上任一点：
- **切线**：$Y - y = y'(X - x)$；它在 $y$ 轴上的截距为 $y - xy'$，在 $x$ 轴上的截距为 $x - \dfrac{y}{y'}$；
- **法线**：$Y - y = -\dfrac{1}{y'}(X - x)$；它与 $x$ 轴交点的横坐标为 $x + yy'$；
- **面积、弧长**：写成变限积分，如曲线在 $[a, x]$ 上的弧长 $\displaystyle\int_a^x \sqrt{1 + y'^2(t)}\,\mathrm{d}t$（第 3 章），再对 $x$ 求导；
- **初始条件**：曲线过的已知点。

#### 3. 列方程：物理问题
- **变化率**：量 $y(t)$ 的变化率是 $\dfrac{\mathrm{d}y}{\mathrm{d}t}$；「与 $y$ 成正比」写成 $\dfrac{\mathrm{d}y}{\mathrm{d}t} = ky$，通解 $y = Ce^{kt}$；
- **冷却**：温度 $T$ 的变化率与它和环境温度 $T_0$ 之差成正比，$\dfrac{\mathrm{d}T}{\mathrm{d}t} = -k(T - T_0)$（$k > 0$），通解 $T = T_0 + Ce^{-kt}$；
- **运动**：牛顿第二定律 $m\dfrac{\mathrm{d}^2x}{\mathrm{d}t^2} = F$，速度 $v = \dfrac{\mathrm{d}x}{\mathrm{d}t}$，$\dfrac{\mathrm{d}^2x}{\mathrm{d}t^2} = \dfrac{\mathrm{d}v}{\mathrm{d}t}$。

#### 4. 含变限积分的方程
方程里含 $\displaystyle\int_a^x$ 时：
1. **求导**：两边对 $x$ 求导，化成微分方程；被积函数里含 $x$ 的，先把 $x$ 提到积分号外再求导（第 3 章）；
2. **初始条件**：令 $x = a$，积分为 $0$，从原方程读出 $f(a)$；求导两次的，从一次导数的式子再读出 $f'(a)$。

#### 5. 由方程读出导数值
已知 $y(x_0)$、$y'(x_0)$ 时，把 $x = x_0$ 代进二阶方程，就得到 $y''(x_0)$；对方程两边求导再代入，得到 $y'''(x_0)$。
* **用法**：只问 $y$ 在 $x_0$ 附近的极限、泰勒展开时，不必解出方程。

**② 一阶方程怎么积出来**

**分离变量与换元**

#### 1. 分离变量法
方程 $\dfrac{\mathrm{d}y}{\mathrm{d}x} = f(x)g(y)$：
1. **分离变量**：$g(y) \neq 0$ 时，$\dfrac{\mathrm{d}y}{g(y)} = f(x)\,\mathrm{d}x$；
2. **两边积分**：$\displaystyle\int \dfrac{\mathrm{d}y}{g(y)} = \int f(x)\,\mathrm{d}x + C$，得隐式通解；
3. **补常数解**：若 $g(y_0) = 0$，则 $y = y_0$ 也是方程的解。

#### 2. 齐次方程的解法
方程 $\dfrac{\mathrm{d}y}{\mathrm{d}x} = \varphi\left(\dfrac{y}{x}\right)$：
1. **换元**：令 $u = \dfrac{y}{x}$，即 $y = ux$，则 $\dfrac{\mathrm{d}y}{\mathrm{d}x} = u + x\dfrac{\mathrm{d}u}{\mathrm{d}x}$；
2. **化为可分离**：代入得
   $$x\dfrac{\mathrm{d}u}{\mathrm{d}x} = \varphi(u) - u$$
3. **求解代回**：分离变量求出 $u$ 后，以 $\dfrac{y}{x}$ 代 $u$。

#### 3. 其他变量代换
- **$\dfrac{\mathrm{d}y}{\mathrm{d}x} = f(ax + by + c)$（$b \neq 0$）**：令 $u = ax + by + c$，则 $\dfrac{\mathrm{d}u}{\mathrm{d}x} = a + bf(u)$，为可分离变量方程；
- **方程里同时出现 $\varphi(y)$ 与 $\varphi'(y)y'$**：令 $u = \varphi(y)$，常化成线性方程；如 $y'\cos y + \sin y = x$，令 $u = \sin y$，得 $u' + u = x$。

**线性方程**

#### 1. 一阶线性方程的通解公式
- **齐次方程**：$y = Ce^{-\int P(x)\,\mathrm{d}x}$；
- **非齐次方程**：
  $$y = e^{-\int P(x)\,\mathrm{d}x}\left[\int Q(x)e^{\int P(x)\,\mathrm{d}x}\,\mathrm{d}x + C\right]$$

公式中的不定积分都只取一个原函数。
* **依据**：两边乘 $e^{\int P\,\mathrm{d}x}$，左边 $y'e^{\int P\,\mathrm{d}x} + Pye^{\int P\,\mathrm{d}x} = \left(ye^{\int P\,\mathrm{d}x}\right)'$，两边积分；$e^{\int P\,\mathrm{d}x}$ 就是一个积分因子。

#### 2. 常数变易法
1. **求齐次通解**：$y = Ce^{-\int P(x)\,\mathrm{d}x}$；
2. **常数变易**：设非齐次方程的解为 $y = C(x)e^{-\int P(x)\,\mathrm{d}x}$；
3. **代入求 $C(x)$**：代入原方程得 $C'(x) = Q(x)e^{\int P(x)\,\mathrm{d}x}$，积分即得。

#### 3. 以 $x$ 为未知函数的线性方程
方程对 $y$ 不是线性的，但对 $x$ 是线性的，写成
$$\dfrac{\mathrm{d}x}{\mathrm{d}y} + P(y)x = Q(y)$$

把通解公式中的 $x$、$y$ 对调：$x = e^{-\int P(y)\,\mathrm{d}y}\left[\displaystyle\int Q(y)e^{\int P(y)\,\mathrm{d}y}\,\mathrm{d}y + C\right]$。

#### 4. 伯努利方程的解法
方程 $\dfrac{\mathrm{d}y}{\mathrm{d}x} + P(x)y = Q(x)y^n$（$n \neq 0, 1$）：
1. **换元**：两边除以 $y^n$，令 $z = y^{1-n}$；
2. **化为线性**：得一阶线性方程
   $$\dfrac{\mathrm{d}z}{\mathrm{d}x} + (1 - n)P(x)z = (1 - n)Q(x)$$
3. **求解代回**：用通解公式求出 $z$，再以 $y^{1-n}$ 代 $z$；
4. **$n > 0$ 时**：$y = 0$ 也是解。

**全微分方程**

#### 1. 全微分方程的解法
设 $P, Q$ 在单连通区域 $G$ 内具有一阶连续偏导数：
1. **判别**：$P\,\mathrm{d}x + Q\,\mathrm{d}y = 0$ 是全微分方程 $\iff$ ==$\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$==（第 7 章，与路径无关的条件）；
2. **求 $u$**：用第 7 章求原函数的办法，如沿折线 $u = \displaystyle\int_{x_0}^{x} P(x, y_0)\,\mathrm{d}x + \int_{y_0}^{y} Q(x, y)\,\mathrm{d}y$；
3. **通解**：$u(x, y) = C$。

#### 2. 积分因子（边界）
不是全微分方程时，可以乘一个因子凑成全微分：
* **一阶线性方程**：$\mu = e^{\int P\,\mathrm{d}x}$；
* **观察**：$y\,\mathrm{d}x - x\,\mathrm{d}y$ 乘 $\dfrac{1}{y^2}$ 得 $\mathrm{d}\dfrac{x}{y}$，乘 $\dfrac{1}{x^2}$ 得 $-\mathrm{d}\dfrac{y}{x}$；
* **注意**：乘因子时，使因子为 $0$ 或无意义的点可能丢解或多出解。

**③ 高阶方程怎么降阶**

#### 1. $y^{(n)} = f(x)$ 型
连续积分 $n$ 次，每次积分出现一个任意常数，得含 $n$ 个任意常数的通解。

#### 2. $y'' = f(x, y')$ 型（不显含 $y$）
1. **换元**：令 $y' = p(x)$，则 $y'' = p'$；
2. **降阶**：方程化为一阶方程 $p' = f(x, p)$，求出 $p = \varphi(x, C_1)$；
3. **再积分**：$y = \displaystyle\int \varphi(x, C_1)\,\mathrm{d}x + C_2$。

#### 3. $y'' = f(y, y')$ 型（不显含 $x$）
1. **换元**：令 $y' = p(y)$，把 $y$ 看作自变量，则
   $$y'' = \dfrac{\mathrm{d}p}{\mathrm{d}x} = \dfrac{\mathrm{d}p}{\mathrm{d}y} \cdot \dfrac{\mathrm{d}y}{\mathrm{d}x} = p\dfrac{\mathrm{d}p}{\mathrm{d}y}$$
2. **降阶**：方程化为一阶方程 $p\dfrac{\mathrm{d}p}{\mathrm{d}y} = f(y, p)$，求出 $p = \varphi(y, C_1)$；
3. **分离变量**：由 $\dfrac{\mathrm{d}y}{\varphi(y, C_1)} = \mathrm{d}x$ 积分得通解。

* **初始条件早用**：缺 $x$ 型给了 $y(x_0) = y_0$、$y'(x_0) = y_1$ 时，$p(y_0) = y_1$，第一次积分后就定出 $C_1$。

**④ 线性方程的解的结构**

#### 1. 齐次线性方程解的叠加
若 $y_1, y_2$ 是齐次方程 $y'' + P(x)y' + Q(x)y = 0$ 的解，则 $C_1y_1 + C_2y_2$ 也是它的解（$C_1, C_2$ 为任意常数）。
* **依据**：左边对 $y$ 是线性的，$L[C_1y_1 + C_2y_2] = C_1L[y_1] + C_2L[y_2] = 0$。

#### 2. 齐次线性方程的通解
若 $y_1, y_2$ 是齐次方程的两个==线性无关==的解，则
$$y = C_1y_1 + C_2y_2$$

是它的通解。$n$ 阶齐次线性方程同理：$n$ 个线性无关解的线性组合就是通解。

#### 3. 非齐次线性方程的通解
设 $y^*$ 是非齐次方程 $y'' + P(x)y' + Q(x)y = f(x)$ 的一个特解，$Y$ 是对应齐次方程的通解，则
$$y = Y + y^*$$

是非齐次方程的通解。

#### 4. 解的叠加与差
- **两解之差**：非齐次方程的两个解之差是对应齐次方程的解；
- **叠加原理**：若 $y_1^*$、$y_2^*$ 分别是右端为 $f_1(x)$、$f_2(x)$ 的非齐次方程的特解，则 $y_1^* + y_2^*$ 是右端为 $f_1(x) + f_2(x)$ 的方程的特解；
- **组合**：$y_1, y_2$ 是非齐次方程的解时，$\lambda y_1 + \mu y_2$ 是非齐次方程的解 $\iff \lambda + \mu = 1$，是齐次方程的解 $\iff \lambda + \mu = 0$。

#### 5. 由非齐次方程的三个解写通解
设 $y_1, y_2, y_3$ 是二阶非齐次线性方程的三个解，且 $y_1 - y_3$ 与 $y_2 - y_3$ 线性无关，则通解为
$$y = C_1(y_1 - y_3) + C_2(y_2 - y_3) + y_3$$

**⑤ 常系数齐次怎么解**

#### 1. 二阶常系数齐次线性方程的通解
方程 $y'' + py' + qy = 0$ 的特征方程 $r^2 + pr + q = 0$，按特征根写通解：
- **两个不等实根 $r_1 \neq r_2$**：$y = C_1e^{r_1x} + C_2e^{r_2x}$；
- **两个相等实根 $r_1 = r_2 = r$**：$y = (C_1 + C_2x)e^{rx}$；
- **一对共轭复根 $r_{1,2} = \alpha \pm \mathrm{i}\beta$**：$y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$。

* **依据**：$y = e^{rx}$ 代入得 $(r^2 + pr + q)e^{rx} = 0$，$r$ 是特征根时 $e^{rx}$ 就是解；重根时 $xe^{rx}$ 也是解；复根时由欧拉公式 $e^{(\alpha + \mathrm{i}\beta)x} = e^{\alpha x}(\cos\beta x + \mathrm{i}\sin\beta x)$，实部、虚部各是一个解。

#### 2. $n$ 阶常系数齐次线性方程
方程 $y^{(n)} + p_1y^{(n-1)} + \cdots + p_{n-1}y' + p_ny = 0$ 的特征方程为
$$r^n + p_1r^{n-1} + \cdots + p_{n-1}r + p_n = 0$$

每个特征根对应通解中的若干项：
- **单实根 $r$**：一项 $Ce^{rx}$；
- **$k$ 重实根 $r$**：$k$ 项 $e^{rx}(C_1 + C_2x + \cdots + C_kx^{k-1})$；
- **一对单复根 $\alpha \pm \mathrm{i}\beta$**：两项 $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$；
- **一对 $k$ 重复根 $\alpha \pm \mathrm{i}\beta$**：$2k$ 项
  $$\begin{aligned} e^{\alpha x}\big[ & (C_1 + \cdots + C_kx^{k-1})\cos\beta x \\ & + (D_1 + \cdots + D_kx^{k-1})\sin\beta x\big] \end{aligned}$$

#### 3. 由通解反求方程
由通解读出全部特征根（含重数）：
1. **写特征方程**：根为 $r_1, \cdots, r_n$ 时，特征方程为 $(r - r_1)\cdots(r - r_n) = 0$；
2. **展开**：把 $r^k$ 换回 $y^{(k)}$，得到方程；
* **例**：$xe^x$ 是解，说明 $1$ 至少是二重根；$\cos 2x$ 是解，说明 $\pm 2\mathrm{i}$ 是根。

**⑥ 常系数非齐次怎么解**

#### 1. 自由项为 $e^{\lambda x}P_m(x)$ 型
方程 $y'' + py' + qy = e^{\lambda x}P_m(x)$（$P_m(x)$ 为 $m$ 次多项式），设特解
$$y^* = x^kQ_m(x)e^{\lambda x}$$

- **$Q_m(x)$**：$m$ 次待定多项式；
- **$k$**：$\lambda$ 不是特征根取 $0$，是单根取 $1$，是重根取 $2$；
- **定系数**：代入原方程，比较两端同类项的系数求出 $Q_m(x)$；
- **依据**：$e^{\lambda x}Q(x)$ 代入左边得 $e^{\lambda x}[Q'' + (2\lambda + p)Q' + (\lambda^2 + p\lambda + q)Q]$；$\lambda$ 是特征根时 $Q$ 的系数为 $0$，次数不够，要乘 $x$。

#### 2. 自由项为 $e^{\lambda x}[P_l(x)\cos\omega x + P_n(x)\sin\omega x]$ 型
设特解
$$y^* = x^ke^{\lambda x}\left[R_m^{(1)}(x)\cos\omega x + R_m^{(2)}(x)\sin\omega x\right]$$

- **$R_m^{(1)}, R_m^{(2)}$**：$m$ 次待定多项式，$m = \max\{l, n\}$；
- **$k$**：$\lambda + \mathrm{i}\omega$ 不是特征根取 $0$，是特征根取 $1$；
- **两项都要设**：即使自由项中只有 $\cos\omega x$（或只有 $\sin\omega x$），特解中也必须同时含 $\cos\omega x$ 与 $\sin\omega x$ 两项。

#### 3. 自由项是几项之和
$f(x) = f_1(x) + f_2(x)$ 时，分别对 $f_1$、$f_2$ 设特解、求出 $y_1^*$、$y_2^*$，$y^* = y_1^* + y_2^*$（叠加原理）。

#### 4. 欧拉方程的解法
1. **换元**：$x > 0$ 时令 $x = e^t$（即 $t = \ln x$），记 $D = \dfrac{\mathrm{d}}{\mathrm{d}t}$，则
   - $xy' = Dy$，$x^2y'' = D(D - 1)y$；
   - $x^3y''' = D(D - 1)(D - 2)y$；
   - 一般地 $x^ky^{(k)} = D(D - 1)\cdots(D - k + 1)y$；
2. **化为常系数**：代入后得到以 $t$ 为自变量的常系数线性方程，按 ⑤ 与本站的办法求解；自由项里的 $x$ 换成 $e^t$；
3. **代回**：以 $\ln x$ 代 $t$，得原方程的解。

$x < 0$ 时令 $x = -e^t$，结论相同。
* **依据**：$\dfrac{\mathrm{d}y}{\mathrm{d}x} = \dfrac{1}{x}\dfrac{\mathrm{d}y}{\mathrm{d}t}$，所以 $xy' = \dfrac{\mathrm{d}y}{\mathrm{d}t}$；再求一次导，得 $x^2y'' = \dfrac{\mathrm{d}^2y}{\mathrm{d}t^2} - \dfrac{\mathrm{d}y}{\mathrm{d}t}$。

### 意义

本卡在做题时专门用于解决以下 17 类确定性目标，按站排列：

**① 怎么列方程，解是什么**

* **1. 由几何条件列方程**
  * **问题**：曲线的切线、法线、面积满足某个条件，求曲线。
  * **目标**：把条件写成 $y$ 与 $y'$ 的等式，再求解，用曲线过的点定常数。
  * **调用**：切线、法线的方程与截距；一阶方程的解法。
  * **行动**：
    1. 写切线；如曲线 $y = y(x)$（$x > 0$）上任一点处的切线在 $y$ 轴上的截距等于该点的横坐标，且曲线过 $(1, 1)$：截距 $y - xy' = x$；
    2. 化成标准形：$y' - \dfrac{y}{x} = -1$，一阶线性；
    3. 求解：$e^{-\int \frac{1}{x}\mathrm{d}x} = \dfrac{1}{x}$，$\left(\dfrac{y}{x}\right)' = -\dfrac{1}{x}$，$y = x(C - \ln x)$；
    4. 定常数：过 $(1, 1)$，$C = 1$，$y = x(1 - \ln x)$。
* **2. 由物理条件列方程**
  * **问题**：给出变化率与当前量的关系，求某时刻的量或达到某量的时间。
  * **目标**：写出「变化率 $=$ 关系」，解出后用两个已知时刻定出常数和比例系数。
  * **调用**：变化率；冷却 $\dfrac{\mathrm{d}T}{\mathrm{d}t} = -k(T - T_0)$；分离变量法。
  * **行动**：
    1. 列方程；如 $100^\circ\mathrm{C}$ 的物体放在 $20^\circ\mathrm{C}$ 的室内，$10$ 分钟后降到 $60^\circ\mathrm{C}$，问多久降到 $30^\circ\mathrm{C}$：$\dfrac{\mathrm{d}T}{\mathrm{d}t} = -k(T - 20)$；
    2. 求解：$T = 20 + 80e^{-kt}$；
    3. 定 $k$：$60 = 20 + 80e^{-10k}$，$e^{-10k} = \dfrac{1}{2}$，$k = \dfrac{\ln 2}{10}$；
    4. 求时间：$30 = 20 + 80e^{-kt}$，$e^{-kt} = \dfrac{1}{8} = \left(\dfrac{1}{2}\right)^3$，$t = 30$ 分钟。
* **3. 解含变限积分的方程**
  * **问题**：$f(x)$ 满足一个含 $\displaystyle\int_0^x f(t)\,\mathrm{d}t$ 的方程，求 $f$。
  * **目标**：求导化成微分方程，再从原方程读出初始条件。
  * **调用**：含变限积分的方程；一阶线性方程的通解公式。
  * **行动**：
    1. 求导；如 $f(x) = 2\displaystyle\int_0^x f(t)\,\mathrm{d}t + x^2$：$f'(x) = 2f(x) + 2x$；
    2. 初始条件：令 $x = 0$，$f(0) = 0$；
    3. 求解：$f' - 2f = 2x$，$f = Ce^{2x} - x - \dfrac{1}{2}$；
    4. 定常数：$C = \dfrac{1}{2}$，$f(x) = \dfrac{e^{2x}}{2} - x - \dfrac{1}{2}$。
* **4. 不解方程，求导数值或极限**
  * **问题**：$y$ 是方程满足初始条件的解，求 $y''(x_0)$ 或含 $y$ 的极限。
  * **目标**：把 $x_0$ 代进方程读出高阶导数，再按泰勒展开或洛必达。
  * **调用**：由方程读出导数值；泰勒公式（第 2 章）。
  * **行动**：
    1. 读导数；如 $y'' - 3y' + 2y = e^{3x}$，$y(0) = y'(0) = 0$：$y''(0) = 3y'(0) - 2y(0) + e^0 = 1$；
    2. 展开：$y(x) = \dfrac{1}{2}x^2 + o(x^2)$；
    3. 求极限：$\lim\limits_{x \to 0}\dfrac{\ln(1 + x^2)}{y(x)} = \lim\limits_{x \to 0}\dfrac{x^2}{x^2/2} = 2$。

**② 一阶方程怎么积出来**

* **5. 可分离变量方程与齐次方程**
  * **问题**：解能分离变量、或右端只依赖 $\dfrac{y}{x}$ 的一阶方程。
  * **目标**：分离变量积分；齐次的先换元 $u = \dfrac{y}{x}$。
  * **调用**：分离变量法；齐次方程的解法。
  * **行动**：
    1. 分离；如 $xy' - y\ln y = 0$：$\dfrac{\mathrm{d}y}{y\ln y} = \dfrac{\mathrm{d}x}{x}$，积分得 $\ln|\ln y| = \ln|x| + C_1$，即 $\ln y = Cx$，$y = e^{Cx}$；
    2. 补常数解：$\ln y = 0$ 即 $y = 1$ 是解，已含在 $C = 0$ 中；
    3. 齐次；如 $(x^2 + y^2)\,\mathrm{d}x - xy\,\mathrm{d}y = 0$：$y' = \dfrac{x}{y} + \dfrac{y}{x}$，令 $u = \dfrac{y}{x}$，$xu' = \dfrac{1}{u}$；
    4. 积分代回：$\dfrac{u^2}{2} = \ln|x| + C$，即 $y^2 = 2x^2(\ln|x| + C)$。
* **6. 一阶线性方程**
  * **问题**：解 $y' + P(x)y = Q(x)$；或对 $x$ 线性的方程。
  * **目标**：化成标准形，套通解公式。
  * **调用**：一阶线性方程的通解公式；以 $x$ 为未知函数的线性方程。
  * **行动**：
    1. 标准形；如 $y' + y\tan x = \cos x$：$P = \tan x$，$e^{\int\tan x\,\mathrm{d}x} = \dfrac{1}{\cos x}$；
    2. 套公式：$\left(\dfrac{y}{\cos x}\right)' = 1$，$y = (x + C)\cos x$；
    3. 换未知函数；如 $y' = \dfrac{y}{x + y^3}$：$\dfrac{\mathrm{d}x}{\mathrm{d}y} - \dfrac{x}{y} = y^2$；
    4. 求解：$\left(\dfrac{x}{y}\right)' = y$（对 $y$ 求导），$x = \dfrac{y^3}{2} + Cy$。
* **7. 伯努利方程与其他换元**
  * **问题**：右端含 $y^n$；或右端是 $ax + by + c$ 的函数；或出现 $\varphi(y)$ 与 $\varphi'(y)y'$。
  * **目标**：选一个换元，化成线性或可分离方程。
  * **调用**：伯努利方程的解法；其他变量代换。
  * **行动**：
    1. 伯努利；如 $y' + \dfrac{y}{x} = y^2\ln x$：令 $z = y^{-1}$，$z' - \dfrac{z}{x} = -\ln x$；
    2. 求解：$\left(\dfrac{z}{x}\right)' = -\dfrac{\ln x}{x}$，$z = x\left(C - \dfrac{\ln^2 x}{2}\right)$，$y = \dfrac{1}{x\left(C - \frac{1}{2}\ln^2 x\right)}$；另有解 $y = 0$；
    3. $u = x + y$；如 $y' = (x + y)^2$：$u' = 1 + u^2$，$\arctan u = x + C$，$y = \tan(x + C) - x$；
    4. $u = \sin y$；如 $y'\cos y + \sin y = x$：$u' + u = x$，$u = x - 1 + Ce^{-x}$，即 $\sin y = x - 1 + Ce^{-x}$。
* **8. 全微分方程**
  * **问题**：解 $P\,\mathrm{d}x + Q\,\mathrm{d}y = 0$。
  * **目标**：验证是全微分方程，求出 $u$。
  * **调用**：全微分方程的解法；积分因子。
  * **行动**：
    1. 验证；如 $(5x^4 + 3xy^2 - y^3)\,\mathrm{d}x + (3x^2y - 3xy^2 + y^2)\,\mathrm{d}y = 0$：$\dfrac{\partial P}{\partial y} = 6xy - 3y^2 = \dfrac{\partial Q}{\partial x}$；
    2. 求 $u$：从原点沿折线，$\displaystyle\int_0^x 5x^4\,\mathrm{d}x + \int_0^y (3x^2y - 3xy^2 + y^2)\,\mathrm{d}y$；
    3. 通解：$x^5 + \dfrac{3}{2}x^2y^2 - xy^3 + \dfrac{1}{3}y^3 = C$；
    4. 不是全微分时试积分因子；如 $y\,\mathrm{d}x - x\,\mathrm{d}y = 0$ 乘 $\dfrac{1}{y^2}$，得 $\mathrm{d}\dfrac{x}{y} = 0$，$x = Cy$。

**③ 高阶方程怎么降阶**

* **9. 可降阶的二阶方程**
  * **问题**：解不显含 $y$ 或不显含 $x$ 的二阶方程，常带初始条件。
  * **目标**：令 $y' = p$ 降阶，第一次积分后就用初始条件。
  * **调用**：$y'' = f(x, y')$ 型；$y'' = f(y, y')$ 型。
  * **行动**：
    1. 缺 $y$；如 $(1 + x^2)y'' = 2xy'$，$y(0) = 1$，$y'(0) = 3$：令 $y' = p(x)$，$\dfrac{\mathrm{d}p}{p} = \dfrac{2x}{1 + x^2}\,\mathrm{d}x$，$p = C_1(1 + x^2)$；
    2. 早定常数：$p(0) = 3$，$C_1 = 3$；再积分，$y = x^3 + 3x + C_2$，$C_2 = 1$，$y = x^3 + 3x + 1$；
    3. 缺 $x$；如 $y'' = 3\sqrt{y}$，$y(0) = 1$，$y'(0) = 2$：令 $y' = p(y)$，$p\dfrac{\mathrm{d}p}{\mathrm{d}y} = 3y^{\frac{1}{2}}$，$\dfrac{p^2}{2} = 2y^{\frac{3}{2}} + C_1$；$y = 1$ 时 $p = 2$，$C_1 = 0$；
    4. 再分离：$p = 2y^{\frac{3}{4}}$，$y^{-\frac{3}{4}}\,\mathrm{d}y = 2\,\mathrm{d}x$，$4y^{\frac{1}{4}} = 2x + 4$，$y = \left(\dfrac{x}{2} + 1\right)^4$。

**④ 线性方程的解的结构**

* **10. 由特解写通解；判断解的组合**
  * **问题**：已知线性方程的几个解，写通解；或判断某个组合是不是解（常见于选择题）。
  * **目标**：两两相减得齐次方程的解，按结构定理组合。
  * **调用**：解的叠加与差；由非齐次方程的三个解写通解。
  * **行动**：
    1. 三个解；如 $1$、$x$、$x^2$ 是某个二阶非齐次线性方程的解：$x - 1$、$x^2 - 1$ 是齐次方程的解，比值不是常数，线性无关；
    2. 写通解：$y = C_1(x - 1) + C_2(x^2 - 1) + 1$；
    3. 组合；如 $y_1, y_2$ 是 $y' + P(x)y = Q(x)$ 的两个不同解，$\lambda y_1 + \mu y_2$ 是该方程的解、$\lambda y_1 - \mu y_2$ 是对应齐次方程的解：$\lambda + \mu = 1$，$\lambda - \mu = 0$，所以 $\lambda = \mu = \dfrac{1}{2}$。

**⑤ 常系数齐次怎么解**

* **11. 解常系数齐次线性方程**
  * **问题**：解二阶或高阶常系数齐次线性方程，或求它的初值问题。
  * **目标**：写特征方程，按根的类型写通解，再定常数。
  * **调用**：二阶、$n$ 阶常系数齐次线性方程的通解。
  * **行动**：
    1. 复根；如 $y'' - 2y' + 5y = 0$：$r = 1 \pm 2\mathrm{i}$，$y = e^x(C_1\cos 2x + C_2\sin 2x)$；
    2. 重根与初值；如 $y'' - 4y' + 4y = 0$，$y(0) = 1$，$y'(0) = 4$：$r = 2$（二重），$y = (C_1 + C_2x)e^{2x}$；$C_1 = 1$，$2C_1 + C_2 = 4$，$C_2 = 2$，$y = (1 + 2x)e^{2x}$；
    3. 高阶；如 $y^{(4)} - y = 0$：$r^4 - 1 = 0$，$r = \pm 1, \pm\mathrm{i}$，$y = C_1e^x + C_2e^{-x} + C_3\cos x + C_4\sin x$；
    4. 三重根；如 $y''' - 3y'' + 3y' - y = 0$：$(r - 1)^3 = 0$，$y = (C_1 + C_2x + C_3x^2)e^x$。
* **12. 由通解反求方程**
  * **问题**：已知通解（或几个线性无关的解），求常系数齐次线性方程。
  * **目标**：读出全部特征根，写出特征方程。
  * **调用**：由通解反求方程。
  * **行动**：
    1. 读根；如通解 $y = (C_1 + C_2x)e^x + C_3e^{-x}$：$1$ 是二重根，$-1$ 是单根；
    2. 特征方程：$(r - 1)^2(r + 1) = r^3 - r^2 - r + 1 = 0$；
    3. 方程：$y''' - y'' - y' + y = 0$。

**⑥ 常系数非齐次怎么解**

* **13. 自由项为 $e^{\lambda x}P_m(x)$**
  * **问题**：解 $y'' + py' + qy = e^{\lambda x}P_m(x)$，多项式自由项是 $\lambda = 0$ 的情形。
  * **目标**：看 $\lambda$ 是几重特征根，设特解，比较系数。
  * **调用**：自由项为 $e^{\lambda x}P_m(x)$ 型；非齐次线性方程的通解。
  * **行动**：
    1. 特征根；如 $y'' - 5y' + 6y = xe^{2x}$：$r = 2, 3$，$\lambda = 2$ 是单根，$k = 1$；
    2. 设特解：$y^* = x(ax + b)e^{2x}$，代入比较系数，$-2a = 1$，$2a - b = 0$，$a = -\dfrac{1}{2}$，$b = -1$；
    3. 通解：$y = C_1e^{2x} + C_2e^{3x} - \left(\dfrac{x^2}{2} + x\right)e^{2x}$；
    4. $\lambda = 0$ 是根；如 $y'' + y' = x^2$：$r = 0, -1$，$k = 1$，设 $y^* = x(ax^2 + bx + c)$，得 $y^* = \dfrac{x^3}{3} - x^2 + 2x$。
* **14. 自由项含正弦、余弦**
  * **问题**：解 $y'' + py' + qy = e^{\lambda x}[P_l(x)\cos\omega x + P_n(x)\sin\omega x]$。
  * **目标**：看 $\lambda + \mathrm{i}\omega$ 是不是特征根，正弦、余弦两项都设。
  * **调用**：自由项为 $e^{\lambda x}[P_l\cos\omega x + P_n\sin\omega x]$ 型。
  * **行动**：
    1. 不是根；如 $y'' + y = x\cos 2x$：$r = \pm\mathrm{i}$，$2\mathrm{i}$ 不是根，设 $y^* = (ax + b)\cos 2x + (cx + d)\sin 2x$；
    2. 比较系数：$a = -\dfrac{1}{3}$，$b = 0$，$c = 0$，$d = \dfrac{4}{9}$，$y^* = -\dfrac{x}{3}\cos 2x + \dfrac{4}{9}\sin 2x$；
    3. 是根；如 $y'' + y = \sin x$：$\mathrm{i}$ 是根，设 $y^* = x(a\cos x + b\sin x)$，得 $y^* = -\dfrac{x}{2}\cos x$；
    4. 通解：$y = C_1\cos x + C_2\sin x - \dfrac{x}{2}\cos x$。
* **15. 自由项是和；由一个解反求方程**
  * **问题**：自由项是几类之和；或已知方程的一个解，求方程中的常数。
  * **目标**：分开设特解再相加；反求时把解拆成齐次部分与特解部分。
  * **调用**：自由项是几项之和；由通解反求方程。
  * **行动**：
    1. 分开设；如 $y'' - y = e^x + x$：对 $e^x$，$1$ 是单根，$y_1^* = axe^x$，得 $a = \dfrac{1}{2}$；对 $x$，$y_2^* = -x$；
    2. 相加：$y^* = \dfrac{x}{2}e^x - x$；
    3. 反求；如 $y = e^{2x} + (1 + x)e^x$ 是 $y'' + ay' + by = ce^x$ 的一个解：$e^{2x}$、$e^x$ 是齐次方程的解，特征根 $2$、$1$，$a = -3$，$b = 2$；
    4. 定 $c$：剩下的 $xe^x$ 是特解，代入得 $(x + 2 - 3x - 3 + 2x)e^x = -e^x$，$c = -1$。
* **16. 欧拉方程**
  * **问题**：解 $x^2y'' + pxy' + qy = f(x)$。
  * **目标**：令 $x = e^t$，化成 $y(t)$ 的常系数方程。
  * **调用**：欧拉方程的解法。
  * **行动**：
    1. 换元；如 $x^2y'' + xy' - 4y = x^3$（$x > 0$）：$D(D - 1)y + Dy - 4y = e^{3t}$，即 $\dfrac{\mathrm{d}^2y}{\mathrm{d}t^2} - 4y = e^{3t}$；
    2. 解常系数方程：$r = \pm 2$，$3$ 不是根，$y^* = \dfrac{1}{5}e^{3t}$；
    3. 代回：$y = C_1x^2 + \dfrac{C_2}{x^2} + \dfrac{x^3}{5}$。
* **17. 幂级数的和函数满足的方程**
  * **问题**：证明幂级数的和函数满足某个微分方程，并由它求出和函数。
  * **目标**：逐项求导拼出方程，初始条件取级数在 $x = 0$ 处的值。
  * **调用**：逐项求导（第 8 章）；常系数非齐次线性方程。
  * **行动**：
    1. 拼方程；如 $y(x) = \displaystyle\sum_{n=0}^{\infty}\dfrac{x^{3n}}{(3n)!}$：$y$、$y'$、$y''$ 分别是 $e^x$ 的展开式中次数被 $3$ 除余 $0$、$2$、$1$ 的项，所以 $y'' + y' + y = e^x$；
    2. 初始条件：$y(0) = 1$，$y'(0) = 0$；
    3. 求解：$r = -\dfrac{1}{2} \pm \dfrac{\sqrt{3}}{2}\mathrm{i}$，$y^* = \dfrac{1}{3}e^x$；定常数得 $y = \dfrac{2}{3}e^{-\frac{x}{2}}\cos\dfrac{\sqrt{3}}{2}x + \dfrac{1}{3}e^x$。
