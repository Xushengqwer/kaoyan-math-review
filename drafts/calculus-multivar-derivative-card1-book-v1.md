### 〔定义〕

**本卡主线**：站在曲面上一点，往四周走，高度怎么变。整张卡分三层、六站，每一站由上一站引出：
* **变化率**：
  * **① 从四面八方靠近**：二元函数可以沿任意路径靠近一点，极限要求每条路径都趋于同一个数；
  * **② 变化有多快**：先沿坐标轴看，是偏导数；一点附近整体像一张平面，是可微；
  * **③ 怎么求偏导**：套着的函数用链式法则；藏在方程里的函数，对恒等式两边求偏导；
* **方向**：
  * **④ 往哪个方向升得最快**：可微时，两个偏导数拼出所有方向，拼成的向量是梯度，它垂直于等值线；
  * **⑤ 切平面和切线**：曲面 $F = 0$ 是 $F$ 的一张等值面，法向量就是 $\operatorname{grad} F$；
* **极值**：
  * **⑥ 最高点和最低点**：驻点是候选，二阶看二次型的符号；有约束时，相切处两个梯度共线；
* **依赖**：求极限的工具（第 1 章）；导数（第 2 章）；平面和直线的方程（第 4 章）；二次型的正定（线性代数第 4 章）。

**① 从四面八方靠近**

第 2 章研究 $y = f(x)$ 在一点变化得多快；第 4 章说 $z = f(x, y)$ 的图像是空间里的一张曲面。现在把第 2 章的问题搬到曲面上：站在曲面上一点，往四周走，高度怎么变？先要说清楚「靠近」。一元时，$x \to x_0$ 只有左右两条路；二元时，点 $(x, y)$ 可以沿直线、沿抛物线、绕着圈，从任意路径靠近 $(x_0, y_0)$。极限要求每条路径都趋于同一个数，所以比一元严格：说明极限不存在容易，找两条结果不同的路径就够；说明存在反而难，要用一个和路径无关的量去夹。连续的定义和一元一样：极限等于函数值。

#### 1. 二元函数
设 $D$ 是平面上的非空点集，若对每个点 $(x, y) \in D$，按照某一法则 $f$ 总有唯一确定的数 $z$ 与之对应，则称 $z = f(x, y)$ 为定义在 $D$ 上的==二元函数==，$D$ 称为它的==定义域==。
* **图像**：点 $(x, y, f(x, y))$ 组成的集合，一般是空间里的一张曲面。

#### 2. 邻域
* **邻域**：$U(P_0, \delta) = \{\, P \mid |PP_0| < \delta \,\}$，即以 $P_0$ 为圆心、$\delta$ 为半径的圆盘内部；
* **去心邻域**：去掉中心 $P_0$ 后，记作 $\mathring{U}(P_0, \delta)$。

#### 3. 二重极限
设 $f(x, y)$ 在 $P_0(x_0, y_0)$ 的某去心邻域内有定义，若对任意 $\varepsilon > 0$，总存在 $\delta > 0$，使当
$$0 < \sqrt{(x - x_0)^2 + (y - y_0)^2} < \delta$$

时恒有 $|f(x, y) - A| < \varepsilon$，则称 $A$ 为 $f(x, y)$ 当 $(x, y) \to (x_0, y_0)$ 时的==极限==，记作 $\lim\limits_{(x, y) \to (x_0, y_0)} f(x, y) = A$。
* **任意方式趋近**：要求点 $(x, y)$ 以==任意方式==趋于 $(x_0, y_0)$ 时，$f(x, y)$ 都趋于同一个 $A$。

#### 4. 连续
若 $\lim\limits_{(x, y) \to (x_0, y_0)} f(x, y) = f(x_0, y_0)$，则称 $f(x, y)$ 在 $(x_0, y_0)$ ==连续==；在 $D$ 内每一点都连续，称 $f$ 在 $D$ 内连续。

**② 变化有多快**

有了极限，就能问变化率。无数个方向，先挑最简单的两个：只动 $x$，或只动 $y$。这就是偏导数，求的时候把另一个变量当常数，按一元求导。但两个方向管不住其余方向：$\dfrac{xy}{x^2 + y^2}$（原点处补定义为 $0$）在原点的两个偏导数都是 $0$，沿 $y = x$ 靠近原点时，函数值却一直是 $\dfrac{1}{2}$，连连续都不是。真正说明「一点附近像一张平面」的是可微：不管往哪个方向走，函数的增量都只比一个一次式 $A\Delta x + B\Delta y$ 差一个更高阶的无穷小。第 2 章里，可导和可微是一回事；到了二元，偏导数存在只说明了两个方向，可微才说明了所有方向。

#### 1. 偏导数
设 $z = f(x, y)$ 在 $(x_0, y_0)$ 的某邻域内有定义，若极限
$$f_x(x_0, y_0) = \lim\limits_{\Delta x \to 0} \dfrac{f(x_0 + \Delta x, y_0) - f(x_0, y_0)}{\Delta x}$$

存在，则称此极限为 $f(x, y)$ 在 $(x_0, y_0)$ 处对 $x$ 的==偏导数==，也记作 $\dfrac{\partial z}{\partial x}\Big|_{(x_0, y_0)}$；对 $y$ 的偏导数 $f_y(x_0, y_0)$ 同理。
* **求法**：对 $x$ 求偏导时，把 $y$ 看作常数，按一元函数求导。

#### 2. 可微与全微分
设 $z = f(x, y)$ 在 $(x_0, y_0)$ 的某邻域内有定义，若全增量 $\Delta z = f(x_0 + \Delta x, y_0 + \Delta y) - f(x_0, y_0)$ 可表示为
$$\Delta z = A\Delta x + B\Delta y + o(\rho)$$

其中 $A, B$ 与 $\Delta x, \Delta y$ 无关，$\rho = \sqrt{(\Delta x)^2 + (\Delta y)^2}$，则称 $f$ 在 $(x_0, y_0)$ ==可微==，$A\Delta x + B\Delta y$ 称为==全微分==，记作 $\mathrm{d}z$。

**③ 怎么求偏导**

按定义求偏导数，每次都要算一个极限，太累。和第 2 章一样，靠法则机械地算。题目里的函数常常一层套一层，如 $z = f(xy, x + y)$；或者不写成 $z = f(x, y)$ 的样子，而是藏在一个方程里，如 $x^2 + y^2 + z^2 = 4z$。套着的用链式法则：$x$ 变一点，要经过每个中间变量传到 $z$，每条路径上逐层相乘，各条路径相加。藏在方程里的，不用另记方法：把 $z = z(x, y)$ 代回方程，得到一个恒等式，两边对 $x$ 求偏导，就能解出 $z_x$。偏导数还能再求偏导，就是高阶偏导数。

#### 1. 高阶偏导数
偏导数 $f_x, f_y$ 的偏导数称为二阶偏导数：
$$f_{xx} = \dfrac{\partial^2 z}{\partial x^2}, \quad f_{xy} = \dfrac{\partial^2 z}{\partial x\,\partial y}$$
$$f_{yx} = \dfrac{\partial^2 z}{\partial y\,\partial x}, \quad f_{yy} = \dfrac{\partial^2 z}{\partial y^2}$$

其中 $f_{xy}$（先对 $x$ 后对 $y$）与 $f_{yx}$ 称为==混合偏导数==。

#### 2. 抽象函数的偏导数记号
对 $z = f(u, v)$：
* **一阶**：$f_1' = \dfrac{\partial f}{\partial u}$，$f_2' = \dfrac{\partial f}{\partial v}$（下标表示对第几个变量求偏导）；
* **二阶**：$f_{12}'' = \dfrac{\partial^2 f}{\partial u\,\partial v}$，余类推。

#### 3. 隐函数
若把 $z = z(x, y)$ 代入方程 $F(x, y, z) = 0$ 后得到恒等式 $F(x, y, z(x, y)) \equiv 0$，则称 $z = z(x, y)$ 是由这个方程确定的==隐函数==；方程组确定的 $u = u(x, y)$，$v = v(x, y)$ 同理。

#### 4. 雅可比行列式
$$J = \dfrac{\partial(F, G)}{\partial(u, v)} = \begin{vmatrix} F_u & F_v \\ G_u & G_v \end{vmatrix}$$

称为 $F, G$ 关于 $u, v$ 的==雅可比行列式==。

**④ 往哪个方向升得最快**

偏导数只看了沿坐标轴的两个方向。其余方向呢？如果可微，往单位向量 $\boldsymbol{e} = (\cos\alpha, \cos\beta)$ 的方向走一小段 $t$，增量约为 $f_x t\cos\alpha + f_y t\cos\beta$，所以沿 $\boldsymbol{e}$ 的变化率是 $f_x\cos\alpha + f_y\cos\beta$：两个偏导数拼出了所有方向。把两个偏导数排成一个向量，就是梯度；沿 $\boldsymbol{e}$ 的变化率，正是梯度与 $\boldsymbol{e}$ 的数量积。于是：沿梯度方向升得最快；反方向降得最快；与梯度垂直的方向，变化率为 $0$，函数值不变，那正是等值线的方向。用爬山来想：最陡的上坡方向，和等高线垂直。

#### 1. 方向导数
设 $\boldsymbol{e}_l = (\cos\alpha, \cos\beta)$ 是与方向 $l$ 同向的单位向量，点 $P(x_0 + t\cos\alpha,\ y_0 + t\cos\beta)$ 在从 $P_0(x_0, y_0)$ 出发、沿 $l$ 方向的射线上，$|PP_0| = t$。若极限
$$\dfrac{\partial f}{\partial l}\Big|_{P_0} = \lim\limits_{t \to 0^+} \dfrac{f(P) - f(P_0)}{t}$$

存在，则称其为 $f(x, y)$ 在 $P_0$ 处沿方向 $l$ 的==方向导数==。
* **三元函数**：$\boldsymbol{e}_l = (\cos\alpha, \cos\beta, \cos\gamma)$，定义同理。

#### 2. 梯度
$$\operatorname{grad} f = \nabla f = f_x\,\boldsymbol{i} + f_y\,\boldsymbol{j} = (f_x, f_y)$$

（偏导数取在 $(x_0, y_0)$ 处）称为 $f(x, y)$ 在 $(x_0, y_0)$ 的==梯度==；三元函数 $\operatorname{grad} f = (f_x, f_y, f_z)$。

#### 3. 等值线与等值面
* **等值线**：$f(x, y) = c$ 在 $xOy$ 面上表示的曲线，称为 $f$ 的==等值线==；地图上的等高线，就是高度的等值线；
* **等值面**：三元函数 $u = f(x, y, z)$ 的 $f(x, y, z) = c$ 表示的曲面，称为 $f$ 的==等值面==。

**⑤ 切平面和切线**

梯度垂直于等值线，直接给出了曲面的法向量。曲面 $F(x, y, z) = 0$ 是三元函数 $F$ 取值为 $0$ 的那张等值面，所以 $\operatorname{grad} F = (F_x, F_y, F_z)$ 垂直于它：曲面上过这一点的每条曲线，切线都与 $\operatorname{grad} F$ 垂直，这些切线铺成一个平面，就是切平面。有了一个点和法向量，切平面、法线按第 4 章的写法写出来。曲线有两种给法：参数式时，各坐标对 $t$ 求导，就是运动的速度方向；两张曲面的交线，切线同时在两张切平面内，切向量同时垂直于两个法向量，取它们的向量积。

#### 1. 曲线的切线与法平面
设 $M_0$ 是空间曲线 $\Gamma$ 上一点，$M$ 是 $\Gamma$ 上另一点：
* **切线**：$M$ 沿 $\Gamma$ 趋于 $M_0$ 时，割线 $M_0M$ 的极限位置称为 $\Gamma$ 在 $M_0$ 处的==切线==，切线的方向向量称为==切向量==；
* **法平面**：过 $M_0$ 且垂直于切线的平面，称为==法平面==。

#### 2. 曲面的切平面与法线
设 $M_0$ 是曲面 $\Sigma$ 上一点：
* **切平面**：$\Sigma$ 上过 $M_0$ 的所有曲线在 $M_0$ 处的切线，若都在同一个平面上，这个平面称为 $\Sigma$ 在 $M_0$ 处的==切平面==；
* **法线**：过 $M_0$ 且垂直于切平面的直线，称为==法线==；它的方向向量称为曲面在 $M_0$ 处的==法向量==。

**⑥ 最高点和最低点**

最后找最高点和最低点。和第 2 章一样，先找候选：在极值点处只让 $x$ 变，得到一个一元函数，它在这里也取极值，所以 $f_x = 0$；$f_y = 0$ 同理。这样的点叫驻点，再加上偏导数不存在的点，就是全部候选。驻点处一次项都是 $0$，增量由二次项决定：$\dfrac{1}{2}(Ah^2 + 2Bhk + Ck^2)$ 是 $h, k$ 的二次型，它恒正、恒负还是有正有负，就是极小、极大还是不是极值，正好用线性代数第 4 章读二次型符号的办法。在有界闭区域上，连续函数一定取得最大值和最小值，把候选点的函数值比一比就行。有约束 $\varphi(x, y) = 0$ 时，只能沿约束曲线走：在极值点处，$f$ 的等值线与约束曲线相切，两条曲线的法向量 $\operatorname{grad} f$ 与 $\operatorname{grad}\varphi$ 共线，这就是拉格朗日乘数法。

#### 1. 极值
设 $f(x, y)$ 在 $(x_0, y_0)$ 的某邻域内有定义，若对该邻域内异于 $(x_0, y_0)$ 的点都有 $f(x, y) < f(x_0, y_0)$（或 $>$），则称 $f(x_0, y_0)$ 为==极大值==（或==极小值==），$(x_0, y_0)$ 称为==极值点==。

#### 2. 驻点
使 $f_x(x, y) = 0$，$f_y(x, y) = 0$ 同时成立的点，称为 $f$ 的==驻点==。

#### 3. 最值与有界闭区域
* **最大值、最小值**：若 $f(P_0) \ge f(P)$ 对 $D$ 上所有点 $P$ 成立，则称 $f(P_0)$ 为 $f$ 在 $D$ 上的==最大值==；最小值同理；
* **有界闭区域**：像圆盘 $x^2 + y^2 \le 1$ 这样，连成一片、包含边界、又能被一个圆盘盖住的平面区域。

#### 4. 条件极值
对自变量附加约束条件的极值称为==条件极值==，如求 $z = f(x, y)$ 在条件 $\varphi(x, y) = 0$ 下的极值；不附加条件的称为==无条件极值==。

### 〔性质〕

**① 从四面八方靠近**

**二重极限**

#### 1. 一元的工具照用
二重极限与一元极限有相同的四则运算法则；夹逼、等价无穷小、有界乘无穷小都照用（第 1 章）。
* **例**：$(x, y) \to (0, 2)$ 时，$\dfrac{\sin(xy)}{x} = \dfrac{\sin(xy)}{xy} \cdot y \to 1 \cdot 2 = 2$。

#### 2. 连续函数
* **多元初等函数**：一切多元初等函数在其定义区域内连续，求极限时能直接代入；
* **运算**：连续函数的和、差、积、商（分母不为零）、复合仍连续。

**说明不存在**

#### 1. 两条路径
沿两条不同路径趋于 $(x_0, y_0)$ 时，$f$ 的极限不同，或沿某条路径极限不存在，则二重极限不存在。
* **常用路径**：$y = kx$、$y = kx^2$ 等，结果随 $k$ 变；
* **例**：$f(x, y) = \dfrac{xy}{x^2 + y^2}$ 沿 $y = kx$ 趋于原点时极限为 $\dfrac{k}{1 + k^2}$，随 $k$ 而变。

#### 2. 只验证直线不够（边界）
沿所有直线 $y = kx$ 极限都相同，也不能说明极限存在：$\dfrac{x^2y}{x^4 + y^2}$ 沿每条过原点的直线趋于原点，极限都是 $0$；沿 $y = x^2$，函数值恒为 $\dfrac{1}{2}$。

**说明存在**

#### 1. 夹逼
用一个与路径无关、且趋于 $0$ 的量控制 $|f(x, y) - A|$。
* **常用不等式**：$|xy| \le \dfrac{x^2 + y^2}{2}$，$|x| \le \sqrt{x^2 + y^2}$；
* **例**：$\left|\dfrac{x^2y}{x^2 + y^2}\right| \le |y| \to 0$，所以 $(x, y) \to (0, 0)$ 时极限为 $0$。

#### 2. 极坐标
令 $x = x_0 + \rho\cos\theta$，$y = y_0 + \rho\sin\theta$。若 $|f - A| \le g(\rho)$，$g(\rho) \to 0$，且 $g$ 与 $\theta$ 无关，则极限为 $A$。
* **对每个 $\theta$ 趋于 $0$ 不够（边界）**：那只说明沿每条射线趋于 $0$；如 $\dfrac{x^2y}{x^4 + y^2}$ 化成极坐标后，对每个固定的 $\theta$ 都趋于 $0$，极限却不存在。

**② 变化有多快**

**偏导数**

#### 1. 几何意义
$f_x(x_0, y_0)$ 是曲面 $z = f(x, y)$ 与平面 $y = y_0$ 的交线，在点 $(x_0, y_0, f(x_0, y_0))$ 处的切线对 $x$ 轴的斜率；$f_y(x_0, y_0)$ 同理。

#### 2. 一点处的偏导数
* **先代值，再求导**：$f_x(x_0, y_0)$ 就是一元函数 $f(x, y_0)$ 在 $x_0$ 处的导数，所以先把 $y = y_0$ 代进去，再对 $x$ 求导；
* **分段点**：只能用定义，如 $f_x(0, 0) = \lim\limits_{x \to 0}\dfrac{f(x, 0) - f(0, 0)}{x}$。

**可微**

#### 1. 可微的必要条件
若 $f(x, y)$ 在 $(x_0, y_0)$ 可微，则：
* **连续**：$f$ 在 $(x_0, y_0)$ 连续；
* **偏导数存在**：$f_x(x_0, y_0)$、$f_y(x_0, y_0)$ 存在，且 $A = f_x(x_0, y_0)$，$B = f_y(x_0, y_0)$，即
  $$\mathrm{d}z = f_x(x_0, y_0)\,\mathrm{d}x + f_y(x_0, y_0)\,\mathrm{d}y$$
* **依据**：$\Delta x, \Delta y \to 0$ 时 $\Delta z \to 0$，得连续；令 $\Delta y = 0$，$\Delta z = A\Delta x + o(|\Delta x|)$，两边除以 $\Delta x$ 再取极限，得 $f_x(x_0, y_0) = A$。

#### 2. 可微的充分条件
若 $f_x(x, y)$、$f_y(x, y)$ 在 $(x_0, y_0)$ ==连续==，则 $f$ 在 $(x_0, y_0)$ 可微。

#### 3. 用定义判断可微
1. **求偏导数**：先求出 $f_x(x_0, y_0)$、$f_y(x_0, y_0)$，若不存在则不可微；
2. **验证极限**：判断
   $\lim\limits_{\rho \to 0} \dfrac{\Delta z - f_x\Delta x - f_y\Delta y}{\rho} = 0$
   （$f_x, f_y$ 取在 $(x_0, y_0)$ 处）是否成立，成立则可微，否则不可微。

* **这是一个二重极限**：用说明极限存在、不存在的办法判断。

#### 4. 全微分的计算
* **二元**：$\mathrm{d}z = f_x\,\mathrm{d}x + f_y\,\mathrm{d}y$；
* **三元**：$u = f(x, y, z)$ 时，$\mathrm{d}u = f_x\,\mathrm{d}x + f_y\,\mathrm{d}y + f_z\,\mathrm{d}z$。

**四个概念**

#### 1. 成立的推出
* 偏导数连续 $\implies$ 可微；
* 可微 $\implies$ 连续；可微 $\implies$ 偏导数存在。

#### 2. 不成立的推出
* 以上各箭头，反过来都不成立；
* 连续与偏导数存在，谁也推不出谁；
* **与一元不同**：一元函数可导 $\iff$ 可微，且可导 $\implies$ 连续；二元函数偏导数存在，连连续都推不出。

**原点处的反例（边界）**

#### 1. 四个反例
下面的函数都在原点讨论；分式与含 $\sin$ 的两个，补定义 $f(0, 0) = 0$。
* **$\sqrt{x^2 + y^2}$**：连续；但 $\dfrac{f(x, 0) - f(0, 0)}{x} = \dfrac{|x|}{x}$ 没有极限，偏导数不存在；
* **$\dfrac{xy}{x^2 + y^2}$**：$f(x, 0) = f(0, y) = 0$，两个偏导数都是 $0$；但沿 $y = x$ 函数值恒为 $\dfrac{1}{2}$，不连续；
* **$\sqrt{|xy|}$**：连续，两个偏导数都是 $0$；但取 $\Delta y = \Delta x$ 时 $\dfrac{\Delta z}{\rho} = \dfrac{1}{\sqrt{2}}$，不趋于 $0$，不可微；
* **$(x^2 + y^2)\sin\dfrac{1}{x^2 + y^2}$**：$\left|\dfrac{\Delta z}{\rho}\right| \le \rho \to 0$，可微，两个偏导数都是 $0$；但 $x \ne 0$ 时 $f_x(x, 0) = 2x\sin\dfrac{1}{x^2} - \dfrac{2}{x}\cos\dfrac{1}{x^2}$，$x \to 0$ 时没有极限，偏导数不连续。

**③ 怎么求偏导**

**复合函数**

#### 1. 多元复合函数求导法则
设 $u = \varphi(x, y)$、$v = \psi(x, y)$ 在点 $(x, y)$ 处偏导数存在，$z = f(u, v)$ 在对应点 $(u, v)$ 处可微，则 $z = f[\varphi(x, y), \psi(x, y)]$ 在 $(x, y)$ 处的偏导数存在，且
$$\dfrac{\partial z}{\partial x} = \dfrac{\partial z}{\partial u}\dfrac{\partial u}{\partial x} + \dfrac{\partial z}{\partial v}\dfrac{\partial v}{\partial x}$$
$$\dfrac{\partial z}{\partial y} = \dfrac{\partial z}{\partial u}\dfrac{\partial u}{\partial y} + \dfrac{\partial z}{\partial v}\dfrac{\partial v}{\partial y}$$

* **记法**：画出变量关系图，$z$ 到 $x$ 有几条路径，就有几项；每一项是这条路径上各层偏导数的乘积；
* **依据**：$f$ 可微，$\Delta z = f_u\Delta u + f_v\Delta v + o\big(\sqrt{(\Delta u)^2 + (\Delta v)^2}\big)$；只让 $x$ 变，两边除以 $\Delta x$，再令 $\Delta x \to 0$。

#### 2. 其他复合情形
* **中间变量是一元函数（全导数）**：$z = f(u, v)$，$u = \varphi(t)$，$v = \psi(t)$，则
  $$\dfrac{\mathrm{d}z}{\mathrm{d}t} = \dfrac{\partial z}{\partial u}\varphi'(t) + \dfrac{\partial z}{\partial v}\psi'(t)$$
* **自变量也直接出现**：$z = f(u, x, y)$，$u = \varphi(x, y)$，则
  $$\dfrac{\partial z}{\partial x} = \dfrac{\partial f}{\partial u}\dfrac{\partial u}{\partial x} + \dfrac{\partial f}{\partial x}$$
  其中 $\dfrac{\partial z}{\partial x}$ 是复合后对 $x$ 的偏导数，$\dfrac{\partial f}{\partial x}$ 是把 $u, y$ 看作常数时 $f$ 对第二个变量的偏导数。

#### 3. 二阶偏导数
* **$f_1'$、$f_2'$ 仍是复合函数（易错）**：$f_1'$ 是 $u, v$ 的函数，而 $u, v$ 又是 $x, y$ 的函数，所以对 $y$ 求偏导时还要再用一次链式：
  $$\dfrac{\partial f_1'}{\partial y} = f_{11}''\dfrac{\partial u}{\partial y} + f_{12}''\dfrac{\partial v}{\partial y}$$
* **乘积**：$z_x$ 的每一项通常是「中间变量的偏导数 $\times f_i'$」，再求偏导时先用乘积法则。

#### 4. 混合偏导数相等的条件
若 $f_{xy}(x, y)$ 与 $f_{yx}(x, y)$ 在区域 $D$ 内连续，则在 $D$ 内
$$f_{xy}(x, y) = f_{yx}(x, y)$$

即二阶混合偏导数在连续的条件下与求导次序无关。
* **抽象函数**：二阶偏导数连续时 $f_{12}'' = f_{21}''$，合并同类项时要用。

**隐函数**

#### 1. 一个方程确定的一元隐函数
设 $F(x, y)$ 在 $P(x_0, y_0)$ 的某邻域内具有连续偏导数，$F(x_0, y_0) = 0$，$F_y(x_0, y_0) \neq 0$，则方程 $F(x, y) = 0$ 在 $x_0$ 的某邻域内能唯一确定一个具有连续导数的函数 $y = f(x)$，满足 $y_0 = f(x_0)$，且
$$\dfrac{\mathrm{d}y}{\mathrm{d}x} = -\dfrac{F_x}{F_y}$$

#### 2. 一个方程确定的二元隐函数
设 $F(x, y, z)$ 在 $(x_0, y_0, z_0)$ 的某邻域内具有连续偏导数，$F(x_0, y_0, z_0) = 0$，$F_z(x_0, y_0, z_0) \neq 0$，则方程 $F(x, y, z) = 0$ 在该点附近唯一确定具有连续偏导数的函数 $z = z(x, y)$，且
$$\dfrac{\partial z}{\partial x} = -\dfrac{F_x}{F_z}, \qquad \dfrac{\partial z}{\partial y} = -\dfrac{F_y}{F_z}$$

* **依据**：恒等式 $F(x, y, z(x, y)) \equiv 0$ 两边对 $x$ 求偏导，得 $F_x + F_z z_x = 0$，解出 $z_x$；
* **两种算法别混（易错）**：用公式时，求 $F_x$ 把 $x, y, z$ 都当自变量，$z$ 当常数；两边直接求偏导时，$z$ 是 $x, y$ 的函数。

#### 3. 隐函数的二阶偏导数
对 $z_x$ 的表达式再求偏导，其中的 $z$ 仍是 $x, y$ 的函数；求完后把 $z_x$、$z_y$ 代进去。

#### 4. 方程组确定的隐函数
设方程组 $\begin{cases} F(x, y, u, v) = 0 \\ G(x, y, u, v) = 0 \end{cases}$ 在某点附近确定 $u = u(x, y)$，$v = v(x, y)$，且雅可比行列式 $J = \dfrac{\partial(F, G)}{\partial(u, v)} \neq 0$：
1. **两边对 $x$ 求偏导**：得关于 $u_x, v_x$ 的线性方程组
   $$\begin{cases} F_x + F_u u_x + F_v v_x = 0 \\ G_x + G_u u_x + G_v v_x = 0 \end{cases}$$
2. **解方程组**：由 $J \neq 0$ 解出唯一的 $u_x, v_x$（克拉默法则）；对 $y$ 的偏导数同理。

**全微分**

#### 1. 全微分形式不变性
设 $z = f(u, v)$ 可微，无论 $u, v$ 是自变量还是中间变量，都有
$$\mathrm{d}z = \dfrac{\partial z}{\partial u}\,\mathrm{d}u + \dfrac{\partial z}{\partial v}\,\mathrm{d}v$$

* **依据**：$u, v$ 是 $x, y$ 的函数时，把 $\mathrm{d}u = u_x\,\mathrm{d}x + u_y\,\mathrm{d}y$、$\mathrm{d}v = v_x\,\mathrm{d}x + v_y\,\mathrm{d}y$ 代入右边，按 $\mathrm{d}x$、$\mathrm{d}y$ 合并，两个系数正是链式法则给出的 $z_x$、$z_y$。

#### 2. 全微分法
对方程两边取全微分，整理成 $\mathrm{d}z = P\,\mathrm{d}x + Q\,\mathrm{d}y$，则 $z_x = P$，$z_y = Q$；方程组同样两边取全微分，解出 $\mathrm{d}u$、$\mathrm{d}v$。
* **用处**：不必分清谁是自变量、谁是中间变量，一次得出全部一阶偏导数。

**常见操作**

#### 1. 用变量代换化简含偏导数的方程
设 $u = u(x, y)$，$v = v(x, y)$，把 $z$ 看成 $u, v$ 的函数：
1. **一阶**：$z_x = z_uu_x + z_vv_x$，$z_y = z_uu_y + z_vv_y$；
2. **二阶**：$z_u$、$z_v$ 仍是 $u, v$ 的函数，再对 $x$、$y$ 求偏导时，还要再用一次链式；
3. **代入**：代入原方程，合并同类项，比较系数。

**④ 往哪个方向升得最快**

**方向导数**

#### 1. 方向导数的计算
若 $f(x, y)$ 在 $(x_0, y_0)$ ==可微==，则沿任一方向 $l$ 的方向导数都存在，且
$$\dfrac{\partial f}{\partial l}\Big|_{(x_0, y_0)} = f_x(x_0, y_0)\cos\alpha + f_y(x_0, y_0)\cos\beta$$

* **依据**：取 $\Delta x = t\cos\alpha$，$\Delta y = t\cos\beta$，则 $\rho = t$，由可微 $\Delta z = f_x t\cos\alpha + f_y t\cos\beta + o(t)$，两边除以 $t$ 再令 $t \to 0^+$；
* **三元函数**：$\dfrac{\partial f}{\partial l} = f_x\cos\alpha + f_y\cos\beta + f_z\cos\gamma$。

**梯度**

#### 1. 梯度与方向导数的关系
设 $f$ 可微，$\theta$ 为 $\operatorname{grad} f$ 与 $\boldsymbol{e}_l$ 的夹角，则
$$\dfrac{\partial f}{\partial l} = \operatorname{grad} f \cdot \boldsymbol{e}_l = |\operatorname{grad} f|\cos\theta$$

* **最大值**：沿梯度方向（$\theta = 0$），方向导数取最大值 $|\operatorname{grad} f|$；
* **最小值**：沿梯度反方向，方向导数取最小值 $-|\operatorname{grad} f|$；
* **为零**：与梯度垂直的方向（$\theta = \dfrac{\pi}{2}$），方向导数为 $0$。

#### 2. 梯度垂直于等值线
设 $f$ 可微，$\operatorname{grad} f(x_0, y_0) \ne \boldsymbol{0}$，则 $\operatorname{grad} f(x_0, y_0)$ 是等值线 $f(x, y) = f(x_0, y_0)$ 在该点的法向量；三元函数的梯度，是等值面的法向量。
* **依据**：沿等值线 $x = x(t)$，$y = y(t)$ 走，$f(x(t), y(t)) \equiv c$，对 $t$ 求导得 $f_x x'(t) + f_y y'(t) = 0$，即梯度与等值线的切向量垂直。

**单侧极限（边界）**

#### 1. 方向导数与偏导数
* **定义不同**：方向导数是单侧极限（$t \to 0^+$），偏导数是双侧极限；
* **偏导数存在时**：沿 $x$ 轴正向的方向导数是 $f_x$，沿 $x$ 轴负向的是 $-f_x$；
* **反过来不行**：$\sqrt{x^2 + y^2}$ 在原点沿任何方向的方向导数都是 $1$，偏导数却不存在。

#### 2. 方向导数都存在，推不出可微
$\sqrt{x^2 + y^2}$ 在原点沿各方向的方向导数都存在，但偏导数不存在，所以不可微。

**⑤ 切平面和切线**

**曲面**

#### 1. 曲面 $F(x, y, z) = 0$
设 $F$ 在 $M_0(x_0, y_0, z_0)$ 处偏导数连续且不全为零：
* **法向量**：$\boldsymbol{n} = (F_x, F_y, F_z)\big|_{M_0}$；
* **切平面**：$F_x(M_0)(x - x_0) + F_y(M_0)(y - y_0) + F_z(M_0)(z - z_0) = 0$；
* **法线**：
  $$\dfrac{x - x_0}{F_x(M_0)} = \dfrac{y - y_0}{F_y(M_0)} = \dfrac{z - z_0}{F_z(M_0)}$$
* **依据**：曲面上过 $M_0$ 的任一曲线 $x = x(t)$，$y = y(t)$，$z = z(t)$ 满足 $F(x(t), y(t), z(t)) \equiv 0$，对 $t$ 求导得 $\operatorname{grad} F \cdot (x'(t), y'(t), z'(t)) = 0$：每条曲线的切向量都垂直于 $\operatorname{grad} F$，所以它们在同一个平面上，$\operatorname{grad} F$ 就是这个平面的法向量。

#### 2. 显式曲面 $z = f(x, y)$
令 $F = f(x, y) - z$，得：
* **法向量**：$\boldsymbol{n} = (f_x(x_0, y_0),\ f_y(x_0, y_0),\ -1)$；
* **切平面**：$z - z_0 = f_x(x_0, y_0)(x - x_0) + f_y(x_0, y_0)(y - y_0)$，右端即全微分 $\mathrm{d}z$。

**曲线**

#### 1. 参数方程曲线的切线与法平面
设曲线 $\Gamma: x = \varphi(t)$，$y = \psi(t)$，$z = \omega(t)$，$t = t_0$ 对应点 $M_0(x_0, y_0, z_0)$，且 $\varphi'(t_0), \psi'(t_0), \omega'(t_0)$ 不全为零：
* **切向量**：$\boldsymbol{T} = (\varphi'(t_0), \psi'(t_0), \omega'(t_0))$；
* **切线**：
  $$\dfrac{x - x_0}{\varphi'(t_0)} = \dfrac{y - y_0}{\psi'(t_0)} = \dfrac{z - z_0}{\omega'(t_0)}$$
* **法平面**：$\varphi'(t_0)(x - x_0) + \psi'(t_0)(y - y_0) + \omega'(t_0)(z - z_0) = 0$；
* **依据**：割线 $M_0M$ 的方向向量可取 $\left(\dfrac{\Delta x}{\Delta t}, \dfrac{\Delta y}{\Delta t}, \dfrac{\Delta z}{\Delta t}\right)$，令 $\Delta t \to 0$，各分量趋于导数。

#### 2. 以 $x$ 为参数
曲线 $y = \varphi(x)$，$z = \psi(x)$ 可取 $x$ 为参数，切向量为 $(1, \varphi'(x_0), \psi'(x_0))$。

#### 3. 交线式曲线的切向量
设曲线 $\Gamma: \begin{cases} F(x, y, z) = 0 \\ G(x, y, z) = 0 \end{cases}$，则在 $M_0$ 处的切向量可取
$$\boldsymbol{T} = (F_x, F_y, F_z) \times (G_x, G_y, G_z)\Big|_{M_0}$$

* **依据**：切线同时在两张曲面的切平面内，所以切向量同时垂直于两个法向量；
* **另一种算法**：方程组两边对 $x$ 求导，解出 $y'(x_0)$、$z'(x_0)$，切向量为 $(1, y'(x_0), z'(x_0))$。

**⑥ 最高点和最低点**

**无条件极值**

#### 1. 极值的必要条件
若 $f(x, y)$ 在 $(x_0, y_0)$ 处偏导数存在且取得极值，则
$$f_x(x_0, y_0) = 0, \quad f_y(x_0, y_0) = 0$$

* **依据**：一元函数 $f(x, y_0)$ 在 $x_0$ 处取得极值且可导，所以导数为 $0$（第 2 章）；$f_y$ 同理；
* **候选点**：极值点只可能是驻点，或偏导数不存在的点。

#### 2. 二元函数的二阶泰勒公式
设 $f(x, y)$ 在 $(x_0, y_0)$ 的某邻域内有连续的二阶偏导数，则
$$\begin{aligned} & f(x_0 + h, y_0 + k) \\ = {} & f(x_0, y_0) + f_x h + f_y k \\ & + \dfrac{1}{2}\left(f_{xx}h^2 + 2f_{xy}hk + f_{yy}k^2\right) + o(\rho^2) \end{aligned}$$

其中各偏导数取在 $(x_0, y_0)$ 处，$\rho = \sqrt{h^2 + k^2}$。

#### 3. 极值的充分条件
设 $f(x, y)$ 在驻点 $(x_0, y_0)$ 的某邻域内有连续的二阶偏导数，记
$$A = f_{xx}, \quad B = f_{xy}, \quad C = f_{yy}$$

（均取在 $(x_0, y_0)$ 处）：
* **$AC - B^2 > 0$**：取得极值，$A < 0$ 时为==极大值==，$A > 0$ 时为==极小值==；
* **$AC - B^2 < 0$**：不是极值；
* **$AC - B^2 = 0$**：不能确定，需另行讨论。
* **依据**：驻点处一次项为 $0$，增量的符号由二次项 $Ah^2 + 2Bhk + Ck^2$ 决定，它是矩阵为
  $\begin{pmatrix} A & B \\ B & C \end{pmatrix}$
  的二次型。顺序主子式 $A > 0$、$AC - B^2 > 0$ 时正定，增量为正，极小；$A < 0$、$AC - B^2 > 0$ 时负定，增量为负，极大；$AC - B^2 < 0$ 时不定，沿某些方向增、某些方向减，不是极值（线性代数第 4 章）。
* **$AC - B^2 = 0$（边界）**：二次型只是半定，沿某个方向二次项为 $0$，由更高阶的项决定；可沿过该点的几条特殊路径比较函数值。

#### 4. 由方程确定的函数的极值
设 $z = z(x, y)$ 由 $F(x, y, z) = 0$ 确定，$F_z \ne 0$：
* **驻点**：$z_x = -\dfrac{F_x}{F_z} = 0$，$z_y = -\dfrac{F_y}{F_z} = 0$，即 $F_x = 0$，$F_y = 0$，与 $F = 0$ 联立；
* **二阶**：方程两边求两次偏导，代入 $z_x = z_y = 0$，得
  $$A = -\dfrac{F_{xx}}{F_z}, \quad B = -\dfrac{F_{xy}}{F_z}, \quad C = -\dfrac{F_{yy}}{F_z}$$
  （各偏导数取在该点）。

**最值**

#### 1. 有界闭区域上连续函数的性质
设 $f(x, y)$ 在有界闭区域 $D$ 上连续，则：
* **有界与最值**：$f$ 在 $D$ 上有界，且能取得最大值与最小值；
* **介值**：$f$ 能取得介于最小值与最大值之间的任何值。

#### 2. 有界闭区域上的最值
设 $f(x, y)$ 在有界闭区域 $D$ 上连续：
1. **内部**：求出 $D$ 内的驻点与偏导数不存在的点，算出函数值；
2. **边界**：求出 $f$ 在 $D$ 的边界上的最大值与最小值（代入化为一元函数，或用条件极值）；
3. **比较**：以上所有值中最大者为最大值，最小者为最小值。

* **不必判断极值**：候选点的函数值直接比较，不用算 $AC - B^2$。

#### 3. 实际问题
根据问题的意义知道最值一定在区域内部取得，而可能的极值点只有一个时，这个点就是最值点。

**条件极值**

#### 1. 拉格朗日乘数法
求 $z = f(x, y)$ 在条件 $\varphi(x, y) = 0$ 下的可能极值点：
1. **构造拉格朗日函数**：$L(x, y, \lambda) = f(x, y) + \lambda\varphi(x, y)$；
2. **求驻点**：解方程组
   $$\begin{cases} L_x = f_x(x, y) + \lambda\varphi_x(x, y) = 0 \\ L_y = f_y(x, y) + \lambda\varphi_y(x, y) = 0 \\ L_\lambda = \varphi(x, y) = 0 \end{cases}$$
3. **判定**：所得 $(x, y)$ 为可能的极值点，是否为极值点一般由问题的实际意义判定。

* **依据**：沿约束曲线走，设曲线在该点的切向量为 $\boldsymbol{T}$。$f$ 在这里取极值，沿 $\boldsymbol{T}$ 的变化率为 $0$，即 $\operatorname{grad} f \cdot \boldsymbol{T} = 0$；$\varphi$ 沿曲线恒为 $0$，所以 $\operatorname{grad}\varphi \cdot \boldsymbol{T} = 0$。平面上两个向量都垂直于 $\boldsymbol{T}$，所以共线：$\operatorname{grad} f + \lambda\operatorname{grad}\varphi = \boldsymbol{0}$（要求 $\operatorname{grad}\varphi \ne \boldsymbol{0}$），这正是前两个方程。几何上，$f$ 的等值线与约束曲线在这一点相切。

#### 2. 多个变量、多个约束
求 $u = f(x, y, z)$ 在条件 $\varphi(x, y, z) = 0$，$\psi(x, y, z) = 0$ 下的极值：
* **拉格朗日函数**：$L = f(x, y, z) + \lambda\varphi(x, y, z) + \mu\psi(x, y, z)$；
* **方程组**：令 $L_x = L_y = L_z = 0$，与 $\varphi = 0$、$\psi = 0$ 联立求解。

#### 3. 目标是距离
距离带根号，换成距离的平方作目标函数，最值点不变，方程组简单得多。

### 意义

本卡在做题时专门用于解决以下 15 类确定性目标，按站排列：

**① 从四面八方靠近**

* **1. 求二重极限，或说明极限不存在**
  * **问题**：求 $\lim\limits_{(x, y) \to (x_0, y_0)} f(x, y)$；说明极限不存在；判断分段函数在分段点处是否连续。
  * **目标**：先猜极限存不存在：存在就用与路径无关的量去夹，不存在就找两条路径。
  * **调用**：
    * 一元的工具：四则、等价无穷小、有界乘无穷小、夹逼（第 1 章）；
    * 常用不等式：$|xy| \le \dfrac{x^2 + y^2}{2}$，$|x| \le \sqrt{x^2 + y^2}$；
    * 两条路径极限不同 $\implies$ 极限不存在。
  * **行动**：
    1. 能代入就代入：多元初等函数在定义区域内连续；
    2. 代不进去，先用一元的工具：如 $(x, y) \to (0, 2)$ 时，$\dfrac{\sin(xy)}{x} = \dfrac{\sin(xy)}{xy} \cdot y \to 2$；
    3. 分子的次数比分母高：放缩夹逼；如 $\left|\dfrac{x^2y}{x^2 + y^2}\right| \le |y| \to 0$，极限为 $0$；
    4. 分子分母次数相同：多半不存在，取 $y = kx$；如 $\dfrac{xy}{x^2 + y^2}$ 得 $\dfrac{k}{1 + k^2}$，随 $k$ 变，不存在；沿所有直线都相同时，再试 $y = kx^2$ 等曲线；
    5. 判断连续：求出分段点处的极限，与函数值比较；如 $\dfrac{x^2y}{x^2 + y^2}$（补定义 $f(0, 0) = 0$）在原点的极限为 $0$，等于函数值，连续。

**② 变化有多快**

* **2. 求一点处的偏导数、全微分**
  * **问题**：求 $f_x(x_0, y_0)$、$f_y(x_0, y_0)$；分段函数在分段点处的偏导数；求 $\mathrm{d}z$ 或 $\mathrm{d}z\big|_{(x_0, y_0)}$。
  * **目标**：把偏导数变成一元函数的导数。
  * **调用**：
    * 先代值、再求导：$f_x(x_0, y_0)$ 是 $f(x, y_0)$ 在 $x_0$ 处的导数；
    * 定义：$f_x(0, 0) = \lim\limits_{x \to 0}\dfrac{f(x, 0) - f(0, 0)}{x}$；
    * 全微分：$\mathrm{d}z = f_x\,\mathrm{d}x + f_y\,\mathrm{d}y$。
  * **行动**：
    1. 求一点处的偏导数，先把另一个坐标代进去；如 $f(x, y) = x + (y - 1)\arcsin\sqrt{\dfrac{x}{y}}$，求 $f_x(x, 1)$：$f(x, 1) = x$，所以 $f_x(x, 1) = 1$；
    2. 分段点处用定义；如 $f(x, y) = \dfrac{xy}{x^2 + y^2}$，$f(0, 0) = 0$：$f(x, 0) = 0$，$f_x(0, 0) = 0$；
    3. 全微分：求出两个偏导数，代入；如 $z = e^{xy}$，$\mathrm{d}z = ye^{xy}\,\mathrm{d}x + xe^{xy}\,\mathrm{d}y$，$\mathrm{d}z\big|_{(1, 2)} = 2e^2\,\mathrm{d}x + e^2\,\mathrm{d}y$。
* **3. 判断连续、偏导数存在、可微、偏导数连续**
  * **问题**：给出一个分段函数，问它在某点是否连续、偏导数是否存在、是否可微、偏导数是否连续；或在四个概念中判断谁推出谁。
  * **目标**：按「连续 → 偏导数 → 可微 → 偏导数连续」的顺序逐个判断。
  * **调用**：
    * 可微的必要条件：可微 $\implies$ 连续，可微 $\implies$ 偏导数存在；
    * 可微的充分条件：偏导数连续 $\implies$ 可微；
    * 用定义判断可微：$\lim\limits_{\rho \to 0}\dfrac{\Delta z - f_x\Delta x - f_y\Delta y}{\rho} = 0$；
    * 四个反例。
  * **行动**：
    1. 连续：求该点的二重极限，与函数值比较；
    2. 偏导数：用定义；不连续或偏导数不存在，直接不可微；
    3. 可微：代入定义的极限；如 $\sqrt{|xy|}$ 在原点，连续，$f_x(0, 0) = f_y(0, 0) = 0$，取 $\Delta y = \Delta x$，$\dfrac{\Delta z}{\rho} = \dfrac{1}{\sqrt{2}}$，极限不为 $0$，不可微；
    4. 偏导数连续：分别求出该点以外的 $f_x(x, y)$ 和该点的 $f_x(x_0, y_0)$，看前者的极限是否等于后者；如 $(x^2 + y^2)\sin\dfrac{1}{x^2 + y^2}$ 可微，但 $f_x(x, 0)$ 在 $x \to 0$ 时没有极限，偏导数不连续；
    5. 选择题判断谁推出谁：对照四个反例。

**③ 怎么求偏导**

* **4. 求复合函数的偏导数（含抽象函数、二阶）**
  * **问题**：$z = f(u, v)$，$u, v$ 是 $x, y$ 的函数，$f$ 具有二阶连续偏导数，求 $z_x$、$z_{xy}$ 等。
  * **目标**：按变量关系图写出一阶，再把 $f_1'$、$f_2'$ 当复合函数求二阶。
  * **调用**：
    * 链式法则：$z_x = f_1'u_x + f_2'v_x$；
    * $\dfrac{\partial f_1'}{\partial y} = f_{11}''u_y + f_{12}''v_y$；
    * 二阶偏导数连续时 $f_{12}'' = f_{21}''$。
  * **行动**：
    1. 画变量关系图，写一阶；如 $z = f(xy, x + y)$：$u = xy$，$v = x + y$，$z_x = yf_1' + f_2'$；
    2. 对 $y$ 求偏导：$yf_1'$ 先用乘积法则，得 $f_1' + y\dfrac{\partial f_1'}{\partial y}$；$f_1'$、$f_2'$ 各再用一次链式：$\dfrac{\partial f_1'}{\partial y} = xf_{11}'' + f_{12}''$，$\dfrac{\partial f_2'}{\partial y} = xf_{21}'' + f_{22}''$；
    3. 合并：
       $\begin{aligned} z_{xy} = {} & f_1' + xyf_{11}'' \\ & + (x + y)f_{12}'' + f_{22}'' \end{aligned}$
    4. 函数是具体的：能先化简就先化简，再求偏导。
* **5. 求一个方程确定的隐函数的偏导数**
  * **问题**：$z = z(x, y)$ 由 $F(x, y, z) = 0$ 确定，求 $z_x$、$z_y$、$\mathrm{d}z$、$z_{xx}$。
  * **目标**：选一种算法求一阶，二阶时记住 $z$ 是 $x, y$ 的函数。
  * **调用**：
    * 公式：$z_x = -\dfrac{F_x}{F_z}$，$z_y = -\dfrac{F_y}{F_z}$；
    * 全微分法：两边取全微分，整理成 $\mathrm{d}z = P\,\mathrm{d}x + Q\,\mathrm{d}y$。
  * **行动**：
    1. 一阶：如 $x^2 + y^2 + z^2 = 4z$，令 $F = x^2 + y^2 + z^2 - 4z$，$F_x = 2x$，$F_z = 2z - 4$，$z_x = \dfrac{x}{2 - z}$；同理 $z_y = \dfrac{y}{2 - z}$；
    2. 全微分法：$2x\,\mathrm{d}x + 2y\,\mathrm{d}y + 2z\,\mathrm{d}z = 4\,\mathrm{d}z$，$\mathrm{d}z = \dfrac{x\,\mathrm{d}x + y\,\mathrm{d}y}{2 - z}$，结果相同；
    3. 二阶：对 $z_x = \dfrac{x}{2 - z}$ 再对 $x$ 求偏导，$z$ 仍是 $x$ 的函数：
       $\begin{aligned} z_{xx} & = \dfrac{(2 - z) + xz_x}{(2 - z)^2} \\ & = \dfrac{(2 - z)^2 + x^2}{(2 - z)^3} \end{aligned}$
    4. 求一点处的值：先由方程算出该点的 $z$，再代入。
* **6. 求方程组确定的隐函数的偏导数**
  * **问题**：$u = u(x, y)$，$v = v(x, y)$ 由两个方程确定，求 $u_x$、$v_x$ 等。
  * **目标**：两边求偏导，解一个二元一次方程组。
  * **调用**：方程组两边对 $x$ 求偏导；$J \ne 0$ 时用克拉默法则。
  * **行动**：
    1. 两边对 $x$ 求偏导，$u, v$ 都是 $x, y$ 的函数；如 $xu - yv = 0$，$yu + xv = 1$：
       $$\begin{cases} xu_x - yv_x = -u \\ yu_x + xv_x = -v \end{cases}$$
    2. 系数行列式 $J = x^2 + y^2 \ne 0$，解出
       $$u_x = -\dfrac{xu + yv}{x^2 + y^2}, \quad v_x = \dfrac{yu - xv}{x^2 + y^2}$$
    3. 对 $y$ 的偏导数同理；也可以两边取全微分，一次解出 $\mathrm{d}u$、$\mathrm{d}v$。
* **7. 用变量代换化简含偏导数的方程**
  * **问题**：作变换 $u = u(x, y)$，$v = v(x, y)$，把含 $z_{xx}, z_{xy}, z_{yy}$ 的方程化成指定形式，求变换中的参数。
  * **目标**：把对 $x, y$ 的偏导数全部换成对 $u, v$ 的偏导数。
  * **调用**：链式法则；$z_u$、$z_v$ 仍是 $u, v$ 的函数；二阶偏导数连续时 $z_{uv} = z_{vu}$。
  * **行动**：
    1. 写一阶；如 $u = x + ay$，$v = x + by$：$z_x = z_u + z_v$，$z_y = az_u + bz_v$；
    2. 写二阶：$z_{xx} = z_{uu} + 2z_{uv} + z_{vv}$，$z_{xy} = az_{uu} + (a + b)z_{uv} + bz_{vv}$，$z_{yy} = a^2z_{uu} + 2abz_{uv} + b^2z_{vv}$；
    3. 代入原方程比较系数；如要把 $4z_{xx} + 12z_{xy} + 5z_{yy} = 0$ 化成 $z_{uv} = 0$：$z_{uu}$、$z_{vv}$ 的系数为 $0$，即 $5a^2 + 12a + 4 = 0$，$5b^2 + 12b + 4 = 0$；$z_{uv}$ 的系数 $8 + 12(a + b) + 10ab$ 不能为 $0$，而 $a = b$ 时它恰为 $0$，所以 $a \ne b$，取 $a = -2$，$b = -\dfrac{2}{5}$（或对调）。

**④ 往哪个方向升得最快**

* **8. 求方向导数**
  * **问题**：求函数在某点沿某方向（某向量、两点连线、曲线的切线或法线方向）的方向导数。
  * **目标**：求出梯度和单位方向向量，作数量积。
  * **调用**：
    * 可微时：$\dfrac{\partial f}{\partial l} = \operatorname{grad} f \cdot \boldsymbol{e}_l = f_x\cos\alpha + f_y\cos\beta\ (+ f_z\cos\gamma)$；
    * 不可微时：方向导数的定义。
  * **行动**：
    1. 方向化成单位向量：$\boldsymbol{e}_l = \dfrac{\boldsymbol{l}}{|\boldsymbol{l}|}$；
    2. 求该点的梯度，作数量积；如 $u = \ln\left(x + \sqrt{y^2 + z^2}\right)$ 在 $A(1, 0, 1)$ 处沿 $A$ 指向 $B(3, -2, 2)$ 的方向：$\operatorname{grad} u\big|_A = \left(\dfrac{1}{2}, 0, \dfrac{1}{2}\right)$，$\boldsymbol{e}_l = \left(\dfrac{2}{3}, -\dfrac{2}{3}, \dfrac{1}{3}\right)$，方向导数为 $\dfrac{1}{2}$；
    3. 方向是曲线的切线或曲面的法线方向：先求出切向量、法向量，再化成单位向量；
    4. 函数在该点不可微（如 $\sqrt{x^2 + y^2}$ 在原点）：用定义，$t \to 0^+$。
* **9. 求梯度、变化率最大的方向**
  * **问题**：求梯度；求函数在某点沿哪个方向增加最快、最大变化率是多少；沿哪个方向变化率为 $0$。
  * **目标**：读出梯度的方向和模。
  * **调用**：$\dfrac{\partial f}{\partial l} = |\operatorname{grad} f|\cos\theta$：最大值 $|\operatorname{grad} f|$，最小值 $-|\operatorname{grad} f|$，垂直于梯度时为 $0$。
  * **行动**：
    1. 求梯度；如 $f = x^2 + 2y^2$ 在 $(1, 1)$ 处，$\operatorname{grad} f = (2, 4)$；
    2. 增加最快：沿 $(2, 4)$，即 $\dfrac{1}{\sqrt{5}}(1, 2)$，最大变化率 $|\operatorname{grad} f| = 2\sqrt{5}$；
    3. 减少最快：沿 $-(2, 4)$；变化率为 $0$：沿与梯度垂直的 $\pm(2, -1)$，即等值线的切线方向。

**⑤ 切平面和切线**

* **10. 求曲面的切平面和法线**
  * **问题**：求曲面在某点的切平面、法线；求切平面平行于已知平面（或法线平行于已知直线）的切点。
  * **目标**：求出法向量，再按第 4 章写方程。
  * **调用**：
    * $F(x, y, z) = 0$：$\boldsymbol{n} = (F_x, F_y, F_z)$；
    * $z = f(x, y)$：$\boldsymbol{n} = (f_x, f_y, -1)$；
    * 切平面用点法式，法线用对称式（第 4 章）。
  * **行动**：
    1. 移项写成 $F = 0$，求法向量并代入该点；如球面 $x^2 + y^2 + z^2 = 14$ 在 $(1, 2, 3)$ 处：$\boldsymbol{n} = (2, 4, 6)$，取 $(1, 2, 3)$；
    2. 写方程：切平面 $x + 2y + 3z = 14$；法线 $\dfrac{x - 1}{1} = \dfrac{y - 2}{2} = \dfrac{z - 3}{3}$；
    3. 求满足条件的切点：令法向量与已知向量成比例；如 $z = x^2 + y^2$ 上切平面平行于 $2x + 4y - z = 0$ 的点：$(2x, 2y, -1) \parallel (2, 4, -1)$，得 $x = 1$，$y = 2$，切点 $(1, 2, 5)$，切平面 $2x + 4y - z = 5$。
* **11. 求曲线的切线和法平面**
  * **问题**：求参数式曲线或两曲面交线在某点的切线、法平面。
  * **目标**：求出切向量，再按第 4 章写方程。
  * **调用**：
    * 参数式：$\boldsymbol{T} = (x'(t_0), y'(t_0), z'(t_0))$；
    * 交线：$\boldsymbol{T} = \boldsymbol{n}_1 \times \boldsymbol{n}_2$；
    * 切线用对称式，法平面用点法式（第 4 章）。
  * **行动**：
    1. 参数式：如 $x = t$，$y = t^2$，$z = t^3$ 在 $t = 1$ 处，点 $(1, 1, 1)$，$\boldsymbol{T} = (1, 2, 3)$；切线 $\dfrac{x - 1}{1} = \dfrac{y - 1}{2} = \dfrac{z - 1}{3}$，法平面 $x + 2y + 3z = 6$；
    2. 交线：如 $x^2 + y^2 + z^2 = 6$ 与 $x + y + z = 0$ 在 $(1, -2, 1)$ 处：$\boldsymbol{n}_1 = (2, -4, 2)$，$\boldsymbol{n}_2 = (1, 1, 1)$，$\boldsymbol{n}_1 \times \boldsymbol{n}_2 = (-6, 0, 6)$，取 $\boldsymbol{T} = (1, 0, -1)$；
    3. 写方程：切线 $\dfrac{x - 1}{1} = \dfrac{y + 2}{0} = \dfrac{z - 1}{-1}$，法平面 $x - z = 0$。

**⑥ 最高点和最低点**

* **12. 求无条件极值**
  * **问题**：求二元函数的极值。
  * **目标**：先求全部候选点，再逐个用二阶判断。
  * **调用**：
    * 必要条件：$f_x = 0$，$f_y = 0$；
    * 充分条件：$AC - B^2 > 0$ 时有极值（$A > 0$ 极小，$A < 0$ 极大），$AC - B^2 < 0$ 时没有。
  * **行动**：
    1. 解 $f_x = 0$，$f_y = 0$；如 $f = x^3 - y^3 + 3x^2 + 3y^2 - 9x$：$f_x = 3x^2 + 6x - 9 = 0$ 得 $x = 1, -3$；$f_y = -3y^2 + 6y = 0$ 得 $y = 0, 2$，驻点有 $4$ 个；
    2. 求 $A = 6x + 6$，$B = 0$，$C = -6y + 6$，逐个判断：$(1, 0)$ 处 $AC - B^2 = 72 > 0$，$A = 12 > 0$，极小值 $f(1, 0) = -5$；$(-3, 2)$ 处 $AC - B^2 = 72 > 0$，$A = -12 < 0$，极大值 $f(-3, 2) = 31$；$(1, 2)$、$(-3, 0)$ 处 $AC - B^2 < 0$，不是极值；
    3. 偏导数不存在的点：用极值的定义判断；
    4. $AC - B^2 = 0$：沿过该点的几条路径比较函数值。
* **13. 求由方程确定的函数的极值**
  * **问题**：$z = z(x, y)$ 由 $F(x, y, z) = 0$ 确定，求 $z$ 的极值。
  * **目标**：用 $F$ 的偏导数写出驻点和 $A, B, C$。
  * **调用**：驻点 $F_x = 0$，$F_y = 0$，$F = 0$；$A = -\dfrac{F_{xx}}{F_z}$，$B = -\dfrac{F_{xy}}{F_z}$，$C = -\dfrac{F_{yy}}{F_z}$。
  * **行动**：
    1. 联立求点；如 $x^2 + y^2 + z^2 - 2x + 2y - 4z - 10 = 0$：$F_x = 2x - 2 = 0$，$F_y = 2y + 2 = 0$，得 $x = 1$，$y = -1$，代入方程 $z^2 - 4z - 12 = 0$，$z = 6$ 或 $-2$；
    2. 算 $A, B, C$：$F_{xx} = F_{yy} = 2$，$F_{xy} = 0$，$F_z = 2z - 4$；$z = 6$ 时 $F_z = 8$，$A = C = -\dfrac{1}{4}$，$B = 0$，极大值 $6$；$z = -2$ 时 $F_z = -8$，$A = C = \dfrac{1}{4}$，极小值 $-2$；
    3. 对照几何：方程是以 $(1, -1, 2)$ 为球心、$4$ 为半径的球面，最高点 $z = 6$，最低点 $z = -2$。
* **14. 求有界闭区域上的最值**
  * **问题**：求连续函数在有界闭区域上的最大值、最小值。
  * **目标**：内部的候选点加上边界上的最值，一起比较。
  * **调用**：有界闭区域上的连续函数一定取得最大值和最小值；边界上用代入或拉格朗日。
  * **行动**：
    1. 内部：求驻点和偏导数不存在的点；如 $f = x^2 + 2y^2 - 2x$，$D: x^2 + y^2 \le 4$：驻点 $(1, 0)$，$f(1, 0) = -1$；
    2. 边界：$y^2 = 4 - x^2$ 代入，$f = -x^2 - 2x + 8$，$x \in [-2, 2]$，最大值 $9$（$x = -1$），最小值 $0$（$x = 2$）；
    3. 比较：最大值 $9$，在 $(-1, \pm\sqrt{3})$ 取得；最小值 $-1$，在 $(1, 0)$ 取得；
    4. 边界不好代入（如边界是几段曲线）：分段处理，或在边界上用拉格朗日，并算上各段的端点。
* **15. 求条件极值**
  * **问题**：求函数在约束条件下的极值或最值；求曲线、曲面上离某点最近、最远的点；实际问题中的最大、最小。
  * **目标**：构造拉格朗日函数，解方程组，比较函数值。
  * **调用**：
    * $L = f + \lambda\varphi$：$L_x = L_y = 0$，$\varphi = 0$；两个约束时 $L = f + \lambda\varphi + \mu\psi$；
    * 距离换成距离的平方。
  * **行动**：
    1. 写目标函数和约束；如求曲线 $x^2 + xy + y^2 = 3$ 上离原点最近、最远的点：目标 $f = x^2 + y^2$，约束 $\varphi = x^2 + xy + y^2 - 3$；
    2. 列方程：$2x + \lambda(2x + y) = 0$，$2y + \lambda(x + 2y) = 0$；
    3. 先消去 $\lambda$：两式移项相比，$x(x + 2y) = y(2x + y)$，即 $x^2 = y^2$；
    4. 代回约束：$y = x$ 时 $x = \pm 1$，得 $(1, 1)$、$(-1, -1)$，$f = 2$；$y = -x$ 时 $x = \pm\sqrt{3}$，得 $(\sqrt{3}, -\sqrt{3})$、$(-\sqrt{3}, \sqrt{3})$，$f = 6$；
    5. 比较：最近距离 $\sqrt{2}$，最远距离 $\sqrt{6}$；实际问题中可能的极值点只有一个时，它就是所求的点。
