### 〔定义〕

**① 怎么列方程，解是什么**

#### 1. 微分方程与阶：方程里有导数
* **例**：$y' = 2x$ 是一阶的，$y'' + y = 0$ 是二阶的，$y''' + (y')^5 = x$ 是三阶的；阶看导数的阶数，不看次数。
* **和代数方程对照**：代数方程的未知数是一个数；微分方程的未知数是一个函数。

#### 2. 解、通解与特解：一族曲线和其中一条
* **例**：$y' = 2x$ 的通解是 $y = x^2 + C$，是一族上下平移的抛物线；过 $(0, 1)$ 的那一条 $y = x^2 + 1$ 是特解。
* **独立的意思**：$y = C_1e^x + C_2e^x$ 只相当于一个常数 $(C_1 + C_2)e^x$，不是 $y'' - y = 0$ 的通解。
* **通解不一定包含所有解**：$y' = y^2$ 的通解 $y = -\dfrac{1}{x + C}$ 不含 $y = 0$，它是另外的解。

#### 3. 初始条件与初值问题：定出那一条
* **个数**：$n$ 阶方程要 $n$ 个条件，二阶的常给 $y(x_0)$ 和 $y'(x_0)$。
* **从哪来**：几何题里是曲线过的点、该点的斜率；积分方程里是积分上下限相等那一点的值。

**② 一阶方程怎么积出来**

#### 1. 可分离变量的方程：右边能拆成乘积
* **例**：$y' = xy^2$ 能分（$f = x$，$g = y^2$）；$y' = x + y$ 不能分。
* **判断**：右边能写成「只含 $x$ 的式子」乘「只含 $y$ 的式子」。

#### 2. 齐次方程：右边只依赖 $\dfrac{y}{x}$
* **例**：$y' = \dfrac{x + y}{x - y}$，分子分母同除以 $x$，得 $\dfrac{1 + y/x}{1 - y/x}$，是齐次方程。
* **怎么认**：把 $x, y$ 同时换成 $tx, ty$，右边不变。
* **和线性方程里的「齐次」不同**：这里说的是右边的形状；线性方程的齐次是指右端为 $0$。

#### 3. 一阶线性方程：$y$ 和 $y'$ 都是一次的
* **例**：$y' + \dfrac{y}{x} = \sin x$ 是线性的；$y' + y^2 = x$ 不是（$y^2$）；$yy' = x$ 不是（$yy'$）。
* **标准形**：$y'$ 的系数要化成 $1$，才能读出 $P$、$Q$。

#### 4. 伯努利方程：比线性多一个 $y^n$
* **例**：$y' + y = xy^3$，$n = 3$。
* **为什么能化**：除以 $y^n$ 后，$y^{-n}y'$ 正好是 $z = y^{1-n}$ 的导数的 $\dfrac{1}{1 - n}$ 倍。

#### 5. 全微分方程与积分因子：左边是某个函数的全微分
* **例**：$y\,\mathrm{d}x + x\,\mathrm{d}y = 0$，左边是 $\mathrm{d}(xy)$，所以通解是 $xy = C$。
* **积分因子的例**：$y\,\mathrm{d}x - x\,\mathrm{d}y = 0$ 不是全微分方程；乘 $\dfrac{1}{y^2}$ 后是 $\mathrm{d}\dfrac{x}{y} = 0$。

**③ 高阶方程怎么降阶**

#### 1. 可降阶的方程：缺什么，就从哪里降
* **例**：$y'' = x + y'$ 缺 $y$；$yy'' = (y')^2$ 缺 $x$；$y'' + y = 0$ 两个都不缺，不能这样降，要用 ⑤。
* **为什么缺 $y$ 才能令 $y' = p(x)$**：方程里只剩 $x, y', y''$，换成 $x, p, p'$ 正好是 $p$ 的一阶方程。

**④ 线性方程的解的结构**

#### 1. 二阶线性方程：$y, y', y''$ 都是一次
* **例**：$y'' + xy' + e^xy = \sin x$ 是线性的，系数可以是 $x$ 的函数；$y'' + y^2 = 0$ 不是。
* **对应的齐次方程**：把右端换成 $0$，左边不变。

#### 2. 函数组的线性相关与线性无关：成不成比例
* **例**：$e^x$ 与 $xe^x$ 的比值是 $\dfrac{1}{x}$，不是常数，线性无关；$\sin 2x$ 与 $\sin x\cos x$ 的比值是 $2$，线性相关。
* **和线性代数对照**：向量组的线性相关是存在不全为零的系数使组合为零向量；这里组合为零函数，要在整个区间上恒为 $0$。

**⑤ 常系数齐次怎么解**

#### 1. 常系数线性方程：系数都是常数
* **例**：$y'' - 3y' + 2y = e^x$ 是常系数的；$y'' + xy = 0$ 不是。
* **为什么单独讲**：系数是常数，才能用 $e^{rx}$ 去试，求导后与 $e^{rx}$ 约掉。

#### 2. 特征方程与特征根：把求导换成乘 $r$
* **例**：$y'' - 3y' + 2y = 0$ 的特征方程是 $r^2 - 3r + 2 = 0$，特征根 $1$、$2$，所以 $e^x$、$e^{2x}$ 是解。
* **写法**：$y''$ 换成 $r^2$，$y'$ 换成 $r$，$y$ 换成 $1$；右端不管，只看左边。

**⑥ 常系数非齐次怎么解**

#### 1. 两类自由项：指数乘多项式，再乘正弦余弦
* **例**：$x^2$ 是 $\lambda = 0$、$m = 2$；$xe^{-x}$ 是 $\lambda = -1$、$m = 1$；$e^x\sin 2x$ 是 $\lambda = 1$、$\omega = 2$。
* **为什么只考这两类**：它们求导以后还是同一类，特解能按同样的形状设出来。

#### 2. 欧拉方程：$x$ 的次数跟着导数的阶数
* **例**：$x^2y'' + 3xy' + y = 0$ 是欧拉方程；$x^2y'' + y' = 0$ 不是（$y'$ 前面没有 $x$）。
* **为什么换 $x = e^t$**：$x$ 每乘一次，正好抵掉对 $t$ 求导时出来的 $\dfrac{1}{x}$。

### 〔性质〕

**① 怎么列方程，解是什么**

#### 1. 一阶方程解的存在唯一性：过一点只有一条
* **画面**：把平面上每一点画上斜率 $f(x, y)$ 的小线段，解曲线处处顺着小线段走；从一点出发，只有一条路。
* **例**：$y' = y$ 过 $(0, 1)$ 的解只有 $e^x$；过 $(0, 0)$ 的只有 $y = 0$。

#### 2. 列方程：几何问题：切线就是 $y'$
* **截距怎么来**：切线 $Y - y = y'(X - x)$ 里令 $X = 0$，得 $Y = y - xy'$。
* **例**：切线斜率处处等于纵坐标的 $2$ 倍，就是 $y' = 2y$，曲线是 $y = Ce^{2x}$。
* **法线**：斜率是切线斜率的负倒数 $-\dfrac{1}{y'}$。

#### 3. 列方程：物理问题：变化率就是导数
* **「成正比」**：写成等式要带一个比例系数 $k$，它和常数 $C$ 一起，用两个已知时刻的数据定出来。
* **符号**：量在减少，变化率为负，冷却、衰减方程里有负号。
* **例**：细菌数的增长率与当前数量成正比，$N' = kN$，$N = N_0e^{kt}$；数量翻倍的时间是 $\dfrac{\ln 2}{k}$。

#### 4. 含变限积分的方程：求导去掉积分
* **初始条件为什么必须读**：求导会丢掉常数；不从原方程读出 $f(a)$，解出的 $f$ 会多一个常数。
* **例**：$f(x) = 1 + \displaystyle\int_0^x f(t)\,\mathrm{d}t$：求导 $f' = f$，令 $x = 0$ 得 $f(0) = 1$，所以 $f = e^x$。

#### 5. 由方程读出导数值：不用解
* **例**：$y'' = x + y^2$，$y(0) = 1$，$y'(0) = 0$：$y''(0) = 0 + 1 = 1$；两边求导 $y''' = 1 + 2yy'$，$y'''(0) = 1$。
* **用在哪**：求含 $y(x)$ 的极限，用泰勒公式 $y = y(0) + y'(0)x + \dfrac{y''(0)}{2}x^2 + \cdots$。

**② 一阶方程怎么积出来**

**分离变量与换元**

#### 1. 分离变量法：两边各积各的
* **为什么能各积各的**：$\dfrac{y'}{g(y)} = f(x)$ 左边是 $G(y(x))$ 对 $x$ 的导数，$G$ 是 $\dfrac{1}{g}$ 的原函数。
* **常数怎么写**：积出 $\ln|y| = x + C_1$ 时，常写成 $y = Ce^x$，把 $\pm e^{C_1}$ 和 $y = 0$ 一起放进 $C$。
* **例**：$y' = xy$：$\ln|y| = \dfrac{x^2}{2} + C_1$，$y = Ce^{\frac{x^2}{2}}$，$C = 0$ 就是常数解 $y = 0$。

#### 2. 齐次方程的解法：$u = \dfrac{y}{x}$
* **为什么 $y' = u + xu'$**：$y = ux$ 两边对 $x$ 求导，乘积法则。
* **例**：$y' = \dfrac{y}{x} + 1$：$u + xu' = u + 1$，$u' = \dfrac{1}{x}$，$u = \ln|x| + C$，$y = x(\ln|x| + C)$。
* **漏解**：$\varphi(u) - u = 0$ 的根 $u_0$ 给出解 $y = u_0x$，要补上。

#### 3. 其他变量代换：看见什么换什么
* **原则**：把方程里成块出现的式子换成新变量，目标是化成可分离或线性。
* **例**：$y' = \sin^2(x - y)$：令 $u = x - y$，$u' = 1 - \sin^2 u = \cos^2 u$，$\tan u = x + C$。

**线性方程**

#### 1. 一阶线性方程的通解公式：乘积分因子
* **积分因子的作用**：$y' + Py$ 本身不是谁的导数；乘 $e^{\int P\,\mathrm{d}x}$ 后，正好是 $ye^{\int P\,\mathrm{d}x}$ 的导数。
* **例**：$y' + \dfrac{y}{x} = 1$（$x > 0$）：$e^{\int\frac{1}{x}\mathrm{d}x} = x$，$(xy)' = x$，$y = \dfrac{x}{2} + \dfrac{C}{x}$。
* **为什么只取一个原函数**：$\int P\,\mathrm{d}x$ 多一个常数，只让积分因子多乘一个常数，不影响结果。

#### 2. 常数变易法：把齐次解里的 $C$ 变成函数
* **为什么能成**：$y = C(x)y_1$ 代入后，含 $C(x)$ 的项因为 $y_1$ 是齐次解而抵消，只剩 $C'(x)$。
* **和公式的关系**：算到底就是通解公式；记不住公式时用它。

#### 3. 以 $x$ 为未知函数的线性方程：反过来看
* **例**：$y' = \dfrac{1}{x + y}$：对 $y$ 不是线性的；倒过来 $\dfrac{\mathrm{d}x}{\mathrm{d}y} = x + y$，即 $\dfrac{\mathrm{d}x}{\mathrm{d}y} - x = y$，是线性的，$x = Ce^y - y - 1$。
* **信号**：$y'$ 的式子里分母含 $x$ 的一次，分子只有 $y$。

#### 4. 伯努利方程的解法：换成 $z = y^{1-n}$
* **例**：$y' + y = y^2$：$n = 2$，$z = y^{-1}$，$z' - z = -1$，$z = 1 + Ce^x$，$y = \dfrac{1}{1 + Ce^x}$。
* **系数别漏**：$z$ 的方程里 $P$、$Q$ 都乘了 $1 - n$。

**全微分方程**

#### 1. 全微分方程的解法：求出 $u$，令 $u = C$
* **为什么通解是 $u = C$**：$\mathrm{d}u = 0$ 说明 $u$ 沿解曲线不变。
* **例**：$2xy\,\mathrm{d}x + x^2\,\mathrm{d}y = 0$：$P_y = 2x = Q_x$，$u = x^2y$，通解 $x^2y = C$。

#### 2. 积分因子（边界）：乘一个因子凑全微分
* **常用的凑法**：$x\,\mathrm{d}y + y\,\mathrm{d}x = \mathrm{d}(xy)$，$\dfrac{x\,\mathrm{d}y - y\,\mathrm{d}x}{x^2} = \mathrm{d}\dfrac{y}{x}$，$\dfrac{x\,\mathrm{d}y - y\,\mathrm{d}x}{x^2 + y^2} = \mathrm{d}\arctan\dfrac{y}{x}$。
* **例**：$(x + y^2)\,\mathrm{d}x - 2xy\,\mathrm{d}y = 0$ 乘 $\dfrac{1}{x^2}$：$\dfrac{\mathrm{d}x}{x} + \dfrac{y^2\,\mathrm{d}x - 2xy\,\mathrm{d}y}{x^2} = \mathrm{d}\ln|x| - \mathrm{d}\dfrac{y^2}{x}$，通解 $\ln|x| - \dfrac{y^2}{x} = C$。

**③ 高阶方程怎么降阶**

#### 1. $y^{(n)} = f(x)$ 型：一层一层积
* **例**：$y'' = \sin x$：$y' = -\cos x + C_1$，$y = -\sin x + C_1x + C_2$。

#### 2. $y'' = f(x, y')$ 型（不显含 $y$）：$y'$ 当新未知函数
* **例**：$y'' = y' + x$：$p' - p = x$，$p = C_1e^x - x - 1$，$y = C_1e^x - \dfrac{x^2}{2} - x + C_2$。
* **常数个数**：解 $p$ 带一个，积分回 $y$ 再带一个，共两个。

#### 3. $y'' = f(y, y')$ 型（不显含 $x$）：$y$ 当自变量
* **为什么 $y'' = p\dfrac{\mathrm{d}p}{\mathrm{d}y}$**：$p$ 是 $y$ 的函数，$y$ 又是 $x$ 的函数，链式法则。
* **例**：$yy'' = (y')^2$：$yp\dfrac{\mathrm{d}p}{\mathrm{d}y} = p^2$，$p \neq 0$ 时 $\dfrac{\mathrm{d}p}{p} = \dfrac{\mathrm{d}y}{y}$，$p = C_1y$，$y = C_2e^{C_1x}$。
* **两种降阶别混**：缺 $y$ 时 $y'' = \dfrac{\mathrm{d}p}{\mathrm{d}x}$；缺 $x$ 时 $y'' = p\dfrac{\mathrm{d}p}{\mathrm{d}y}$。

**④ 线性方程的解的结构**

#### 1. 齐次线性方程解的叠加：解的组合还是解
* **例**：$e^x$、$e^{2x}$ 是 $y'' - 3y' + 2y = 0$ 的解，$3e^x - 5e^{2x}$ 也是。
* **非线性不行**：$y' = y^2$ 的解乘 $2$ 就不是解了。

#### 2. 齐次线性方程的通解：两个不成比例的解
* **为什么要无关**：$e^x$ 与 $2e^x$ 的组合只有一个常数，管不住两个初始条件。
* **和线性代数对照**：齐次方程的解组成一个二维的空间，两个线性无关的解是它的一组基。

#### 3. 非齐次线性方程的通解：特解加齐次通解
* **例**：$y'' + y = 1$：$y^* = 1$，齐次通解 $C_1\cos x + C_2\sin x$，通解 $y = 1 + C_1\cos x + C_2\sin x$。
* **和线性代数对照**：$Ax = b$ 的通解 $=$ 一个特解 $+$ $Ax = 0$ 的通解，道理相同：两个解之差落在齐次方程的解里。

#### 4. 解的叠加与差：组合系数之和定成败
* **为什么 $\lambda + \mu = 1$**：$L[\lambda y_1 + \mu y_2] = (\lambda + \mu)f$，等于 $f$ 要 $\lambda + \mu = 1$，等于 $0$ 要 $\lambda + \mu = 0$。
* **例**：$y_1, y_2$ 是非齐次方程的解，$\dfrac{y_1 + y_2}{2}$ 是非齐次的解，$y_1 - y_2$ 是齐次的解，$y_1 + y_2$ 都不是。

#### 5. 由非齐次方程的三个解写通解：两两相减
* **为什么要减同一个**：$y_1 - y_3$、$y_2 - y_3$ 是齐次方程的解；再加上任一个 $y_3$ 作特解。
* **先验无关**：两差成比例时，三个解不够写出通解。

**⑤ 常系数齐次怎么解**

#### 1. 二阶常系数齐次线性方程的通解：看判别式
* **三种情形**：$p^2 - 4q > 0$ 两个实根；$= 0$ 重根；$< 0$ 复根。
* **重根为什么是 $xe^{rx}$**：把 $y = xe^{rx}$ 代入，得 $x(r^2 + pr + q)e^{rx} + (2r + p)e^{rx}$，重根时两个括号都为 $0$。
* **复根的例**：$y'' + 4y = 0$：$r = \pm 2\mathrm{i}$，$\alpha = 0$，$y = C_1\cos 2x + C_2\sin 2x$。

#### 2. $n$ 阶常系数齐次线性方程：每个根管几项
* **数项数**：特征方程是 $n$ 次的，根（含重数）一共 $n$ 个，通解正好 $n$ 项、$n$ 个常数。
* **例**：$y''' - y' = 0$：$r^3 - r = 0$，$r = 0, 1, -1$，$y = C_1 + C_2e^x + C_3e^{-x}$；$r = 0$ 对应常数项。

#### 3. 由通解反求方程：倒着走
* **例**：$y = C_1e^x + C_2e^{3x}$：根 $1$、$3$，$(r - 1)(r - 3) = r^2 - 4r + 3$，方程 $y'' - 4y' + 3y = 0$。
* **复根成对**：$e^x\sin x$ 是解，$1 + \mathrm{i}$、$1 - \mathrm{i}$ 都是根。

**⑥ 常系数非齐次怎么解**

#### 1. 自由项为 $e^{\lambda x}P_m(x)$ 型：看 $\lambda$ 撞没撞上
* **为什么要乘 $x$**：$\lambda$ 是特征根时，$e^{\lambda x}Q_m$ 代入左边，最高次项被消掉，左边的次数比 $m$ 低，配不出 $P_m$；乘 $x$ 把次数补回来。
* **例**：$y'' - y = e^x$：$1$ 是单根，设 $y^* = axe^x$，代入得 $2ae^x = e^x$，$a = \dfrac{1}{2}$。
* **多项式右端**：$y'' + y = x^2$，$\lambda = 0$ 不是根，设 $y^* = ax^2 + bx + c$，得 $y^* = x^2 - 2$。

#### 2. 自由项为 $e^{\lambda x}[P_l(x)\cos\omega x + P_n(x)\sin\omega x]$ 型：正弦余弦一起设
* **为什么两项都要**：$\cos\omega x$ 求一次导就变成 $\sin\omega x$，只设一项配不平。
* **例**：$y'' + 3y' = \cos x$：$\mathrm{i}$ 不是根，设 $y^* = a\cos x + b\sin x$，得 $a = -\dfrac{1}{10}$，$b = \dfrac{3}{10}$。

#### 3. 自由项是几项之和：拆开设
* **例**：$y'' + y = 1 + e^x$：$y_1^* = 1$，$y_2^* = \dfrac{e^x}{2}$，$y^* = 1 + \dfrac{e^x}{2}$。
* **每一项单独看撞不撞根**：同一个方程里，有的项要乘 $x$，有的不用。

#### 4. 欧拉方程的解法：换成 $t = \ln x$
* **算子写法**：记 $D = \dfrac{\mathrm{d}}{\mathrm{d}t}$，$x^2y''$ 写成 $D(D - 1)y$，展开就是 $\dfrac{\mathrm{d}^2y}{\mathrm{d}t^2} - \dfrac{\mathrm{d}y}{\mathrm{d}t}$。
* **例**：$x^2y'' + xy' - y = 0$：$D(D - 1)y + Dy - y = (D^2 - 1)y = 0$，$y = C_1e^t + C_2e^{-t} = C_1x + \dfrac{C_2}{x}$。
* **右端也要换**：右端的 $x$ 换成 $e^t$，$\ln x$ 换成 $t$。

### 〔例题〕

**① 怎么列方程，解是什么**

#### 例题 1：从条件到方程

**题目**：
1. 曲线过原点，每一点处切线的斜率等于 $2x + y$，求曲线；
2. 曲线上任一点 $P$ 处的法线与 $x$ 轴交于 $Q$，线段 $PQ$ 被 $y$ 轴平分，求曲线族；
3. 镭的衰变速度与现存量成正比，半衰期 $1600$ 年，求 $800$ 年后剩下原来的多少；
4. $f(x)$ 连续，$f(x) = 1 + \displaystyle\int_0^x f^2(t)\,\mathrm{d}t$，求 $f(x)$。
##### 【小题 1】斜率就是 $y'$
* $y' = 2x + y$，即 $y' - y = 2x$，一阶线性；
* $(ye^{-x})' = 2xe^{-x}$，$ye^{-x} = -2(x + 1)e^{-x} + C$，$y = Ce^x - 2x - 2$；
* 过原点：$C = 2$，$y = 2e^x - 2x - 2$。
* **细节**：$\displaystyle\int 2xe^{-x}\,\mathrm{d}x = -2(x + 1)e^{-x}$ 用分部积分。
##### 【小题 2】法线与 $x$ 轴的交点
* 法线 $Y - y = -\dfrac{1}{y'}(X - x)$，令 $Y = 0$，$Q$ 的横坐标 $X = x + yy'$；
* $PQ$ 的中点在 $y$ 轴上：$\dfrac{x + (x + yy')}{2} = 0$，即 $yy' = -2x$；
* 分离变量：$y\,\mathrm{d}y = -2x\,\mathrm{d}x$，$2x^2 + y^2 = C$，是一族椭圆。
##### 【小题 3】成正比，带负号
* $\dfrac{\mathrm{d}R}{\mathrm{d}t} = -\lambda R$，$R = R_0e^{-\lambda t}$；
* 半衰期：$e^{-1600\lambda} = \dfrac{1}{2}$；
* $800$ 年后：$e^{-800\lambda} = \left(e^{-1600\lambda}\right)^{\frac{1}{2}} = \dfrac{1}{\sqrt{2}}$，剩下约 $70.7\%$。
* **细节**：不必求出 $\lambda$，$800$ 正好是半衰期的一半。
##### 【小题 4】积分方程
* 求导：$f'(x) = f^2(x)$；令 $x = 0$：$f(0) = 1$；
* 分离变量：$-\dfrac{1}{f} = x + C$，$C = -1$，$f(x) = \dfrac{1}{1 - x}$（$x < 1$）。
* **细节**：$f$ 在 $x = 1$ 处趋于无穷，解只在 $x < 1$ 上成立；方程里看不出这一点，是解出来才知道的。

**② 一阶方程怎么积出来**

#### 例题 2：六个一阶方程

**题目**：解下列方程：
1. $y' = e^{x - y}$；
2. $xy' = y + \sqrt{x^2 - y^2}$（$x > 0$）；
3. $y' + 2xy = 2xe^{-x^2}$；
4. $(y^2 - 6x)y' + 2y = 0$；
5. $y' + y = y^2(\cos x - \sin x)$；
6. $(x^2 + y)\,\mathrm{d}x + (x - 2y)\,\mathrm{d}y = 0$。
##### 【小题 1】可分离
* $e^y\,\mathrm{d}y = e^x\,\mathrm{d}x$，$e^y = e^x + C$。
* **细节**：$e^{x - y} = e^x \cdot e^{-y}$，指数的差拆成乘积。
##### 【小题 2】齐次，再补解
* $y' = \dfrac{y}{x} + \sqrt{1 - \left(\dfrac{y}{x}\right)^2}$，令 $u = \dfrac{y}{x}$：$xu' = \sqrt{1 - u^2}$；
* $\dfrac{\mathrm{d}u}{\sqrt{1 - u^2}} = \dfrac{\mathrm{d}x}{x}$，$\arcsin u = \ln x + C$，$y = x\sin(\ln x + C)$；
* **若 $\sqrt{1 - u^2} = 0$**：$u = \pm 1$，$y = \pm x$ 也是解（分离变量时除掉了）。
##### 【小题 3】线性
* $e^{\int 2x\,\mathrm{d}x} = e^{x^2}$，$(ye^{x^2})' = 2x$，$y = (x^2 + C)e^{-x^2}$。
##### 【小题 4】以 $x$ 为未知函数
* $\dfrac{\mathrm{d}x}{\mathrm{d}y} = \dfrac{6x - y^2}{2y}$，即 $\dfrac{\mathrm{d}x}{\mathrm{d}y} - \dfrac{3}{y}x = -\dfrac{y}{2}$；
* 积分因子 $y^{-3}$：$\left(\dfrac{x}{y^3}\right)' = -\dfrac{1}{2y^2}$，$\dfrac{x}{y^3} = \dfrac{1}{2y} + C$，$x = Cy^3 + \dfrac{y^2}{2}$。
* **细节**：对 $y$ 看，方程里有 $y^2y'$，不是线性的；对 $x$ 看，$x$ 只出现一次方。
##### 【小题 5】伯努利
* $n = 2$，令 $z = y^{-1}$：$z' - z = \sin x - \cos x$；
* $(ze^{-x})' = (\sin x - \cos x)e^{-x}$，积分得 $ze^{-x} = -e^{-x}\sin x + C$，$z = Ce^x - \sin x$；
* $y = \dfrac{1}{Ce^x - \sin x}$；另有解 $y = 0$。
* **细节**：$\displaystyle\int(\sin x - \cos x)e^{-x}\,\mathrm{d}x = -e^{-x}\sin x$，可以对 $-e^{-x}\sin x$ 求导验证。
##### 【小题 6】全微分
* $P_y = 1 = Q_x$；
* $u = \displaystyle\int_0^x x^2\,\mathrm{d}x + \int_0^y (x - 2y)\,\mathrm{d}y = \dfrac{x^3}{3} + xy - y^2$；
* 通解 $\dfrac{x^3}{3} + xy - y^2 = C$。

**③ 高阶方程怎么降阶**

#### 例题 3：降阶的三种情形

**题目**：
1. 解 $y''' = e^{2x} - \cos x$；
2. 解 $xy'' + y' = 0$；
3. 解 $y'' = 2yy'$，$y(0) = 1$，$y'(0) = 1$；
4. 不给初始条件，小题 3 的通解有几种形式？
##### 【小题 1】积三次
* $y'' = \dfrac{e^{2x}}{2} - \sin x + C_1$，$y' = \dfrac{e^{2x}}{4} + \cos x + C_1x + C_2$；
* $y = \dfrac{e^{2x}}{8} + \sin x + \dfrac{C_1}{2}x^2 + C_2x + C_3$。
##### 【小题 2】缺 $y$
* $p = y'$：$xp' + p = 0$，即 $(xp)' = 0$，$p = \dfrac{C_1}{x}$；
* $y = C_1\ln|x| + C_2$。
* **细节**：$xp' + p$ 正好是 $(xp)'$，不必套线性方程的公式。
##### 【小题 3】缺 $x$，早用初始条件
* $p\dfrac{\mathrm{d}p}{\mathrm{d}y} = 2yp$，$p \ne 0$ 时 $\dfrac{\mathrm{d}p}{\mathrm{d}y} = 2y$，$p = y^2 + C_1$；
* $y = 1$ 时 $p = 1$：$C_1 = 0$，$y' = y^2$；
* $-\dfrac{1}{y} = x + C_2$，$C_2 = -1$，$y = \dfrac{1}{1 - x}$。
* **细节**：$y'(0) = 1 \ne 0$，所以 $p = 0$ 那个分支不满足初始条件，直接舍去。
##### 【小题 4】不给初始条件，要分情形
* $p = 0$：$y = C$；
* $p = y^2 + C_1$，**若 $C_1 = a^2 > 0$**：$\dfrac{1}{a}\arctan\dfrac{y}{a} = x + C_2$，$y = a\tan(ax + aC_2)$；
* **若 $C_1 = 0$**：$y = -\dfrac{1}{x + C_2}$；
* **若 $C_1 = -a^2 < 0$**：$\dfrac{1}{2a}\ln\left|\dfrac{y - a}{y + a}\right| = x + C_2$。
* **细节**：小题 3 早定 $C_1 = 0$，三种情形只剩一种；这就是「初始条件早用」的好处。

**④ 线性方程的解的结构**

#### 例题 4：解的结构

**题目**：
1. $y_1 = 1$，$y_2 = x$，$y_3 = x^2$ 是某二阶非齐次线性方程的解，写出它的通解；
2. $y_1, y_2$ 是 $y' + P(x)y = Q(x)$ 的两个不同的解，常数 $\lambda, \mu$ 使 $\lambda y_1 + \mu y_2$ 是该方程的解，$\lambda y_1 - \mu y_2$ 是对应齐次方程的解，求 $\lambda, \mu$；
3. 判断 $e^x$ 与 $xe^x$、$\sin 2x$ 与 $\sin x\cos x$ 是否线性无关。
##### 【小题 1】两两相减
* $y_2 - y_1 = x - 1$，$y_3 - y_1 = x^2 - 1$，比值 $x + 1$ 不是常数，线性无关；
* 通解 $y = C_1(x - 1) + C_2(x^2 - 1) + 1$。
* **细节**：选 $y_1$ 当特解、$y_2 - y_1$ 和 $y_3 - y_1$ 当齐次解，结果形式不同，但是同一族函数。
##### 【小题 2】系数之和
* $\lambda y_1 + \mu y_2$ 是非齐次的解：$\lambda + \mu = 1$；
* $\lambda y_1 - \mu y_2$ 是齐次的解：$\lambda - \mu = 0$；
* $\lambda = \mu = \dfrac{1}{2}$。
##### 【小题 3】看比值
* $\dfrac{xe^x}{e^x} = x$，不是常数，线性无关；
* $\dfrac{\sin 2x}{\sin x\cos x} = 2$，线性相关。

**⑤ 常系数齐次怎么解**

#### 例题 5：特征根的几种样子

**题目**：
1. 解 $y'' + 4y' + 4y = 0$，$y(0) = 2$，$y'(0) = 0$；
2. 解 $y'' + 2y' + 5y = 0$；
3. 解 $y^{(4)} + 2y'' + y = 0$；
4. 求以 $y = C_1e^{2x} + e^{-x}(C_2\cos x + C_3\sin x)$ 为通解的常系数齐次线性方程。
##### 【小题 1】重根，定常数
* $r^2 + 4r + 4 = 0$，$r = -2$（二重），$y = (C_1 + C_2x)e^{-2x}$；
* $y(0) = C_1 = 2$；$y'(0) = C_2 - 2C_1 = 0$，$C_2 = 4$；
* $y = (2 + 4x)e^{-2x}$。
##### 【小题 2】复根
* $r = -1 \pm 2\mathrm{i}$，$y = e^{-x}(C_1\cos 2x + C_2\sin 2x)$。
##### 【小题 3】重复根
* $r^4 + 2r^2 + 1 = (r^2 + 1)^2 = 0$，$\pm\mathrm{i}$ 各是二重根；
* $y = (C_1 + C_2x)\cos x + (C_3 + C_4x)\sin x$。
* **细节**：四阶方程，四个常数；二重复根每个带 $x^0$、$x^1$ 两次，正弦余弦各一套。
##### 【小题 4】反求
* 根：$2$，$-1 \pm \mathrm{i}$；
* $(r - 2)(r^2 + 2r + 2) = r^3 - 2r - 4$；
* 方程 $y''' - 2y' - 4y = 0$。
* **细节**：$-1 \pm \mathrm{i}$ 对应的二次因式是 $(r + 1)^2 + 1 = r^2 + 2r + 2$。

**⑥ 常系数非齐次怎么解**

#### 例题 6：一个左边，五个右边

**题目**：方程左边都是 $y'' - 3y' + 2y$（特征根 $1$、$2$），求下列右端对应的特解：
1. $f(x) = x$；
2. $f(x) = e^{3x}$；
3. $f(x) = e^x$；
4. $f(x) = e^x\cos x$；
5. $f(x) = x + e^{3x}$，并求满足 $y(0) = y'(0) = 0$ 的解。
##### 【小题 1】多项式，$\lambda = 0$ 不是根
* 设 $y^* = ax + b$：$-3a + 2ax + 2b = x$，$a = \dfrac{1}{2}$，$b = \dfrac{3}{4}$；
* $y^* = \dfrac{x}{2} + \dfrac{3}{4}$。
##### 【小题 2】$\lambda = 3$ 不是根
* 设 $y^* = Ae^{3x}$：$(9 - 9 + 2)A = 1$，$A = \dfrac{1}{2}$。
##### 【小题 3】$\lambda = 1$ 是单根
* 设 $y^* = Axe^x$：代入得 $(x + 2 - 3x - 3 + 2x)Ae^x = -Ae^x = e^x$，$A = -1$；
* $y^* = -xe^x$。
* **细节**：若不乘 $x$，设 $Ae^x$，代入左边是 $0$，永远配不出 $e^x$。
##### 【小题 4】$1 + \mathrm{i}$ 不是根
* 设 $y^* = e^xu$，$u = A\cos x + B\sin x$：左边化成 $e^x(u'' - u')$；
* $u'' - u' = (-A - B)\cos x + (A - B)\sin x = \cos x$，$A = B = -\dfrac{1}{2}$；
* $y^* = -\dfrac{1}{2}e^x(\cos x + \sin x)$。
* **细节**：把 $y = e^xu$ 代入 $y'' - 3y' + 2y$，得 $e^x(u'' - u')$，比直接求导省事。
##### 【小题 5】叠加，再定常数
* $y^* = \dfrac{x}{2} + \dfrac{3}{4} + \dfrac{1}{2}e^{3x}$，通解 $y = C_1e^x + C_2e^{2x} + y^*$；
* $y(0) = 0$：$C_1 + C_2 + \dfrac{5}{4} = 0$；$y'(0) = 0$：$C_1 + 2C_2 + 2 = 0$；
* $C_1 = -\dfrac{1}{2}$，$C_2 = -\dfrac{3}{4}$，$y = -\dfrac{1}{2}e^x - \dfrac{3}{4}e^{2x} + \dfrac{x}{2} + \dfrac{3}{4} + \dfrac{1}{2}e^{3x}$。
* **细节**：初始条件用在通解上，不能用在特解上。

#### 例题 7：撞上特征根，与积分方程

**题目**：
1. 求 $y'' + 4y = \cos 2x$ 的一个特解；
2. 求 $y'' + 4y = \cos x$ 的一个特解；
3. $f(x)$ 连续，$f(x) = e^x - \displaystyle\int_0^x (x - t)f(t)\,\mathrm{d}t$，求 $f(x)$。
##### 【小题 1】$2\mathrm{i}$ 是根
* 设 $y^* = x(A\cos 2x + B\sin 2x)$，代入得 $-4A\sin 2x + 4B\cos 2x = \cos 2x$；
* $A = 0$，$B = \dfrac{1}{4}$，$y^* = \dfrac{x}{4}\sin 2x$。
* **细节**：右端只有余弦，特解却是正弦；所以两项都要设。
##### 【小题 2】$\mathrm{i}$ 不是根
* 设 $y^* = A\cos x + B\sin x$：$3A\cos x + 3B\sin x = \cos x$，$y^* = \dfrac{1}{3}\cos x$。
##### 【小题 3】求导两次
* 拆开：$f(x) = e^x - x\displaystyle\int_0^x f(t)\,\mathrm{d}t + \int_0^x tf(t)\,\mathrm{d}t$；
* 求导：$f'(x) = e^x - \displaystyle\int_0^x f(t)\,\mathrm{d}t$；再求导：$f''(x) = e^x - f(x)$；
* 初始条件：$f(0) = 1$，$f'(0) = 1$；
* $f'' + f = e^x$：$y^* = \dfrac{e^x}{2}$，$f = C_1\cos x + C_2\sin x + \dfrac{e^x}{2}$，$C_1 = C_2 = \dfrac{1}{2}$；
* $f(x) = \dfrac{1}{2}(\cos x + \sin x + e^x)$。
* **细节**：第一次求导时，$-x\displaystyle\int_0^x f$ 用乘积法则，得 $-\displaystyle\int_0^x f - xf(x)$，与 $\displaystyle\int_0^x tf$ 的导数 $xf(x)$ 抵消。

#### 例题 8：欧拉方程与幂级数

**题目**：
1. 解 $x^2y'' - xy' + y = 0$（$x > 0$）；
2. 解 $x^2y'' - 2xy' + 2y = x^3$（$x > 0$）；
3. $S(x) = \displaystyle\sum_{n=0}^{\infty}\dfrac{(-1)^nx^{2n}}{2^nn!}$，证明 $S' + xS = 0$，并求 $S(x)$。
##### 【小题 1】重根
* $D(D - 1)y - Dy + y = (D - 1)^2y = 0$，$t$ 的方程有二重根 $1$；
* $y = (C_1 + C_2t)e^t = (C_1 + C_2\ln x)x$。
##### 【小题 2】带右端
* $D(D - 1)y - 2Dy + 2y = e^{3t}$，即 $(D^2 - 3D + 2)y = e^{3t}$，根 $1$、$2$；
* $3$ 不是根，$y^* = \dfrac{1}{2}e^{3t}$；
* $y = C_1x + C_2x^2 + \dfrac{x^3}{2}$。
##### 【小题 3】由级数得方程
* 逐项求导：$S'(x) = \displaystyle\sum_{n=1}^{\infty}\dfrac{(-1)^n 2n x^{2n-1}}{2^nn!} = -x\sum_{n=1}^{\infty}\dfrac{(-1)^{n-1}x^{2n-2}}{2^{n-1}(n - 1)!} = -xS(x)$；
* $S(0) = 1$，分离变量：$S(x) = e^{-\frac{x^2}{2}}$。
* **细节**：也可以直接认出 $S$ 是 $e^u$ 的展开式在 $u = -\dfrac{x^2}{2}$ 处的值（第 8 章）；两种办法结果一致。

### 〔提示〕

**① 怎么列方程，解是什么**

#### 1. 积分方程要读初始条件
* 求导会丢常数；令 $x$ 等于积分下限，从原方程读出 $f$ 的值。

#### 2. 「成正比」要带比例系数
* 减少的量变化率为负，方程里写负号。

#### 3. 特解不带任意常数
* 题目给了初始条件，答案就是特解。

**② 一阶方程怎么积出来**

#### 1. 分离变量会丢解
* $g(y_0) = 0$ 的常数解要补上，或说明已含在通解里。

#### 2. 线性方程先化标准形
* $y'$ 的系数化成 $1$，再读 $P$、$Q$。

#### 3. 对 $y$ 不线性，试试对 $x$
* $\dfrac{\mathrm{d}x}{\mathrm{d}y}$ 的方程可能是线性的。

**③ 高阶方程怎么降阶**

#### 1. 两种降阶的 $y''$ 不一样
* 缺 $y$：$y'' = p'(x)$；缺 $x$：$y'' = p\dfrac{\mathrm{d}p}{\mathrm{d}y}$。

#### 2. 初始条件早用
* 第一次积分后就定 $C_1$，避免分情形。

**④ 线性方程的解的结构**

#### 1. 通解要两个线性无关的解
* 成比例的两个解只给一个常数。

#### 2. 非齐次的解相减才是齐次的解
* 相加不是；系数和为 $1$ 才是非齐次的解。

**⑤ 常系数齐次怎么解**

#### 1. 重根别忘了乘 $x$
* 二重根 $(C_1 + C_2x)e^{rx}$，三重根再多一个 $x^2$。

#### 2. 复根写成实函数
* $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$，答案里不留 $\mathrm{i}$。

**⑥ 常系数非齐次怎么解**

#### 1. $\lambda$ 是特征根就乘 $x$
* 单根乘 $x$，重根乘 $x^2$；不乘，代入后配不出右端。

#### 2. 三角右端两项都设
* 只有 $\cos\omega x$ 也要设 $\cos\omega x$、$\sin\omega x$ 两项。

#### 3. 初始条件代通解
* 先写出 $y = Y + y^*$，再用初始条件定常数。
