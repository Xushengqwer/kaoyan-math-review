### 第一步：看题目在问谁

先找题目问的对象，它决定去哪一站：

* **问二重极限、连续**（求极限；说明极限不存在；判断在某点是否连续）→ **① 从四面八方靠近**
* **问一点处的偏导数、可微**（按定义求偏导数；判断可微；连续、偏导数存在、可微、偏导数连续之间谁推出谁；求全微分）→ **② 变化有多快**
* **求复合函数、隐函数的偏导数**（含抽象函数 $f(u, v)$；二阶偏导数；方程或方程组确定的函数；用变量代换化简含偏导数的方程）→ **③ 怎么求偏导**
* **求方向导数、梯度**（沿某方向的变化率；变化率最大的方向和最大值）→ **④ 往哪个方向升得最快**
* **求曲面的切平面、法线，曲线的切线、法平面** → **⑤ 切平面和切线**
* **求极值、最值、条件极值**（含由方程确定的函数的极值；实际问题的最大、最小）→ **⑥ 最高点和最低点**

平面方程、直线方程的写法：在第 4 章，这里只负责求出法向量、切向量。正定的判断：在线代第 4 章，这里只用 $A$ 与 $AC - B^2$ 的符号。已知 $\mathrm{d}u$ 求 $u$：在第 7 章（与路径无关）。

### 第二步：动笔之前，先看能不能直接判断

* **沿 $y = kx$ 趋于原点，结果随 $k$ 变**：极限不存在；函数在原点不连续，也不可微。
* **在分段点处求偏导数**：只能用定义，$f_x(0, 0) = \lim\limits_{x \to 0}\dfrac{f(x, 0) - f(0, 0)}{x}$。
* **求一点处的偏导数 $f_x(x_0, y_0)$**：先把 $y = y_0$ 代进去，再对 $x$ 求导，常常省去大量计算。
* **偏导数在该点连续**：直接可微，不必用定义。
* **在该点不连续，或偏导数不存在**：直接不可微。
* **$f(x, y) = f(y, x)$**：只算 $f_x$，把 $x$、$y$ 对调就得 $f_y$。
* **问变化率最大的方向和最大值**：直接是 $\operatorname{grad} f$ 的方向和 $|\operatorname{grad} f|$，不必设方向再求最值。
* **有界闭区域上的连续函数求最值**：不必判断驻点是不是极值，算出函数值直接比较。
* **约束能解出一个变量**（如 $x + y = 1$）：代入化成一元，不一定用拉格朗日。

### 第三步：按站计算

* **① 从四面八方靠近**：
  * 能代入就代入：多元初等函数在定义区域内连续；
  * 一元的工具照用：等价无穷小、有界乘无穷小（第 1 章），如 $\dfrac{\sin(xy)}{x} = \dfrac{\sin(xy)}{xy} \cdot y$；
  * 夹逼：用 $|xy| \le \dfrac{x^2 + y^2}{2}$、$|x| \le \sqrt{x^2 + y^2}$ 放缩；或令 $x = \rho\cos\theta$，$y = \rho\sin\theta$，放缩成只含 $\rho$ 的式子；
  * 说明不存在：取 $y = kx$、$y = kx^2$ 等路径，结果随 $k$ 变；或两条路径结果不同；
  * 判断连续：在分段点处求极限，与函数值比较。
* **② 变化有多快**：
  * 偏导数：把其余变量当常数，按一元求导；分段点处用定义；
  * 判可微：先求 $f_x(x_0, y_0)$、$f_y(x_0, y_0)$，不存在则不可微；再看 $\lim\limits_{\rho \to 0}\dfrac{\Delta z - f_x\Delta x - f_y\Delta y}{\rho}$ 是否为 $0$，这是一个二重极限，按 ① 算；
  * 判偏导数连续：分别求出该点以外的 $f_x(x, y)$ 和该点的 $f_x(x_0, y_0)$（定义），看前者的极限是否等于后者；
  * 全微分：$\mathrm{d}z = f_x\,\mathrm{d}x + f_y\,\mathrm{d}y$；三元函数再加 $f_z\,\mathrm{d}z$ 一项。
* **③ 怎么求偏导**：
  * 复合函数：画变量关系图，$z$ 到 $x$ 有几条路径就有几项，每项是路径上各层偏导数的乘积；
  * 抽象函数的二阶：$f_1'$ 仍是 $u, v$ 的函数，$\dfrac{\partial}{\partial y}f_1' = f_{11}''u_y + f_{12}''v_y$；二阶偏导数连续时，合并 $f_{12}'' = f_{21}''$；
  * 隐函数，公式法：$z_x = -\dfrac{F_x}{F_z}$，求 $F_x$ 时 $x, y, z$ 都当自变量，$z$ 当常数；
  * 隐函数，直接求导：两边对 $x$ 求偏导，$z$ 当 $x, y$ 的函数，再解出 $z_x$；
  * 隐函数的二阶：对 $z_x$ 的表达式再求偏导，$z$ 仍是 $x, y$ 的函数，最后把 $z_x$、$z_y$ 代进去；
  * 方程组：两边对 $x$ 求偏导，得关于 $u_x, v_x$ 的二元一次方程组，用克拉默法则解；
  * 全微分法：两边取全微分，整理成 $\mathrm{d}z = (\cdots)\,\mathrm{d}x + (\cdots)\,\mathrm{d}y$，两个系数就是 $z_x$、$z_y$；方程组也一样，解出 $\mathrm{d}u$、$\mathrm{d}v$；
  * 求一点处的值：先由方程算出该点的 $z$，再代入；
  * 变量代换化简方程：用链式把 $z_x$、$z_y$（及二阶偏导数）写成对新变量的偏导数，代入原方程，比较系数定出参数。
* **④ 往哪个方向升得最快**：
  * 方向先化成单位向量：$\boldsymbol{e} = \dfrac{\boldsymbol{l}}{|\boldsymbol{l}|}$；
  * 可微：$\dfrac{\partial f}{\partial l} = \operatorname{grad} f \cdot \boldsymbol{e} = f_x\cos\alpha + f_y\cos\beta$；
  * 不可微，或不知道是否可微：用定义 $\lim\limits_{t \to 0^+}\dfrac{f(x_0 + t\cos\alpha,\ y_0 + t\cos\beta) - f(x_0, y_0)}{t}$；
  * 沿曲线的切线方向、沿曲面的法线方向：先按 ⑤ 求出切向量、法向量，再化成单位向量。
* **⑤ 切平面和切线**：
  * 曲面：移项写成 $F(x, y, z) = 0$，$\boldsymbol{n} = (F_x, F_y, F_z)$，代入切点；
  * $z = f(x, y)$：$\boldsymbol{n} = (f_x, f_y, -1)$；
  * 参数式曲线：$\boldsymbol{T} = (x'(t_0), y'(t_0), z'(t_0))$；$y = \varphi(x)$，$z = \psi(x)$ 以 $x$ 为参数，$\boldsymbol{T} = (1, \varphi'(x_0), \psi'(x_0))$；
  * 交线：$\boldsymbol{T} = \boldsymbol{n}_1 \times \boldsymbol{n}_2$；或方程组两边对 $x$ 求导，解出 $y'$、$z'$，$\boldsymbol{T} = (1, y', z')$；
  * 已知切平面平行于某平面（法线平行于某直线）求切点：令 $\boldsymbol{n}$ 与已知向量成比例 $t$，与曲面方程联立；
  * 写方程：切平面、法平面用点法式，法线、切线用对称式（第 4 章）。
* **⑥ 最高点和最低点**：
  * 无条件极值：解 $f_x = 0$，$f_y = 0$，得驻点；在每个驻点算 $A = f_{xx}$，$B = f_{xy}$，$C = f_{yy}$；
  * 偏导数不存在的点：也是候选，用极值的定义判断；
  * $AC - B^2 = 0$：沿过该点的几条特殊路径（如 $y = 0$、$y = x$）比较函数值，两侧有大有小就不是极值；
  * 由 $F(x, y, z) = 0$ 确定的 $z$ 的极值：$F_x = 0$，$F_y = 0$ 与 $F = 0$ 联立求点；方程两边再求一次偏导，代入 $z_x = z_y = 0$，得 $A = -\dfrac{F_{xx}}{F_z}$，$B = -\dfrac{F_{xy}}{F_z}$，$C = -\dfrac{F_{yy}}{F_z}$；
  * 有界闭区域上的最值：内部的候选点，加上边界上的最值（代入化成一元，或用拉格朗日），一起比较；
  * 条件极值：$L = f + \lambda\varphi$，解 $L_x = L_y = 0$，$\varphi = 0$；三元再加 $L_z = 0$，两个约束再加 $\mu\psi$；
  * 解拉格朗日方程组：先消去 $\lambda$（各式移项后相除），再利用对称性；
  * 目标是距离：换成距离的平方，最值点不变；
  * 实际问题：可能的极值点只有一个，它就是所求的最值点。

### 第四步：读结论

* **① 从四面八方靠近**：
  * **不存在**：两条路径结果不同，就够了。
  * **存在**：只验证了所有直线 $y = kx$ 不够；如 $\dfrac{x^2y}{x^4 + y^2}$ 沿直线都趋于 $0$，沿 $y = x^2$ 趋于 $\dfrac{1}{2}$。
* **② 变化有多快**：
  * **可微**：推出连续，也推出偏导数存在；两者有一个不成立，就不可微。
  * **连续且偏导数存在**：仍可能不可微，如 $\sqrt{|xy|}$ 在原点。
  * **可微**：不要求偏导数连续。
* **④ 往哪个方向升得最快**：
  * **方向导数是一个数**，可以为负，表示沿这个方向下降；梯度是一个向量。
  * **最大变化率**：$|\operatorname{grad} f|$，方向是 $\operatorname{grad} f$；最小是 $-|\operatorname{grad} f|$；与梯度垂直的方向，变化率为 $0$。
* **⑥ 最高点和最低点**：
  * **$AC - B^2 > 0$**：$A > 0$ 极小，$A < 0$ 极大；**$AC - B^2 < 0$**：不是极值。
  * **驻点与极值点**：驻点不一定是极值点；极值点也可能是偏导数不存在的点。
  * **拉格朗日**：只给出可能的极值点；求最值时比较这些点的函数值即可。
  * **有界闭区域**：最值一定取得，比出来的最大、最小就是所求。

---

### 第五步：算完之后

* **自查**：
  * 偏导数：代一个具体的点，与「先代值、再求导」的结果比对；
  * 隐函数：公式法与全微分法各算一次，结果应相同；
  * 二阶混合偏导数：先 $x$ 后 $y$、先 $y$ 后 $x$ 各算一次，应相等；
  * 切平面：切点代入切平面方程，应成立；
  * 极值：把驻点代回 $f_x = 0$，$f_y = 0$；条件极值的点代回约束。
* **交卷前检查**：
  * 抽象函数的二阶，$f_1'$、$f_2'$ 又走了一遍链式，没有当成常数；
  * 合并 $f_{12}''$ 与 $f_{21}''$ 时，写了「二阶偏导数连续」；
  * 隐函数公式带了负号；公式法里求 $F_x$ 时 $z$ 当常数；
  * 方向导数的方向化成了单位向量；
  * 极值的候选没有漏掉偏导数不存在的点；
  * 最值题算了边界；
  * 二重极限没有只沿一种路径就下「存在」的结论。
