# 第 6 章 重积分（二重积分、三重积分）

**一条主线**：把定积分「切细、求和、取极限」的办法搬到平面区域和空间立体上，再化回定积分来算。分六站，每一站由上一站引出：

曲顶柱体的体积怎么算 → 怎么化成两次定积分 → 区域是圆的怎么办 → 三重积分怎么算 → 重积分怎么算更省事 → 什么量能用重积分算

**一段话说完**：第 3 章的定积分，管的是沿一段区间分布的量。可很多量摊在一块平面区域上：一个柱体的顶是曲面，各处高度不同，它的体积多大？一块薄板各处密度不同，它有多重？定义上没有新东西，还是切成小块、每块当常数、相加、取极限，这就是二重积分；区域换成立体，就是三重积分。真正的新问题是怎么算：区域上没有牛顿-莱布尼茨公式。我们的答案是化回定积分：用垂直于 $x$ 轴的平面一刀一刀地切，每个截面的面积是一个定积分，再把截面加起来，又是一个定积分。剩下的内容，都是为了让这一步好做：上下限从区域的图里读出来；内层积不出，或者区域要分块，就换个方向切；区域是圆的，就改成按圆切，面积元多出一个 $r$；立体是同样的事再做一次，圆柱、球也按它们的形状切。每化一次都要画图、定限、积两三次，所以动手之前先看对称，能抵消的直接是 $0$。最后回到开头：权取 $1$ 是面积、体积，取密度是质量，再乘上坐标、距离的平方，就是质心、转动惯量；引力是向量，按分量各积一次。

## ① 曲顶柱体的体积怎么算

柱体的体积是底面积乘高，可曲顶柱体的顶是曲面 $z = f(x, y)$，各处高度不同。一块薄板各处密度不同，求它的质量，也是这个问题。办法照搬定积分：把底面 $D$ 切成小块，每一小块上高度变化不大，就当它不变，用高乘这一小块的面积，加起来，再让小块越切越细，取极限，这就是二重积分。区域换成立体 $\Omega$，面积换成体积，就是三重积分。定积分的性质：线性、可加、比较、估值，都原样搬过来。中值定理也一样：把柱体里的沙子推平，推平后的高度就是平均高度，顶上一定有一点原来就是这个高度；区域缩成一点时，平均高度就趋于这一点的高度。

* 二重积分 = 分割、求和、取极限；$f \ge 0$ 时是曲顶柱体的体积，$\iint_D 1\,\mathrm{d}\sigma$ 是 $D$ 的面积；
* 三重积分把 $D$ 换成立体 $\Omega$、面积元换成体积元；$\iiint_\Omega 1\,\mathrm{d}v$ 是体积，$f$ 是密度时是质量；
* 中值定理：$\iint_D f\,\mathrm{d}\sigma = f(\xi, \eta)\,\sigma$；$\lim\limits_{r \to 0}\dfrac{1}{\pi r^2}\iint_{x^2 + y^2 \le r^2} f\,\mathrm{d}\sigma = f(0, 0)$。

## ② 怎么化成两次定积分

定义照搬了，可区域上没有原函数，牛顿-莱布尼茨公式用不上。我们回到体积：第 3 章算过截面面积已知的立体，体积是 $\int_a^b A(x)\,\mathrm{d}x$。用垂直于 $x$ 轴的平面去切曲顶柱体，位置 $x$ 处的截面是一块曲边梯形：底是这条竖线落在 $D$ 里的一段，从 $y = \varphi_1(x)$ 到 $y = \varphi_2(x)$，高是 $f(x, y)$。它的面积 $A(x)$ 是对 $y$ 的定积分，这时 $x$ 当常数；再对 $x$ 积分，二重积分就成了两次定积分。内层的上下限看竖线从哪条边界进、从哪条边界出，所以第一步总是画出区域。也可以横着切，先对 $x$ 积分。两种次序结果相同，难易可能差很多，换次序有两个原因：一是边界，竖着切时下边界或上边界中途换了式子，要分块，横着切可能一条式子到底；二是被积函数，内层是 $\int e^{y^2}\,\mathrm{d}y$、$\int \frac{\sin y}{y}\,\mathrm{d}y$ 这类积不出的。

* X 型：$\iint_D f\,\mathrm{d}\sigma = \int_a^b \mathrm{d}x\int_{\varphi_1(x)}^{\varphi_2(x)} f(x, y)\,\mathrm{d}y$；Y 型同理；两型都不是，就分块；
* 交换次序：由上下限还原区域、画图、按另一型重写；
* 例：$\int_0^1 \mathrm{d}x\int_x^1 e^{y^2}\,\mathrm{d}y = \int_0^1 \mathrm{d}y\int_0^y e^{y^2}\,\mathrm{d}x = \int_0^1 y\,e^{y^2}\,\mathrm{d}y = \dfrac{e - 1}{2}$，多出的 $y$ 是内层区间的长度。

## ③ 区域是圆的怎么办

直角坐标切出来的是矩形条，和圆不合：圆的边界写成 $y = \pm\sqrt{1 - x^2}$，上下限带根号。区域是圆、被积函数里有 $x^2 + y^2$ 时，我们改成按圆来切：沿射线切，再沿圆周切，切出的小块是一段扇环，两条边是 $\mathrm{d}r$ 和 $r\,\mathrm{d}\theta$，所以面积元是 $r\,\mathrm{d}r\,\mathrm{d}\theta$。这个多出来的 $r$ 常常正好帮了忙：$\int e^{-x^2}\,\mathrm{d}x$ 的原函数不是初等函数，可在圆上积 $e^{-(x^2 + y^2)}$，换成极坐标是 $\int e^{-r^2}r\,\mathrm{d}r$，$r$ 正好凑出微分。定限的办法和直角坐标一样：先定 $\theta$ 的范围，再看射线从哪进、从哪出。更一般的换元，面积放大的倍数是雅可比行列式的绝对值。

* 极坐标：$\mathrm{d}\sigma = r\,\mathrm{d}r\,\mathrm{d}\theta$；圆 $x^2 + y^2 = 2x$ 化成 $r = 2\cos\theta$；极点在区域的边界上或内部时，内层下限是 $0$；
* 例：$\iint_{x^2 + y^2 \le 1} e^{-(x^2 + y^2)}\,\mathrm{d}\sigma = 2\pi\int_0^1 e^{-r^2}r\,\mathrm{d}r = \pi(1 - e^{-1})$；
* 一般换元：$\mathrm{d}x\,\mathrm{d}y = |J|\,\mathrm{d}u\,\mathrm{d}v$，$J = \dfrac{\partial(x, y)}{\partial(u, v)}$；极坐标 $J = r$。

## ④ 三重积分怎么算

三重积分是同样的事再做一次。二重积分里，被积函数可以画成高度；三重积分的三个自变量已经占满了空间，被积函数没处画了，我们改用质量来想，有两种切法。一种是竖着切：在投影区域里取一点，沿 $z$ 方向穿过立体，这根细柱从下曲面进、从上曲面出，先把细柱的质量加起来，是对 $z$ 的定积分；再把所有细柱加起来，是投影区域上的二重积分，这叫先一后二。另一种是横着切：一层一层地切，先求一层薄片的质量，是截面上的二重积分；再把各层加起来，对 $z$ 积分，这叫先二后一。被积函数只含 $z$、截面面积又好算时，截面上的二重积分就是被积函数乘截面面积，先二后一最省事。立体是圆的，也按 ③ 的办法切：圆柱、旋转抛物面在 $xOy$ 面上用极坐标、$z$ 不动，就是柱面坐标；球和圆锥用球面坐标，球面是 $r = $ 常数，顶点在原点、轴是 $z$ 轴的圆锥面是 $\varphi = $ 常数，小块的三条边是 $\mathrm{d}r$、$r\,\mathrm{d}\varphi$、$r\sin\varphi\,\mathrm{d}\theta$。

* 先一后二：$\iint_{D_{xy}} \mathrm{d}x\,\mathrm{d}y\int_{z_1(x, y)}^{z_2(x, y)} f\,\mathrm{d}z$；先二后一：$\int_{c_1}^{c_2} \mathrm{d}z\iint_{D_z} f\,\mathrm{d}x\,\mathrm{d}y$；
* 被积函数只含 $z$：$\iiint_\Omega f(z)\,\mathrm{d}v = \int_{c_1}^{c_2} f(z)S(z)\,\mathrm{d}z$，$S(z)$ 是截面的面积；
* 柱面坐标 $\mathrm{d}v = \rho\,\mathrm{d}\rho\,\mathrm{d}\theta\,\mathrm{d}z$；球面坐标 $\mathrm{d}v = r^2\sin\varphi\,\mathrm{d}r\,\mathrm{d}\varphi\,\mathrm{d}\theta$。

## ⑤ 重积分怎么算更省事

到这里，每个重积分都能化成定积分，可每化一次都要画图、定限、积两三次。区域对称时，这些工作能省掉一半，甚至全部，所以拿到题第一步先看对称。第 3 章里，奇函数在对称区间上积分为 $0$；重积分也一样：区域关于 $y$ 轴对称，被积函数关于 $x$ 是奇函数，左右两半正好抵消；是偶函数，就算一半再乘 $2$。还有一种对称是 $x, y$ 地位相同：积分和变量用什么字母无关，把 $x, y$ 互换只是改了名字，只要区域互换后不变，积分就不变。把两种写法加起来除以 $2$，常能凑出 $x^2 + y^2$。三重积分同理，对称面换成坐标面。

* 区域关于 $y$ 轴对称，看 $f$ 关于 $x$ 的奇偶：奇为 $0$，偶为一半的 $2$ 倍；关于 $x$ 轴对称，看 $y$；
* 区域关于 $y = x$ 对称：$\iint_D f(x, y)\,\mathrm{d}\sigma = \iint_D f(y, x)\,\mathrm{d}\sigma$；例：$\iint_{x^2 + y^2 \le 1} x^2\,\mathrm{d}\sigma = \dfrac{1}{2}\iint_{x^2 + y^2 \le 1} (x^2 + y^2)\,\mathrm{d}\sigma = \dfrac{\pi}{4}$；
* 三重积分：关于 $xOy$ 面对称，看 $f$ 关于 $z$ 的奇偶；$x, y, z$ 任意互换区域都不变时，$\iiint x^2\,\mathrm{d}v = \iiint y^2\,\mathrm{d}v = \iiint z^2\,\mathrm{d}v$。

## ⑥ 什么量能用重积分算

回到开头：能切成小块、每一小块近似是「某个量乘面积元或体积元」、总量等于各块相加的，都能写成重积分，和第 3 章的微元法一样。乘在面积元前面的那个量，叫它权：权取 $1$，二重积分是面积，三重积分是体积；权取密度，是质量；权取坐标乘密度，是一次矩，再除以质量就是质心，密度均匀时叫形心；权取到轴距离的平方乘密度，是转动惯量。曲面面积要多想一步：曲面上的一小片，近似是切平面上的一小片，它投到 $xOy$ 面上是 $\mathrm{d}\sigma$。切平面越斜，这一小片比 $\mathrm{d}\sigma$ 大得越多，放大的倍数是法向量与 $z$ 轴夹角余弦的倒数；法向量用第 5 章的 $\boldsymbol{n} = (f_x, f_y, -1)$，算出来是 $\sqrt{1 + f_x^2 + f_y^2}$。引力也能这样算，只是它是向量：各小块对质点的引力方向不同，大小不能直接相加，要按三个分量各积一次。

* 体积 $\iint_D (f - g)\,\mathrm{d}\sigma$，$f$ 在上、$g$ 在下；曲面面积 $\iint_{D_{xy}} \sqrt{1 + f_x^2 + f_y^2}\,\mathrm{d}x\,\mathrm{d}y$；
* 质心 $\bar{x} = \dfrac{1}{M}\iint_D x\mu\,\mathrm{d}\sigma$；形心反过来用：$\iint_D x\,\mathrm{d}\sigma = \bar{x}\,\sigma$；
* 转动惯量 = 密度 $\times$ 到轴距离的平方，如 $I_z = \iiint_\Omega (x^2 + y^2)\rho\,\mathrm{d}v$；
* 引力按分量积：$F_x = Gm\iiint_\Omega \dfrac{\rho\,(x - x_0)}{r^3}\,\mathrm{d}v$，分母是 $r^3$。
