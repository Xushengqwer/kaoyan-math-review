# 改动说明：卡片变成「格子」，配对与内容解耦（给 Codex，按 AGENTS.md 流程 E）

用户已同意方向（2026-10-07）。先读完本文件，按「实施顺序」做；每一步自检通过再进下一步。有拿不准的地方停下报告，不要猜。

## 1. 要解决的问题

现在一张超级卡的教材（`md`）和笔记（`notes.js` 里同 id 的一条）各是一整段 Markdown。网站读里面的标题来切卡、配对：`### 〔定义〕` 开小节、`**① …**` 开站、`#### n.` 开一张卡，教材第 n 张对笔记第 n 张（`dualSource` / `dualRows` / `cardOutline`）。

后果：用户在卡片内容里写了或粘了 `###`、`#### n.`、站名行，网站就以为多了小节、多了卡，整章对照错位，出现大片「没有这一条」。2026-10-06～07 已经发生多次。现有的粘贴提醒、保存检查、错位提示条（`646f4f1`、`1fb1514`）只是补丁。

目标：**卡片的边界、所属小节和站、配对关系由网站记住，不看内容。** 卡片里写什么（任何标题、整张粘贴）都只是排版。

## 2. 用户看到的样子

- 一张卡 = 一个格子：一份教材 + 一份笔记，永远绑在一起。
- 编号自动：删、挪以后后面的编号自己变。用户定位仍用「站名 · 定义/性质 · 第几张」，网站照常显示。
- 每张卡右上角，除现在的「编辑」，加这些按钮（可以收进一个「⋯」菜单）：
  - **复制到…**：选一张目标卡（同一章里，按站、小节分组列出），把这张卡的教材接到目标卡教材末尾、笔记接到目标卡笔记末尾，各自前面加一行 `##### 复制自：<这张卡的标题>`。这张卡保留。
  - **删除这张卡**：确认一次，教材和笔记一起删。
  - **上移 / 下移**：在同一小节里和相邻的卡交换；到了一站的边上，就挪进相邻那一站。
  - **在下面加一张**：新卡，教材第一行是 `#### 新卡片`，笔记为空，直接打开编辑。
- 所有这些操作和现在的「编辑」一样：存成本机修改（`BookEdits` / `Notes`）、标「本地版 · 待提交」，用户导出后交给 Claude 提交。教材和笔记两边总是同时改，不可能对不上。

## 3. 存储方式：原文里加看不见的边界记号

导出、提交、存档、`superseded` 的流程和格式都不变（仍是两段文字），只在文字里加记号行。

### 3.1 记号格式

单独一行、前后各有一个空行的 HTML 注释：

```
<!-- section:定义 -->      小节开始（定义 / 性质 / 意义 / 例题 / 提示，或主线等其他小节名）
<!-- station:① -->         站开始（圈号，⑤′ 这类照写）
<!-- card:k7f2 -->         一张卡开始；id 是短的随机串（4～6 位小写字母数字），一章内唯一
```

- 一张卡从它的 `card` 记号到下一个任意记号（或文末）为止。
- 卡属于它前面最近的 `section` 和 `station`。
- 教材和笔记里**同一个 id = 同一张卡的两半**。配对只看 id，不看标题、不看编号。
- 记号在渲染前去掉，网页上看不见；搜索、预览、打印、思维导图说明等所有地方都要先去掉记号再用。
- 站名行（`**① 变化有多快**`）和站下面那段介绍、小节标题（`### 〔性质〕`）照旧写在原文里，放在对应记号后面，仍由它们负责显示。但结构只认记号：卡片内容里出现同样的行，只是普通文字。

### 3.2 卡片的标题和编号

- 标题 = 这张卡**教材**内容的第一行（`#### ` 开头的那一行，去掉 `#### ` 和开头的「数字 + 点」）。笔记第一行照旧是用户自己的标题，只做显示。
- 编号按位置自动算（同一站、同一小节里的第几张）。原文里写的数字不再有意义，**不要改写原文里的数字**，只在显示时用自动编号。
- 右侧目录、站卡上的小标题（`cardOutline` / `decorateStations`）、本卡主线每站那句（`cardStory`）都改成按记号取结构。

### 3.3 意义 ↔ 例题

题型配对同样用 id：意义里的一个题型和笔记里对应的例题用同一个 id（`例题 n-1 / n-2` 这种同一题型的两道，放在同一张卡的笔记里）。现在 `appByType` 按 `#### n.` 配，迁移时按现有配对给同一个 id。

### 3.4 只有一边的卡

允许（例如笔记的〔提示〕没有教材那一半）。显示成单边宽格，和现在 `is-wide` 一样，不报「没有这一条」。

3. 必须逐卡核对，任何一项不过就停：

## 5. 代码要改的地方（`assets/js/app.js` 为主）

- 新增按记号解析结构的函数（建议 `cardBlocks(raw)`：返回小节、站、卡的列表，每张卡有 id、在原文里的起止位置、标题）。`dualSource` / `dualRows` / `cardOutline` / `cardStory` / `stationDeco` / `appByType` / `bookParts` 在原文**有记号**时改走它，没有记号时保持现在的行为。
- `mdHtml` / `noteMdHtml` 等渲染入口先去掉记号行。
- 单张卡片「编辑」（`editCell`）：编辑框里只放这张卡记号之后到下一个记号之前的内容，记号本身不进编辑框，保存时原样拼回。
- 第 2 节的四个按钮。每个操作都同时改教材和笔记两段原文，只动记号块，其他字节不变。
- 去掉或放宽现在的结构提醒：有记号的卡，粘贴提醒（`structuralLines`）和保存时的结构检查（`structureChange`）不再需要，因为内容不影响结构了。错位提示条（`unpairedCount`）保留，改成检查「本机副本没有记号而仓库版有」，也就是迁移前的旧副本；提示文字：本机有旧格式的修改，先点左下角「导出」交给 Claude 合并，再点「用仓库版」。
- 整卡「编辑」入口仍然隐藏（`.dual-controls`）。

## 6. 工具与测试

- `tools/apply-export.cjs`、`write.cjs`、`verify.cjs`、`archive.cjs`、`supersede.cjs`：原文仍是字符串，原则上不用改；确认它们对带记号的原文工作正常。
- 测试（`tests/`）至少覆盖：

- 桌面和 375px 手机宽度、深色模式下按钮可用、不溢出，控制台无报错。
