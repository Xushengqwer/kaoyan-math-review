怎么生成令牌？（点开看步骤）
  1. 打开 Fine-grained tokens 新建页
  2. Repository access 选 Only select repositories，只勾选这一个仓库
  3. Permissions → Repository permissions → Contents 设为 Read and write
  4. 设一个过期时间（比如 90 天），生成后把 github_pat_ 开头的字符串粘到上面

令牌只保存在这台设备的浏览器里，不会进入仓库。公用电脑上请用完点「清除令牌」。
